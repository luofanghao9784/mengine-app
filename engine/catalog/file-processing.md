# 完整文件处理 1.1.0

适用：用户明确选定、已通过 read_original 加载的固定版本；使用 process_original，不猜测文件路径。

1. list_originals 确认文件名及版本，再 read_original 获取任务内输入。读取本身不代表理解完成。
2. CSV/TSV 用 csv_summary。默认逗号分隔，有表头，列名必须唯一；TSV 显式 delimiter 为制表符。支持引号、多行单元格及双引号转义，不猜测分隔符。
3. count 统计数据行；sum 必须给 column，可指定 groupBy，或 filterColumn/filterValue 作精确字符串匹配。分组保持输入首次出现的顺序，不自动排序或推断业务口径。
4. 求和使用十进制定点整数，最多 30 位整数及 12 位小数。货币符号、千分位、百分比、指数、公式、空白和缺失值不自动转数字；默认拒绝空值，只有明确 blankNumbers=skip 才跳过并计数。需要明确口径时先询问用户。
5. UTF-8 TXT/Markdown 用 text_extract，可给 1 起始且两端包含的 lineStart/lineEnd。输出纯文字，不渲染 HTML，不据文件扩展名承诺 Office/PDF 理解。保留实际源行范围。
6. 结果和 processing-report-N.json 仅为私人产物；报告记录确切版本、输入摘要、配方版本和参数。不要将读取状态或模型回答当成计算证据。
7. 不支持格式、无效编码、CSV 损坏/歧义数字、缺失列及超限必须如实报告，不能静默截取后声称完整处理。当前没有 Office/图片/音视频处理配方；原件仍可保留和下载。

8. CSV 统计同时生成 table-summary-N.xlsx（汇总及来源/口径两张表）。它是计算完成的结果快照，不是可联动重算的模板，也不包含原表全部明细。超过 Excel 15 位有效数字的合计以文本保留精确值；分组/字段名始终为文字，不执行单元格公式。
9. Excel/JSON/处理报告仍为私人产物；CSV 统计向模型返回计算摘要和文件元信息，不回传这些文件的 Base64；文本提取保持原有正文可供模型使用的行为。网页使用现有成果下载入口；发布到企业需要另行明确授权，不由此工具自动执行。Excel 不可无损呈现的控制字符、过长换行组名或过大结果明确失败，不静默裁切。
