## 平台与引擎开发基线

现有 Demo 可继续单独启动。平台和引擎在 `apps/api/`、`engine/` 独立构建；契约在 `contracts/`。需要 JDK 21、Node 24.20.0、Python 3 与 PostgreSQL 18 的命令行工具（可通过 `POSTGRES_BIN` 指定目录），首次安装后执行：

```bash
npm ci --ignore-scripts --prefix engine
npm run build:engine
npm run setup:parser -- --with-tests  # 本地解析测试需 macOS、Poppler、Tesseract
npm run test:api
npm run test:identity:restart
npm run test:contracts
npm run test:engine
npm run test:conversations  # 需先 trial:build；独立临时环境，无模型调用
npm run test:foundation
```

`test:api` 与 `test:identity:restart` 分别在专用临时 PostgreSQL 验证身份权限与重启持久化。`test:foundation` 在临时数据库和临时端口启动平台、引擎与网页，使用真实浏览器验证连接、引擎停止后的错误与重启恢复，然后清理自己的进程；需要 Playwright Chromium。它不调用模型，也不导入企业资料。服务源码变更后先重新构建。临时数据库验证脚本当前在 macOS 验证；Windows 开发环境尚未验收。

手动开发先按[平台说明](apps/api/README.md)配置本项目专用数据库和 `local` 环境；再分别执行 `npm run start:engine`、`java -jar apps/api/target/workspace-api-0.1.0-SNAPSHOT.jar`、`npm run dev`。默认端口 18182、18181、5173，均监听本机；并行任务可配置独立端口。完整环境变量、命令与验证边界见 [M1-A1 记录](docs/交接/DEV-001工程基线与验证-2026-09-22.md)、[平台说明](apps/api/README.md)、[引擎说明](engine/README.md)。

### 本地备份与恢复（M7-A3）

已停止的本地实例可备份数据库与尚未物理清除的原件，还原到全新目录后先进入隔离状态。`reconcile` 核对独立当前权威实例的权限、删除和有效配置，仍不开放；显式 `activate` 再次核对后，才允许使用全新本地密码登录。旧密码、会话和待接受邀请不沿用，旧任务与计划不会自动重启。

```bash
npm run trial:stop
npm run trial:backup -- --output .local/backups/selfuse-20261001
npm run trial:backup:verify -- --bundle .local/backups/selfuse-20261001
npm run trial:restore -- --bundle .local/backups/selfuse-20261001 --output .local/restored/selfuse-20261001
python3 scripts/local/backup.py reconcile --directory .local/restored/selfuse-20261001 --current-directory .local/trial
python3 scripts/local/backup.py activate --directory .local/restored/selfuse-20261001 --current-directory .local/trial
npm run trial:start -- --directory .local/restored/selfuse-20261001
```

以上使用默认原实例 `.local/trial` 和独立密钥 `.local/backup-private/signing.json`；目录名每次换新。当前权威原实例必须保持停止且通过独立来源登记核验，旧快照不能为自己授权；缺少可靠当前证据时只能隔离还原。切换后保持原实例停止，避免两个业务副本同时使用。新凭据位于恢复目录的 `accounts.json`，只开放当前仍有效的身份与授权交集；正式离职/退出和已清理内容不能因恢复重新生效。

备份自真实快照创建起 30 日到期，复制和 `repack` 不续期；`python3 scripts/local/backup.py rotate --directory .local/backups` 显式清理已校验的过期备份，未安装自动轮转任务。备份含业务内容和密码散列、未加密，须与密钥分开保护。仅支持 PostgreSQL 18 的同版本本地恢复；迁移、表结构或已登记清理实现未被恢复适配器覆盖时拒绝开放。`npm run test:trial-safety` 与 `npm run test:backup` 使用独立合成环境；安装及构建要求沿前文。

[完整操作指南](docs/交接/本地三端试用指南.md#m7-a1-本地备份与新目录还原) · [当前恢复契约](contracts/local-backup/README.md) · [首轮历史验证](docs/交接/M7-A1本地备份与还原验证-2026-09-24.md)。本地恢复不代表生产灾备、在线切换、异地保存或容量/RPO/RTO 承诺。
