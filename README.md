## 已确认的产品主线

- 云端交付，多家企业共享基础设施，企业数据与任务隔离。
- 网页优先，同时覆盖目标电脑与手机浏览器；移动及桌面 App 后续开发。AI 会话的页面优先级至少与智能画报同级。
- 工作空间适用于部门、持续业务和具体项目，资料与成果在空间中积累。
- 资料修改记录与智能体工作状态整合为工作动态，按权限展示。
- 基础使用降低对 FDE 的依赖，深入落地通过实施与陪跑推进。
- 梦核引擎暂沿当前机制，会话与后台主动分析共用并按需调用；通过独立服务契约、构建和版本管理支持后续专人优化、独立升级。
- 云端工作为主，先支持草稿恢复和文件上传下载；云厂商和运行预算暂未确定。
- 首先本项目自用，随后 9POP 从管理者视角、群力从全员使用角度试点；跨部门协作和应用能力按实际场景细化。

## 本地运行

官网与最新 Demo 一起转发：见 [官网与 Demo 转发与启动](docs/交接/官网与Demo转发与启动.md)。在完整开发目录执行 `python3 scripts/package-website-demo.py`，会在临时目录构建最新工作台，再与现有官网合成 ZIP 输出到 `交付包/`。不覆盖官网或主项目的 `dist/`。收件方解压后运行 `node scripts/serve-website-demo.mjs`，默认打开 `http://127.0.0.1:4318/`，无需安装项目依赖。

发给同事体验：见 [Demo 转发与启动](docs/交接/Demo转发与启动.md)，内含可复制给对方 Codex 的提示词。转发包附带 `dist/`，可直接执行 `node scripts/serve-demo.mjs`（或 `npm run demo`）并打开 `http://127.0.0.1:4173/`，无需先安装项目依赖。仍需可用的 Node.js，浏览器个人数据不会随包传递。

在完整开发目录重新制作转发包：已有项目依赖后执行 `python3 scripts/package-demo.py`（需 Python 3），会先运行构建，再将网页、前端源码、测试、启动脚本和专用说明打包到 `交付包/`；不包含依赖目录、凭据、日志和内部商业文档。解压包不附带此打包脚本，收件方启动无需 Python。

使用 Node.js 22.12+，本次在 Node.js 24.20.0 验证。

```bash
npm run setup:git
npm ci
npm run dev
```

浏览器打开 [本地 Demo](http://127.0.0.1:5173/)。默认进入智能画报，底部可直接输入新需求；[智能画报](http://127.0.0.1:5173/#/briefing) 可直接体验本轮改版；[客户 A 会话](http://127.0.0.1:5173/#/chat/client) 可直接查看与 V2 视觉稿对应的会话和成果预览。

```bash
npm run build
npm test
npx playwright install chromium
npm run test:e2e:frontend
```

`npm run build` 执行 TypeScript 检查并生成 `dist/`；`npm test` 验证关键演示状态规则；浏览器测试覆盖实际页面操作，首次运行需安装 Chromium。可用 `npm run preview` 在本地查看构建产物。

演示数据只保存在当前浏览器，可通过“个人设置 → 重置”恢复。文本资料支持本地读取 `.txt`、`.md`、`.csv`，最大 500 KB，不上传到服务端。页面不向外部服务发送资料或会话内容。
