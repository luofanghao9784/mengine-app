## 2. 四端各自现状

### 2.1 workspace（员工端）

- **路径**：`/workspace/` ← `workspace/index.html` → `src/identity/main.tsx` → `AccessApp`（customer）
- **源码**：真实前端；页面在 `src/pages/`（Workspace、Conversation、Library、Briefing 等）；根 `/` 另有 Demo 演示内核（`src/App.tsx` / 空谷无界场景），**不是**第四端
- **与 agent-admin**：无直接关系；勿把空谷 Demo 迁进第四端（ADR-B8 D8-6：第四端全 Live，不挂 Demo）

### 2.2 tenant-admin（企业管理端）

- **路径**：`/tenant-admin/` ← `tenant-admin/index.html`；另有 `prototype/`、`governance/`、`support/` 子入口
- **源码**：真实；主壳 `src/admin/TenantConsole.tsx` + `AdminShell`；hash 键多为 `#admin=...`
- **风格基准（无页仿它）**：`admin-theme.css` 暖白日光、侧栏 `admin-shell`、导航折叠、移动菜单；动效/焦点见 `navigation-focus.ts`
- **与 agent-admin**：租户侧调试/配置/发布/本租户启停仍在此；**不写**能力登记（ADR-B8 D8-1）

### 2.3 platform-admin（总台）

- **路径**：`/platform-admin/` ← `platform-admin/index.html` → `PlatformApp` / `PlatformConsole`
- **源码**：真实；导航含 capabilities 等，但 A1「能力准入」**尚未实现**（路由对照待命）
- **与 agent-admin**：平台账号与授予 `AGENT_ADMIN` 仍在总台；A1 **整体迁入第四端**，总台只留外链（ADR-B8 D8-1）

### 2.4 agent-admin（第四端 · 统一 agent 管理平台）

- **路径（目标）**：`/agent-admin/`；API `/api/agent-admin/v1/**`（ADR-B8 D8-3）
- **目录现状**：**无** `agent-admin/index.html`；**无** `src/features/agent-admin/`；**无** `dist/agent-admin/`；vite input / `main.tsx` 白名单均未登记
- **「Demo 占位」含义**：预览健康检查对缺失入口打「留位」日志（见 CT-005 规格 `preview-health`）；产品侧「空谷无界」是员工端 Demo，**不是**第四端页面。本切片要把占位变成**可点开的壳 + 空态登记页**
- **职责**：平台级**模型能力 / Agent（实现）登记**——五维登记与生命周期唯一写入口；非店员聊天机器人
