# 总部支持访问实施记录

范围：[已确认需求](../产品/总部支持访问需求与验收-2026-10-04.md)。本目录 main 顺序实现，不创建开发 worktree；现有验收目录仅承载运行产物与数据。

## 已实现

- 总台企业概览提供系统调整/测试模式选择及「进入企业管理端」，企业需有有效负责人。进入后显示总部真实操作者和企业范围，可查看本次记录及返回总台。导航保留支持上下文，不替换客户登录。
- 支持上下文绑定平台会话和目标企业，复用企业端界面与服务端业务授权。按现任负责人实际权限判定，包括共享空间与私人内容边界；不增加成员，不改变负责人，专门交接/恢复不通过普通企业接口绕过。
- 请求结果与变更对象分别记录；变更前后仅保留标识、状态等安全字段，不保存凭据、正文、提示词、电话号码。测试对象可按支持上下文与原始对象编号追溯；业务写入、资料处理及队列仍保留实际总部操作者。支持上下文历史及记录提供总台只读接口，当前企业端弹窗展示本次记录。
- 资料上传/处理、检索、原件和导出下载、取数与经验后台处理绑定原始支持上下文。过期、退出、总部角色撤销或账号停用后不借用后来新建会话继续执行。暂停企业允许检查与配置，普通任务执行仍被拦截。真实调用沿用既有执行计量，不设置支持访问免计量分支。

## 验证

隔离 PostgreSQL + 真实 HTTP 集成共 105 项通过：总部支持、平台身份、管理职责、资料、取数、经验维护/队列及导出。补充修正无效进入参数后重跑总部支持 3 项并重新打包。测试使用合成企业、平台账号、客户账号和对象，无短信、供应商模型或外部通知。
