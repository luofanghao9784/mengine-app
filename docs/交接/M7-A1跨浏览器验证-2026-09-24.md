# M7-A1 三端跨浏览器验证

2026-09-24，M7-A1 第五切片，DEC-073；对应 POS-03/POS-06 和多端网页范围。本批将已有真实服务流程扩展为浏览器矩阵；不增加业务权限、收费调用或自动发布。目标平台真机仍单独验收。

## 运行方法

准备 README 所列 JDK/PostgreSQL/macOS 解析环境，再执行：

```bash
npm ci
npm --prefix engine ci
npm run setup:parser -- --with-tests
npm run trial:build
npx playwright install chromium firefox webkit
npm run test:browsers
```

默认依次运行三种浏览器 × 三组流程，共 9 组。各组独立账号、数据库和随机端口；运行结束清理自己创建的服务/数据。`npm run test:browsers -- --browser=webkit --journey=agent` 可按已发现问题定向复验；筛选结果不冒充完整矩阵。已有 `test:three-surfaces`、`test:operations`、`test:agent` 默认仍使用 Chromium 与原产物目录。

`scripts/browser-target.ts` 仅接受 chromium/firefox/webkit 白名单，矩阵禁止保留模式，不继承其他任务的 Docker 执行目标。每次启动先清理所属流程的旧成功报告；汇总记录 planned/passed/failed、浏览器实测版本与启动时间。报告和截图保存在 `.local/m7-browser/<browser>/<journey>/`，总报告为 `.local/m7-browser/matrix.json`。未加入未经授权的远端 CI 工作流。

## 证明范围

三端流程通过真实平台开通两个合成企业，邀请只投递本地 outbox。验证激活/登录/退出、成员与共享空间授权、跨企业/角色拒绝、撤权和停用恢复、原件及版本、真实解析/检索/固定引用、会话本地任务和草稿、丢响应幂等重试、重启保留、端口冲突不接管他人服务、跨标签页退出和桌面/390px 布局。

管理概览流程验证两端的权限、7/30 天范围、已知/缺失用量、当前错误类型、失败后重试、切企业时迟到响应及撤权清空。统计任务元数据为明确合成夹具，无真实供应商消耗。

Agent 流程通过真实 Harness、隔离代码计算、平台授权与原件处理，验证工具产物、固定 Excel 结果、画报关注/隐藏/尺寸与历史会话定位、文稿草稿/版本冲突、Word/PDF 导出、独立共享与版本更新、企业动态、撤权及下载拒绝。每种浏览器使用 34 次**合成模型 HTTP 响应**，不是 34 次云模型调用；公开搜索/网页/候选归档传输同样为测试夹具。真正运行的是平台、数据库、解析器、Harness、沙箱、浏览器及文件导出。

本批只调整测试入口和样例检查，没有更改产品页面或后端规则。脚本严格类型检查发现共享发布旅程中的参数 `document` 遮蔽 DOM 类型，浏览器检查显式改用 `window.document`；这不是声称修复了线上 DOM 故障。引擎、协议、依赖锁和数据库 V14 保持不变。

## 目标设备待验收

Playwright 的 Chromium、Firefox 和 WebKit 均运行于本地 macOS Apple Silicon；WebKit 自动化结果不等于 Safari、iOS 或鸿蒙真机已通过，390px 视口不等于实际触摸、软键盘或系统下载处理。

后续在 macOS Safari/Chrome、Windows Edge/Chrome，以及 iOS Safari、Android Chrome、HarmonyOS 实际浏览器中，用合成账号依次检查：

1. 邀请激活、密码输入/自动填充、登录、刷新、退出及跨标签页身份更新。
2. 窄屏导航、弹窗开关、中文输入法和软键盘遮挡、长内容滚动、横竖屏切换。
3. 从文件选择器/照片入口上传，查看解析提示、搜索并打开固定来源；失败时原件可下载。
4. 输入未发送草稿后刷新，模拟网络中断/恢复；不重复发送结果尚未确认的任务。
5. Word/PDF/Excel 下载、系统预览与另存，原 Office 修改后上传新版本。
6. 画报进入历史会话、文稿编辑保存与共享；用两账号核对私人内容和共享范围。

真机表须记录设备/系统/浏览器版本、实际操作及结果，不能直接复制本地自动化结论。客户材料、真实模型/WeKnora、云部署、生产隔离与容量也未因本批完成而验收。
