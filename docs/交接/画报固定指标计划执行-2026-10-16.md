# 画报固定指标计划执行

用户要求：选定已发布指标 → 执行固定计算计划 → AI 解读 → 交付画报。

## 实现

引擎每个任务尝试独立保存通过 task_context 校验的已发布执行计划。仅采纳 dataset_search/dataset_read 的结构化治理指标字段，校验指标、版本、数据集与快照四者一致；资料正文中的伪造计划不进入注册表。

模型调用 compare_dataset 时，只需提交 metricId、metricVersion、datasetId、snapshotId。工具按这四项从本任务已检索计划中取出完整计算参数，额外计算字段不改变该指标范围，工具说明明确披露此行为。现有后端仍复核指标发布版本、任务读取凭证、来源权限、数据快照与精确计划；计算回执仍经摘要、请求和结果结构核验，成功后才交付。未检索/无适用计划、版本变化、越权等继续拒绝，不自动选其他指标兜底。

每次尝试最多保留 64 个计划，任务间不复用；没有增加模型轮次或并发上限。普通无治理指标的数据集仍走原有受限计算。业务知识数字匹配开关与本次计算校验无关，本次不修改该开关。
