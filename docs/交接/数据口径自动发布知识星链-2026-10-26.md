# 数据口径自动发布知识星链

用户确认补齐“数据基座已有数据、知识星链为空”的缺口，Issue #133。本轮新增独立的自动数据知识流程；旧表治理任务禁止直接生成参考知识的限制保留，来源调查草稿也不能直接作为业务事实发布。

## 实现范围

企业显式启用后，后台每 30 秒检查已登记数据表，由当前企业负责人身份执行。仅处理当前有效的已发布治理版本：所有字段必须有 SOURCE_DOCUMENTED 解释和依据，且通过现有自动分析就绪核验（包括来源契约、逐批回执和已声明规则）。缺证、检查失败、来源撤下均不发布。

系统将已确认字段含义、单位、原依据与使用边界确定性整理成“表名 · 已确认业务口径”，保存独立知识文稿，再核验正文摘要与来源版本后发布。本轮不调用模型、不生成未经计算的经营发现；正文没有原始业务记录。数据业务知识与文件学习文章分别存储，知识星链统一呈现。

V174 新建 `dataset_knowledge_publications`，保存来源表、治理版本、初始快照、正文摘要和 DRAFT/PUBLISHED/STALE 状态及时间。相同表和治理版本唯一，不因重复定时检查或仅更新记录而重复发文。新治理版本替换旧版本的有效性；失败状态保留旧文供追溯，恢复有效依据后复用原文章。

读取时仍逐项检查当前企业、来源权限、治理版本及本批核验结果，不等下一个调度周期才撤回可见性。普通获权读者可以读取，不能调用自动发布服务；服务端要求当前企业负责人。权限撤销、企业背景变化、来源失效或本批异常都会停止展示相应知识。

## 本地启用

本地私有 `.local/trial/automatic-dataset-knowledge.json`：

```json
{"tenantIds":["获准企业UUID"]}
```

文件权限 600。启动器传递 `AUTOMATIC_DATASET_KNOWLEDGE_TENANTS`；缺省不启用，恢复测试快照时忽略该配置。此次只启用美租本地企业，保持原账号、数据库和模型配置；未部署生产。无需新增 cron，知识流程不额外调用模型。

## 验证

- 后端 `NativeAutomaticContinuityIntegrationTest`：18 项集成测试，覆盖原自动分析链路，以及自动知识发布、重复执行和换批复用、异常批次立即隐藏和恢复、背景变化失效、跨企业拒绝、读者撤权与发布资格。
- 本地启动器：18 项测试，含显式企业名单、私有权限与恢复时禁用。
- API Maven 构建和 `npm run build` 通过。
- 本地 V174 迁移成功；2026-10-26 20:24（北京时间）自动发布 **财务-流水账 · 已确认业务口径** 1 篇，后续多次后台核验仍为 1 篇。
- 实际账号读取知识接口、浏览器进入知识星链并找到该文章通过，无页面脚本错误。其余五张表的待确认字段没有被当作已核实知识发布。

后台配置开启只授权这里定义的已确认口径整理，不等于所有表完整业务批准；自动经营洞察、完整知识图谱和文件学习策略不因此宣称完成。

## 回退与交付

代码走任务分支与 PR，由另一位维护者审查合并。备份在本地私有 `automatic-knowledge-rollout` 目录，包含改动前数据库备份；不提交业务数据。停止自动处理可删除私有启用配置后重启原本地服务，历史知识保留、读取继续核验权限和来源；代码回退可运行旧版本，V174 为新增表，无需破坏性回滚数据库。
