## 交付

个人文稿选择固定版本、目标共享空间/文件夹及 Word/PDF 格式，确认后形成独立企业资料；后续个人编辑不自动同步。明确更新同一企业条目时检查企业当前版本，保留历史文件与来源映射。维护权限与读取权限分开，共享接口只给版本来源类别，不公开私人文稿、原会话及来源空间 ID。

V13 增加租户/私人所有者/固定源版本/目标版本复合约束、发布回执及去重；文稿和资料 API 1.1.0。原件上传与发布共用持久版本实现，引擎 0.8.0 / Agent 1.4 不变。页面复用现有按钮、表单、弹窗、目录导航、分页与样式。

后端覆盖：独立副本摘要正确；只有目标权限的读者能够下载，但不能读取私人文稿/发布记录；来源撤权、发布者成员与账号停用不影响副本；读者目标撤权拒绝；同请求键重放/异键重复/并发发布只落一次；键内容冲突；权限降为只读后重试拒绝；目标撤权后私人发布历史过滤；个人修改不改变企业资料；明确更新保留旧文件、固定实际目录；版本冲突无新增企业版本/发布行；错误租户、个人目标、未确认、无维护权及不存在目录均拒绝。

浏览器脚本在既有私人文稿流程后创建真实共享空间、邀请合成同事并授权。发布人维护授权仅在脚本所拥有的一次性数据库内初始化；脚本检查本机地址、专用测试库/用户和临时存储目录，不连接用户试用库。此项测试夹具不表示管理员自授权业务规则已经开放。其余邀请、授权、发布、读取、上传和撤权通过真实 HTTP 接口完成。

浏览器验证包含：发布前明确确认；后台已成功但响应中断，原键重试且只产生一个文件；企业副本经过真实 DOCX 解析达到 READY；只读同事的详情显示“文稿发布”且无更新按钮；共享响应不含私人来源 ID；私人修订不自动更新；普通上传抢先产生 v2 后，旧 v1 发布预期失败；重新核对 v2 后明确发布 v3，v1 下载仍一致；异键重复更新返回已有回执；目标撤权后旧链接 404；发布者撤销自身目标访问后，刷新清除发布历史及缓存成功回执，私人文稿仍可编辑。CSRF、注入所有者字段、未确认发布及总台访问私人历史均拒绝。

截图和结果位于本工作树 `.local/m4-agent/`，不提交运行日志/合成账号会话。视口验证不等于 iOS、安卓、鸿蒙真机或原生 App 验收。DOCX/PDF 渲染器没有改变，沿用前一切片的独立阅读器检查；本批验证实际副本的字节摘要、解析与下载。
