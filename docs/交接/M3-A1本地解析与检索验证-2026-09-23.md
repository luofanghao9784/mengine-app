# M3-A1 本地解析与检索验证

2026-09-23，基于 M2-D1 提交 `d802316da4003f0aaccc4cff1e931f61f4faa010`，分支 `codex/platform/M3-A1-knowledge`。只处理新建本地测试库的合成文件；此前各任务目录、数据库和端口不变。用户确认先完成本地能力；未调用云模型、未导入客户数据、未发邮件、未部署或合并主线。

## 交付范围

新增 V6 解析任务/片段持久化、独立 `DocumentParser`、本机 macOS 沙箱解析器、内容关键词检索、固定版本引用及前端预览。原件仍由平台持有。解析记录保留状态、批次和通用警告；HTML/公式/宏不执行。格式、资源限额、授权与 WeKnora 未完成项见[实现边界](../技术/M3-A1本地解析与WeKnora接入边界.md)。

新增约束后另跑 KnowledgeIntegrationTest 10 项定向回归：省略 expectedGeneration 返回 400，只读成员带有效 CSRF 的解析请求返回 403；检索查询有执行时限。中文 OCR 初测发现混合语言会误判汉字，调整为中文优先后复测通过，结果仍标记 PARTIAL；合成样例仍可能把“梦”识别为“药”，不承诺识别正确率。

桌面解析预览与手机引用截图已检查；结果和截图保存在忽略的 `.local/m3-a1/`，不把私有账号或原件加入 Git。全部浏览器测试使用合成账号，密码只在当前工作树 `.local/trial/accounts.json`。

## 试用与后续

本分支的 `npm run trial:start` 可启动独立保留环境。以 `member` 账号登录客户端，选择合成企业 B，在个人资料根目录打开“梦核解析验收.csv”，点击“查看 v1 解析”；也可用“搜索内容”搜索 `00123.4500`。另有未知格式样例和前序资料历史版本。

这是 M3-A1 的本地切片验证，**不是完整 M3 / WeKnora / Agent 验收**。WeKnora 仅锁定官方版本并核对 API/许可，服务和模型未配置；远程适配、真实语义检索、删除回收、规模性能、Linux 执行器以及目标设备验收仍待后续。真实会话和画报未接入。M4-A1 可以基于当前统一资料接口继续推进。
