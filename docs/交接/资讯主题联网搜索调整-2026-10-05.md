# 资讯主题联网搜索调整

## 用户确认与流程

沿 DEC-120、AI-11—AI-13、DASH-01—DASH-04，用户确认资讯按关注主题实时联网查询，并授权调整生成链路及评估当前网络可用的搜索服务。本轮覆盖此前「必须先选网站」的实现前置条件：总台目录改为补充来源，企业不选网站也能查询。

任务先在授权范围内读取企业、空间背景及有效个人偏好；模型选取一个平台授予的公共主题 ID；服务端固定并记录其公开查询短语；联网搜索后读取原文，核验日期、去重及相关性，再进入既有画报选题与交付链路。搜索为空、原文不可读或没有新增价值时不能编造新闻。偏好与私人材料只能影响主题判断及卡片内容，不能把企业名称、人员、原始资料或经营数字拼入外部查询。

## 实现与约束

- V94 固定任务的搜索策略快照、补充网址及实际查询记录；每任务最多选择两个公共主题，重复选择同一 ID 幂等。来源撤回、成员/空间撤权、服务暂停或关闭搜索仍受每步授权约束。普通会话继续只搜索用户明确填写的固定公开词，模型不能替换。
- 首版提供 16 类发布随附的公共主题，如健身体育、运动安全、教育、健康、零售、制造及企业经营。模型结合背景选择类别，支持范围不是任意自由查询；地区细分、更多行业词和企业明确许可的公开词扩展尚未实现，不假称各类私人偏好都能变成搜索词。
- 资讯无需上传企业资料；若已有材料则仅固定就绪版本作为补充上下文。不相关的旧「等待资料」请求不能挡住新的资讯请求，已有执行任务仍优先恢复与核对。资讯自动调度沿既有规则；当前验收实例继续关闭自动付费生成。
- 支持替换的 SearXNG JSON 接口及 Bing 公开资讯 RSS 适配器。Bing RSS 是已验证的公开入口，非有 SLA 承诺的商业 API；未来稳定服务可替换适配器。搜索摘要不当作已读原文，Bing 跳转包装只用于提取原网站 HTTPS URL。
- 每批最多读取两篇原文、检索最多三条候选；补充网站在候选不足时提供同站点文章。显式日期超过 30 天的过滤、未知日期说明、URL/正文摘要散列去重沿现有实现，不宣称跨媒体事件语义去重或全网覆盖。
- 新闻搜索在当前本机直接请求会重定向到中国区首页；百度 HTTPS 入口返回要求降级 HTTP 的页面，本轮没有执行降级。验证可用路径为本机现有回环代理与 Google 公共 DoH，所有连接固定到已验证的公网 IP，TLS 仍校验原主机；拒绝私网 DNS 答案、非回环代理、代理凭据及任意工具网址。DoH 仅发送公开网站域名，使用 `edns_client_subnet=0.0.0.0/0`。协议依据见 [Google DoH JSON 文档](https://developers.google.com/speed/public-dns/docs/doh/json)。

## 配置与验证边界

生产式环境通过 `AGENT_PUBLIC_WEB_ENABLED=true`、`AGENT_NEWS_SEARCH_PROVIDER=bing-rss|searx` 配置。SearXNG 另需 `AGENT_SEARCH_ENDPOINT=https://.../search`；本机可显式设置 `AGENT_PUBLIC_WEB_PROXY=http://127.0.0.1:7897` 和 `AGENT_PUBLIC_WEB_DNS=google`，不继承 shell 代理或密钥作为隐式授权。本地启动器将实例私有 config.json 的 publicSearch 配置一致传入 API/引擎。

本轮真实公共网络验证返回 3 条近期资讯，并读取到一篇原网站正文（838 字符），未调用付费模型。引擎 20 项合成检查覆盖 RSS 转义、原网址、主题枚举、防泄漏、原文去重、私网地址、代理 CONNECT 固定 IP、DoH 私网拒绝、搜索前服务端登记及真实 Harness 工具调用流程；本地启动配置 17 项检查及浏览器 7 项合成检查通过。API 57 项回归包含主题查询的权限、两主题限额、重复登记、无资料运行、旧等待不阻塞、补充源撤回及既有生成/总部支持流程。全部通过。

54803 已受控更新 API、引擎、启动路由配置和来源说明文字；数据库、旧 jar、运行引擎、目录及实例配置均保留私有备份。客户端资讯标签已可选，未提交真实付费画报任务、未重置额度，既有人工费用验收开关保留。真实模型的资讯卡质量、三层偏好对具体新闻的选择效果及自然定时运行仍需独立验收。
