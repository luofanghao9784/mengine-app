## 本地配置预检（不调用模型）

本分支引擎 `0.10.0` 新增百炼适配。环境示例仍默认 `off`；没有默认 Key、模型、自动路由或收费回退。命令需在已安装 Node/引擎依赖的项目根目录执行，例子适用于 macOS 的 zsh：

```zsh
export AGENT_MODEL_PROVIDER=bailian
export AGENT_BAILIAN_WORKSPACE_ID='替换成梦核业务空间ID'
export AGENT_MODEL_NAME=qwen3.7-plus-2026-05-26
read -rs 'AGENT_MODEL_API_KEY?粘贴梦核专用 API Key（不回显）: '
export AGENT_MODEL_API_KEY
npm run model:check
```

用隐藏输入避免把 Key 明文写进 shell 历史。不要运行 `env`、`printenv` 或开启 `set -x` 来回传配置。环境变量仅保留在当前终端及其子进程，关闭后重新配置。

`model:check` 仅检查结构和已适配模型：成功输出 `configured`、provider/model/region、`modelRequests: 0`、`liveVerified: false`；不回显 Key 或空间 ID。不访问百炼，不能证明 Key 有效、模型已开通、余额足够或答案质量合格。退出码：0 配置合法；1 关闭；2 配置不合法。

预检结束且暂不启用时：

```zsh
unset AGENT_MODEL_API_KEY
export AGENT_MODEL_PROVIDER=off
```

普通 `npm run trial:start` 继续清理模型环境并保持本地模式；不会因为终端中设置了这些变量就偷偷调用云模型。

## 下一轮真实验收

用户另行决定启用真实调用、且账号和预算到位后，先记录待测模型快照、官方当前计价、输入/输出上限、最大请求数和累计预算，再创建独立临时 live 环境。平台须显式开启 `AGENT_TASK_MODE=live`，引擎配置百炼并设置可信平台地址，双方使用同一内部任务密钥。预检和模式开关不能代替费用控制。

首轮分两步：先验证单次文本调用、真实用量、超时和取消；再以小批合成任务验证“上传资料 → 固定来源检索 → 千问工具调用 → 有依据的回答 → 画报/个人文稿”。分别记录来源准确率、工具选择与参数、拒绝越权、失败提示、延迟及费用，明确展示真实调用状态。

live 当前开放授权检索和可信能力发现，不开放任意代码执行、候选安装或完整原件处理；这部分仍需云端隔离验收。当前任务不会投影全部历史会话，模型的长上下文不能替代应用上下文管理。

首轮通过后再比较 Flash/Max 分工，决定是否需要扩展推理模式、长任务时限或语义检索。WeKnora 实机、真实搜索服务和后台主动调度按各自模块继续，不因百炼接通而记为完成。
