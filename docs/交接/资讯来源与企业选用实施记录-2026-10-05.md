# 资讯来源与企业选用

## 授权与范围

用户授权按「可用性 → 最小真实采集 → 来源管理与个性化 → 自动运行验证」顺序实施，随后要求不同企业使用不同来源。本实现不默认替所有企业指定同一组网址。总台维护公开来源目录；企业管理员在企业信息选用来源；个人沿已有三层选题规则影响资讯筛选，不通过偏好文字扩大联网范围。具体真实验收来源仍等待用户确认。

## 本轮实现

- 总台引擎管理新增「资讯来源」，维护名称、公开 HTTPS 地址、网页/RSS/Atom 形式、行业、地区、启停及版本；新建请求编号固定，重复新建返回原记录。企业信息增加独立「资讯来源」标签，仅负责人范围可选用/取消选用。修改与选用分别审计，跨企业不可维护。
- 来源不是自动写入企业背景的业务事实，行业/地区只是人工维护的来源说明。此版由企业明确选用，不宣称自动判断网站可信度或自动批准企业提交的网址。
- 资讯能力由企业实际选用的启用来源与平台联网开关共同决定；状态接口返回 INFO 可用性，客户端不可用时禁选。服务端拒绝新的不可用请求，整次多类型确认原子拒绝，不占预留额度。旧未执行资讯等待结束为 FAILED，保留原因和历史，释放预留；已有任务仍通过现有权限、费用与回执流程管理。
- 资讯任务按批次稳定选择企业已选来源之一，不把内部资料或经营数据生成外部搜索词。取消选用/全局停用后，每步授权检查阻止在途任务继续读取及提交。保留空间资料/数据就绪的既有前置条件，不自动扩大为只凭企业背景生成。
- 引擎从页面文章链接或 RSS/Atom 发现最多 3 个同站点候选，读取最多 2 篇正文；DNS、公网地址、重定向、响应体大小和时间限制复用原读取器。XML 禁止实体/DTD；页面允许标准 HTML doctype。未实现登录网站、JavaScript 渲染页面、跨域订阅正文或通用网络爬取。
- 公布日期来自订阅或页面显式 metadata，检索时间独立记录；拒绝未来异常日期，过滤明确超过 30 天的候选。未知日期保持未知，阅读来源明确显示未核实；30 天是可替换的首轮技术窗口，不是用户确认的各行业时效标准。
- 成功资讯任务保存本人/企业范围下的原文 URL 和正文片段 SHA，后续相同 URL/内容跳过，正文改变可重新候选。使用有界正文摘要，不能把它称为跨媒体新闻事件的语义去重。来源目录显示该来源最近任务状态及时间，不包含企业私人正文。
- 沿用任务固定的企业/个人表达、选题规则快照，以及自然定时触发、既有用量记录和无新内容交付。不能用新增目录或合成验证声称真实资讯质量已经验收。

## 验证与剩余验收

API 52 项隔离 PostgreSQL 回归（43 项生成回归、4 项来源测试、5 项总部支持测试），覆盖权限、版本、企业选用、停止来源、在途授权撤回、旧等待释放和创建幂等。引擎 14 项合成测试覆盖 RSS、Atom、HTML、日期、原文去重、SSRF、公开查询固定及真实 Harness 工具流。浏览器 7 项合成检查覆盖生成交互、资讯禁选及总台来源创建。三层规则效果沿用既有快照链路，本轮未完成多企业/个人真实资讯对比。

真实来源、真实出卡、自然定时运行、来源质量、跨媒体同一事件语义去重、来源健康的独立周期探测及企业提交新来源审核，均未宣称完成。真实采集尚待确定首批来源；真实模型调用需确认当前费用授权余量。本轮不重置每日额度，不默认开启所有企业联网生成。

XML 解析使用锁定的 fast-xml-parser 5.11.2；其声明及上游许可依据见 [官方仓库](https://github.com/NaturalIntelligence/fast-xml-parser)。生产依赖许可随引擎 THIRD_PARTY_NOTICES 一起分发，未随 npm 包提供的许可单独保存上游固定提交及 SHA。

## 本地安装检查

本轮受控更新 54803 验收实例的前端、API、引擎与 V93，更新前保留数据库、运行 jar、前端和引擎备份。总台「引擎管理 → 资讯来源」及总部访问模式下「企业信息 → 资讯来源」均正常读取；客户端类型步骤中的资讯显示「未接入」且禁选。未新增企业来源、未发起模型生成、未重置额度。总部选用操作保留真实总部操作者及企业范围的前后状态留痕。
