## 手工试用

以下为手工试用入口，本轮未启动常驻试用实例；自动验收使用上方独立浏览器脚本。完成 `npm run trial:build` 后，在本工作树运行：

```bash
npm run trial:start:phone
```

该命令显式开启合成短信，使用独立 `.local/phone-trial`，不读取 `.local/selfuse-live` 或其他工作树资料。首次总台初始化仍由已有受控 CLI 完成；在本实例私有 accounts.json 查看初始账号后，通过页面“原邮箱账号迁移”绑定合成手机号。客户端、企业端和总台日常均使用手机号；绑定完成后原账号文件内的邮箱不再能登录该账号，旧密码仍有效。

总台开通企业时填写受邀手机号，生成后点击“查看本地邀请链接”；在另一个浏览器会话中打开。点击“获取验证码”“查看本地测试短信”，用显示的合成验证码完成验证。不要把这些操作描述为真实短信送达或真实手机所有权验证。

```bash
npm run trial:status -- --directory .local/phone-trial
npm run trial:stop -- --directory .local/phone-trial
```

停止保留本实例数据。再次启动测试必须继续显式使用 `trial:start:phone`；普通启动默认不启用测试短信。未准备真实短信服务时，不得将其作为公网账号服务发布。
