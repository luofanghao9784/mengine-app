# 画报推荐查询超时修复（2026-10-13）

沿 AI-11—AI-13、DASH-01—DASH-04，用户要求修复现有官网系统登录后画报空白/报错。当前主目录 main 顺序实施。

## 原因与修复

2026-10-12 23:32—23:46（北京时间），线上 `/recommendations?offset=0&limit=20&generatedOnly=true` 多次 500，数据库对应 `statement timeout`。接口查询上限为 3 秒；新资料权限启用后，旧 SQL 反连接把权限函数用于大量无关资料，111 个任务的只读采样触发 8,780 次文件权限计算。画报候选列表还提前检查全部本人历史任务。

- V122 将任务依赖版本先解析为实际、有效的来源资料，再逐个执行原 `library_mask`，相同资料去重。缺失版本、跨企业、回收资料、递归依赖及下载禁止继续拒绝，不缓存权限、不放宽超时。
- 推荐列表先物化成功任务与真实画报资格，再通过 `readable_source_tasks` 逐项授权。保留该视图的所有条件（包括本地主线后续 Wiki 约束），首条任务标题按原本人/本企业及可读条件单独检查。排名、分页和来源事实不变。

## 验证与发布范围

- 线上只读原查询：仅本人历史任务可读集合即约 3.09 秒。
- 线上数据副本在隔离数据库验证：111 个任务的可读/可下载布尔结果差异 0；完整画报候选 15 条，修复前后逐列集合相同；优化后隔离库完整候选查询约 50ms。该耗时不是线上验收结果。
- 本地主线相关 48 项测试通过。新增取消历史不应消耗推荐授权检查的回归，在旧推荐代码上失败、修复后通过；新增文件级撤权、下载禁止及跨企业来源检查。
- 基于线上 API 基线 `e61ceb8193b5d5b83ff3594289ea356882bca018` 构建限定源码快照，只覆盖 RecommendationService、新回归测试及 V122；历史迁移以线上 JAR 清单为准。限定快照同样通过 48 项测试与打包。
- 新 JAR 仅 RecommendationService 及其嵌套 PublicationPreference 类字节变化（源码行号随外层改动变化），新增 V122；没有其他产物删除或变化。前端、官网、引擎、后台开关均不在发布范围。

本机证据 `.local/briefing-fix-20261013/`，含受限数据库副本、执行计划、等价核对和测试日志，不提交数据或产物。上线结果完成后追加。
