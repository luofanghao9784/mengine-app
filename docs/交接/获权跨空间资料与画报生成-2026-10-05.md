# 获权跨空间资料与画报生成

用户确认：公共资料应可供不同空间调用；同一用户拥有多个空间阅读权限时，可以跨空间使用资料生成画报或处理会话。沿现有资料权限体系实现，不另建公共资料存储，不自动增加人员授权。

## 规则

- 资料仍归属原空间；“企业公共资料”使用普通共享工作空间，对需要使用的人授予阅读权限即可纳入其检索范围。本切片不创建空间、不改变成员权限；全员动态授权的管理入口另行实现。
- 普通客户端会话已默认使用 AUTHORIZED_LIBRARY：当前企业内本人可读的共享资料和本人个人资料可参与检索。其他人的私人附件、会话历史和个人空间不可读取。显式“只用所选资料”、计划及旧 WORKSPACE 任务保持原限制。
- 系统画报候选资料池扩展至同一企业内本人当前可读的资料空间，包括普通公共资料空间。每批仍选最多三个固定文件版本或数据快照，优先覆盖不同来源空间，不代表扫描或统计全企业资料。
- 归属空间不变：企业/本人/归属空间的目标与偏好决定背景，实际参考资料可以来自其他获权空间；跨空间读取不会修改来源、扩大共享发布权限，也不会将其他空间的私有会话历史纳入上下文。
- 文件解析 READY/PARTIAL 才参与选择；跨空间尚未解析或失败资料不阻塞其他已就绪来源。新文件解析就绪后可参与后续选题。
- 数据库的固定快照选择允许不同来源空间，但要求真实系统画报批次、同企业、本人当前源空间权限、SELECTED 模式和 QUEUED 状态。普通所选资料任务不会因此获得数据集访问权。
- 检索、读取、计算与成果查看继续复查实际来源权限、撤权、来源失效和固定版本依赖。个人可读不代表可直接公开到企业公共空间。
