# 客户端六批统一验收指南

本次一次验收 B1—B6。重点沿正常工作完成一整条流程，再检查计划、偏好和待办。自动检查证明机制与权限，真实资料的分析质量、操作习惯由本次人工验收确认。

## 1. 进入原工作空间

地址仍为 http://127.0.0.1:55167/workspace/ 。升级后第一次做一次**浏览器整页刷新**以加载新前端；此后的页面内刷新只更新数据，不重新运行任务。

短信尚未启用时，点击「原邮箱账号登录」，使用原来的邮箱和密码。账号、所属企业、原有资料和会话继续保留。不要使用 Demo 首页做真实验收；这次不需要测试新用户短信加入或绑定。

确认主导航是会话、智能画报、资料库。普通进入默认为智能画报；已有具体链接或中断位置时优先恢复原工作。更多入口中有我的计划、工作空间及本人获权管理入口；头像中有我的档案与偏好。客户端不展示经验库。

## 2. 带资料完成一次工作

1. 打开会话，输入：**只用所选资料，总结这份文件的关键事项，标明依据和无法确认的内容。**
2. 点「添加资料 → 本地上传」，选择一份有权交给模型处理的小型 TXT、DOCX 或 XLSX。也可以拖入文件或选择资料库已有文件。
3. 等待「已准备」。点文件卡查看正文，再点属性按钮：属性以另一张卡出现，关闭属性不应关闭正文。此时尚未发送，不应出现正在执行的任务。
4. 整页刷新一次，确认文字与文件引用仍在。勾选「只用所选资料」，发送。
5. 检查真实执行状态、结果与固定版本引用。再开一次普通提问，确认无需每次手动选择工作空间；必要时可在当前企业本人获权资料中检索。此时可切换其他页面，后台任务不应锁死导航。

上传的文件先保留在本人私有会话，不自动进普通资料库。需要长期查找时从文件属性卡「保存到个人资料库」。准备失败应提供重试；未解析完整不能当成完整读取。

## 3. 保存、查找与共享成果

1. 任务完成后点「保存到个人资料」，确认保存回执出现且仍在原会话；点「查看资料」打开成果卡。
2. 通过「编辑与导出」修改个人稿并导出，核对内容和版本。
3. 在属性中明确选择一个自己有维护权的共享空间，将指定版本发布为企业副本。没有维护权限时不应有可成功执行的发布路径。
4. 回资料库，个人资料中的上传文件和已保存文稿在同一个列表。用名称或正文关键词搜索；进入目录后搜索覆盖该目录及子目录。
5. 修改个人稿后，到共享空间查看：企业副本不应自动变化。显式发布新版本后才更新；再读旧版本仍应对应旧内容。
6. 从资料卡「继续会话」，确认文件及确切版本已准备好，已有未发送草稿不应丢失；用户发送后才执行。

没有可共享的目标空间时，可以先完成个人保存与导出，再用现有获权空间检查共享步骤，不为验收临时扩大成员权限。

## 4. 智能画报与后续处理

在会话请求生成有独立价值的主题画报，例如：

> 根据这份资料生成一张洞察画报：说明主要发现、业务影响和不确定项。

数据画报用含明确两期数据、指标和单位的 XLSX，例如：

> 根据所选经营表，对比九月与十月销售额，生成数据画报，展示各门店对比、变化率与完整分析；缺失数据说明原因，不作零处理。

1. 到智能画报，检查「资讯、数据、洞察、建议、成果」类型筛选和空间筛选。不会给原有无类型回复硬贴标签；它们仍在原会话中。
2. 打开详情，检查标题、正文、来源和生成时间。当前真实计算配方为 XLSX 两期比较，图表为分组条形图及完整数据表；复杂趋势、任意指标或来源不完整时不能假装已经支持。
3. 点有用、没用并选择原因，或提交具体改进建议。确认回执、关注/取消关注实际生效；关注不会自动建立计划。
4. 在关注视图检查原有会话卡顺序和宽度调整；共享企业副本也可关注。只有明确发布的企业副本可站内转发给已获权同事，私人会话结果会先引导保存和共享。
5. 从详情点「继续会话」，输入追问。系统自动携带当前内容上下文，无须另填上下文配置。退出会话回原背景页，不应重新弹出已关闭详情。

首次生成的内容质量由真实模型决定。页面刷新只读取已经成功生成的画报；普通问候、失败任务或没有独立生成回执的回复不会自动成为新画报。

## 5. 计划、偏好与待办

- 在会话明确委托：**未来3天，每天09:00根据个人资料整理销售简报，只给我在系统内查看。** 成功后必须有真实计划卡，并能在「更多 → 我的计划」查到。首版支持每日/资料变化，默认每天最多一次；缺关键条件时应只补问缺口。
- 继续说「把销售简报改到晚上八点」「暂停销售简报」「恢复销售简报」「关闭提醒销售简报」。分别检查时间、计划状态和提醒状态。暂停/停止会中断在途工作；取消某次任务不等于关闭持续计划；关提醒不等于停止执行。验收结束不再需要的计划请停止。
- 表达临时要求「这一次回答简洁一些」，不应自动建立长期偏好。再说「请记住，以后回答简洁一些」，检查保存回执、撤销入口和个人设置中的有效偏好；撤销后新任务不再采用该条。
- 画报顶部有真实待办时，默认最多两排，可展开或全部收起并记住选择。进入原事项处理后返回，页面刷新应同步状态。仅打开不算完成；正常等待和经验维护不列为首版待办。

## 6. 记录问题

遇到问题记录：所在页面、刚做的动作、预期、实际结果，尽量附截图或任务标题。优先记录登录阻塞、内容不可读、结果/版本错误、草稿丢失及权限问题。不要在反馈中发送密码、验证码或 API Key。
