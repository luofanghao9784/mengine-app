# 资料库工具栏与账户入口（2026-10-02）

## 用户确认范围与实现

- 企业名称、企业切换和管理端入口移入左下角“个人设置与账号”弹窗；当前企业明确标记，多企业账号可选择切换。管理端保留同页切换与新标签页入口，沿用现有权限、企业与返回路径规则。
- 个人空间、企业资料库根目录不再重复显示路径名称。进入共享空间、子文件夹或“全部资料”后保留路径导航。
- 搜索简化为单一输入框，支持回车、放大镜提交及清空。继续搜索名称与正文，搜索范围及服务端权限不变；清空同时重置结果与分页。
- 资料库整条工具栏在内容滚动区域顶部吸顶；窄屏下路径与操作合理换行，视图切换始终可用。
- 与本地 Demo 滚动渐变整合：渐变移到工具栏下沿，避免遮盖或模糊固定的搜索控件；回到顶部后隐藏。

实现位于 [AccountWorkspaces](../../src/identity/AccountWorkspaces.tsx)、[LibraryToolbar](../../src/material/LibraryToolbar.tsx)，并接入 [AccessApp](../../src/identity/AccessApp.tsx) 与 [Library](../../src/material/Library.tsx)。
