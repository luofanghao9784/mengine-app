## 浏览器与合成数据

`test:operations` 自建两个合成企业，通过真实邀请/登录/API 操作，并仅在一次性测试数据库中加入确定状态的任务元数据，用来核对聚合数字和异常分支。这些 live/verification 行均为**明确合成夹具**，未调用真实模型、Harness 或供应商，不以页面中的用量字段冒充云模型验收。后端另以真实任务服务验证状态转换和重复请求。

真实 HTTP 响应逐项符合 Operations 契约，禁止内容/私人标识，响应不缓存。7/30 天切换、Token 未上报/部分覆盖、没有成功 Agent 任务、503 后重试恢复、跨企业响应拒绝和权限失效均有浏览器证据。企业 A 请求延迟返回，切到 B 后释放旧响应，B 的数值保持不变。没有浏览器未捕获错误。

总台、企业桌面及 390px 窄屏截图位于 `.local/m7-operations/`，已目视检查；窄屏没有页面横向溢出，当前异常下半段单独截图检查。页面共用现有标题、按钮、主题和面板，不改变工作客户端。模拟视口不能替代 iOS/安卓/鸿蒙及桌面目标真机验收。

## 发现与修正

新接口最初遗漏统一错误处理注册，非法范围被映射为通用 500；已接入现有 IdentityErrors，并明确私有无缓存响应，400/401/403/404 与前端提示验证通过。测试夹具修正了资料详情参数，HTTP 测试隔离了前序登录压力用例在一次性数据库中留下的节流桶，没有放宽产品登录限制。一次全量回归的既有撤权用例发生 HTTP 超时，随后完整重跑 156 项通过。截图路径使用 fileURLToPath 处理中文目录，并禁用截图期间过渡动画以核对最终选中状态；临时输出不提交。
