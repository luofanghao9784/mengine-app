## 运行与检查

在主仓库目录安装并启动：

```bash
npm ci
npm run dev -- --port 5194
```

统一验收入口为 `http://127.0.0.1:5194/#/briefing`。继续使用同一浏览器与端口以保留已有本地数据，不需重置。其他历史 worktree 的预览不是集成基线。

```bash
npm run build
npm test
npm run test:git
CI=true PLAYWRIGHT_PORT=5198 npm run test:e2e:frontend
```

## 同日补充：推荐自动补位、关注自由整理

用户确认推荐不可手动移动或调大小，并需自动补齐中间空位；关注允许移动和调整大小。推荐保留正在跟进／为你推荐／已读分组，组内优先选择原尺寸可填入的卡片，必要时临时适配默认尺寸，取代严格按数组顺序占格造成的孔洞。最后一行按剩余内容自然结束。

关注整合为一个“我的关注”区域，允许不同类型卡片互换位置。桌面拖动卡面、右下角缩放，触屏长按进入整理，右上角完成退出；键盘 Alt+回车拿起卡片、方向键移动、回车放下，聚焦缩放控件后可用方向键调整大小。Esc 取消未提交调整；保存后可撤销，也可恢复自动排列。普通点击仍打开详情。此处沿用四档网格尺寸，是本次前端实现选择。

布局和明确尺寸保存在当前演示身份的独立关注偏好中，不改写原卡配置、内容版本、历史快照及推荐／日期／类型／空间布局。窗口缩窄仅投影显示，刷新和回到关注保留偏好；旧布局存储保留但不自动迁入本次关注板。

本轮本地验证：构建、78 项单元检查、9 项 Git 钩子检查、格式和差异检查通过；30 项浏览器用例分批通过，包括 3 项自动补位、4 项关注布局，以及 23 项详情反馈／会话／杂志展示回归。覆盖 320—1440px（含批注中的 927px）、鼠标、键盘和模拟触屏；当前 5194 预览实测三组推荐均无中间空位，关注显示独立缩放入口。真实触屏手感仍由用户前端验收。

## 同日补充：卡片悬浮抬升与鼠标提示

不可整理的卡片和正文明确使用点击光标，只有实际接入拖移操作的关注卡片显示抓取光标。桌面鼠标悬浮或键盘聚焦时，卡片以 220ms 过渡上抬 4px，阴影加深扩散；移开后平滑落回。使用独立位移属性，避免干扰网格重排动画；拖移、缩放、刷新期间停用抬升，减少动态效果模式只保留静态阴影。触屏不触发悬浮抬升。

本轮构建、差异检查和 6 项既有浏览器用例通过，覆盖关注拖移／缩放／键盘／触屏，以及详情到会话过渡。后台独立预览核对了推荐点击光标、悬浮位移和阴影，未修改用户卡片状态。
