# M6-A1 Excel 统计成果验证

2026-09-24，DEC-067。M6-A1 第三切片本地实现及合成验证，待非作者审查。具体范围见[技术边界](../技术/M6-A1Excel统计成果边界.md)。本批仅 CSV/TSV 统计的 Excel 结果输出，不宣称完整 Excel 处理、真实模型或客户验收。

## 交付

csv_summary 由实际计算同时生成 JSON、XLSX 与处理报告；工作簿有汇总及来源/口径两张表。高精度数字保留、文字不执行公式、固定原件版本、输出摘要、失败和权限边界沿原有流程。引擎 0.9.0 / file-processing 1.1.0，Agent 1.4 及平台 API/V13 不变，未新增第三方运行依赖。

测试覆盖 0.1+0.2 的精确求和、超过 15 位的整数/小数、负小数、零、空结果、明确跳过空值、精确筛选、分组空值与同名标记区分、公式形态文字/前导零/XML 特殊字符与换行、确定性输出、非法字符及过长内容明确失败。输出没有公式节点、宏或外部链接，报告摘要与实际 XLSX 字节相符。生成模块通过真实 macOS TaskSandbox 导入执行；没有为了测试放松网络、宿主路径或写入权限。

浏览器从真实资料上传、明确选择 v1 开始；选择后再上传内容不同的 v2，任务实际仍输出 v1 的 3 行、10.3 合计与 0.3 分组合计，Excel 来源页记录 v1。实际点击下载并读取 XLSX、核对报告摘要；刷新后从平台再次下载字节相同。总台访问 403，企业停用后旧链接也 403。模型 HTTP 夹具核对收到的 CSV 配方结果有计算摘要和文件元信息而无 contentBase64（文本配方保持原有行为），平台仍获得完整产物。其后原 M5 画报和 M6 文稿/共享完整流程保持通过。

所有测试使用自有一次性 PostgreSQL 和合成数据，不修改既有试用服务。浏览器结果/截图在本工作树 `.local/m4-agent/`；文件检查/渲染在 `.local/m6-excel/`，均不提交。独立阅读器通过不等于 Microsoft Excel/WPS、手机真机或 Linux/云执行节点验收；本批没有重跑 Linux VM 或生产部署。
