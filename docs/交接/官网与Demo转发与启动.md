# AI Dreamcore 梦核工作空间：官网与 Demo 体验包

包内包含梦核产品官网、梦核引擎与岚云智能介绍，以及当前空谷无界场景的交互 Demo。首页点击“产品演示”即可进入工作台，演示页左上角可返回官网。

## 解压后启动

1. 完整解压 ZIP，进入 `ai-dreamcore-preview` 文件夹。
2. 电脑需已安装 Node.js 22.12.0 或更高版本。macOS 可双击 `Start-macOS.command`，Windows 可双击 `Start-Windows.cmd`；也可以在该文件夹内打开终端，执行下面的命令。
3. 浏览器打开 `http://127.0.0.1:4318/`。终端保持运行，按 `Ctrl+C` 停止。

```bash
node scripts/serve-website-demo.mjs
```

也可执行 `npm start`，无需 `npm install`、重新构建、Python、账号或 API Key。不要直接双击 `dist/index.html`，页面需要通过本地 HTTP 服务加载。

端口已被占用时，执行 `node scripts/serve-website-demo.mjs --port 4319`，并打开 `http://127.0.0.1:4319/`。不要结束其他应用来释放端口。

每位同事在自己的电脑解压启动。`127.0.0.1` 代表正在使用的电脑，不能把发送方的这个地址当作远程访问链接。此包适合分别体验；如需所有人通过一个网址访问，需要另行托管。

## 体验范围

- 官网包含产品、梦核引擎、持续进化与岚云智能公司介绍。
- 工作台采用空谷无界场景，可体验智能画报、会话、资料库和应用。内置经营记录为合成数据，资讯摘要标有公开来源。
- 官网截图保留通用产品场景；进入 Demo 后展示空谷场景。“AI 会话”的体验入口进入读书会筹备示例。
- AI 回复、权限与业务执行是前端模拟。官网描述的产品方向不代表真实模型、后台主动运行或企业权限已接入。
- 官网、工作台交互和内部资料可本地运行；新闻原图与外部原文需要联网，第三方新闻照片未下载到本包。
- 操作保存在各自浏览器，不会同步给其他同事。包中不含发送方浏览器的会话、导入资料或个人修改。个人设置中的重置会清除当前演示操作。
- 这是打包时的版本快照，后续修改需要重新发包。同一浏览器、地址及端口会沿用本地演示数据。

## 文件说明

`dist/` 是已构建的官网和 Demo；`scripts/` 是仅使用 Node 内置模块的启动服务。`验证记录.txt` 记录构建范围，`文件校验清单.json` 可核对文件完整性。实际验证平台以交付验证记录为准。

此包供浏览体验，不含开发依赖、内部产品与商业文档、环境凭据或 Sites 托管配置。需要继续开发时使用完整开发项目。
