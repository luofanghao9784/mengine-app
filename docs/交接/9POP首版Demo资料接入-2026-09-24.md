# 9POP 首版 Demo 资料接入

## 已确认与实际交付

面向本人及 9POP 内部管理层，以老板视角查看跨店经营、风险、资金和建议。使用 2026-09-24 核验的固定快照与本次真实分析，允许真实姓名和经营数据，排除凭据。此次实现不修改生产业务。

- 36 张卡片：数据 8、洞察 12、建议 6、成果草稿 4、资讯 6；每张可查看完整事实、AI 判断、建议动作、证据边界、统计时间、复核岗位与来源。
- 102 份资料条目：66 份来源阅读内容，以及 36 份卡片分析/草稿。Word 保留表格行列，数据库使用核验聚合快照；部分历史表格、代码和照片只提供核读摘记或筛选记录，未冒充原件全文或导入私人素材。
- 七个可筛选资料空间是首版展示分组，不代表已批准的组织架构。数据期、查询时点和本次生成时间分别保留。
- 应用区提供真实后台链接，新标签页打开 `https://boss.9pop.top/`，使用原 9POP 账号及权限。未接统一登录、内嵌或自动业务处理。
- 画报可阅读、关注与追问；追问明确为固定资料检索，没有实时模型或后台接口调用。原默认空谷 Demo 保持独立。

## 本机运行

```sh
npm run demo:9pop
```

访问 <http://127.0.0.1:5196/?scenario=ninepop>；应用页为 <http://127.0.0.1:5196/?scenario=ninepop#/apps/all>。

默认数据目录为 `customer-data/9pop-demo-2026-09-24`，可用环境变量 `NINEPOP_DEMO_DATA_DIR` 覆盖。启动先校验来源哈希并生成 `09-资料阅读内容.json`，再启动仅监听本机的 Vite。需要原资料仍可访问。`NINEPOP_DEMO_PORT` 可修改端口。

真实数据不进入源码、Git、公开静态目录或普通构建产物。接口只返回所选卡片与阅读内容，不暴露资料索引中的本机绝对路径。未显式启用资料包时该接口为 404；普通 preview 也不能读取它。来源目录直接 URL 访问被拒绝。

会话及反馈仅保存在当前浏览器会话，关闭后不保证保留。刷新时仍须本机资料接口可用；来源正文始终以核验资料包为准。此试用没有企业登录与多人权限体系，不适合直接作为内网或公网部署。

## 验证

接入测试使用合成小包验证导入、来源缺失、固定证据、会话来源权限、链接地址约束，以及私有 HTTP 接口的访问边界。实际资料只在本机的可选浏览器用例中读取，不进入 CI 测试夹具。

```sh
npm run build
node --experimental-strip-types --test tests/ninepop-import.test.ts tests/model.test.ts tests/briefing-article.test.ts
NINEPOP_DEMO_DATA_DIR="$PWD/customer-data/9pop-demo-2026-09-24" PLAYWRIGHT_PORT=5196 npx playwright test tests/e2e/ninepop.spec.ts tests/e2e/konggu.spec.ts tests/e2e/briefing-density.spec.ts
```

浏览器检查覆盖全部卡片导入、完整依据、来源阅读、关注后刷新、应用链接、默认场景隔离、桌面/窄屏图表全部标签及横向布局。截图放在 Git 忽略的 `.local/ninepop`。从真实卡片解释依据、刷新恢复会话也已验证；“查看”类提示沿用打开来源资料的原交互。实际后台已通过 HTTP 与本地部署文档核对，未执行账号登录或生产业务操作，因此此处只验收入口行为，不声称后台业务已完成自然使用验收。

首版保留的业务待核实项在内部调研报告及相关卡片中，包括资金对账依据、制度沿革与续费率分母。未因页面接入将这些判断升级为已确认事实。

实际检查结果：主目录构建通过，50 项相关单元检查及 10 项浏览器场景通过。普通构建中未发现 36 张真实卡片的标题或分析正文；preview 资料接口为 404、原数据路径为 403。真实内容与截图经 `git check-ignore` 确认为忽略文件。未提交、推送或部署。

## 2026-09-25 画报表达修订

按用户的九条页面批注，36 张卡片统一采用管理层汇报语言。卡面和分析正文移除 Demo、开发核验提示与代码术语，取消顶部试用提示条；标题直接讲清经营情况，建议写明待核事项和行动。需要保留的业务限制仍用日常语言说明，原始数字、来源引用与证据时间没有改写。

卡片页脚仅保留简短来源，比较图保留一行必要的比较期，详情展示统计范围。6 张资讯按阅读顺序穿插在经营卡片中，保留各自报道日期，配真实报道图片或活动海报。相关活动照片明确标注资料图与活动月份，详情提供图片出处；媒体地址和来源留在本机资料包 `06-资讯与图片候选.json`，不放进源码。图片采用外部公开地址，需联网加载。

已保存的阅读反馈、自定义标题、关注状态和会话保留；重新加载资料包时更新当前卡片的编辑内容，包括资讯卡，既有会话引用原件不重写。当前资料仍以已核验的固定资料包为准，这次文案调整不增加后台或模型调用。

本轮验证：构建、28 项相关单元检查与6项浏览器用例通过。逐项比对36张卡片的原始数值记录、来源引用和时间未变；6张图片均能加载，1440、977和390像素宽度下36张卡片正文与图片无重叠、无横向溢出。补充截图及布局结果在 `.local/ninepop/`，审阅稿在本机资料包 `04-36张卡片审阅稿.md`。
