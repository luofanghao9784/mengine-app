# 美租引擎自动接入恢复

用户要求恢复数据输入与执行，认领 #146。此轮为本地环境恢复及采集可靠性修复，未操作生产。

## 原因与处理

全房通自动接入因前次数据清理保持关闭，已通过企业账号恢复原每小时计划。重新登记的流水账使用新数据集编号，原八项固定分析方法仍绑定已清理编号，已在本地私有证据配置复制到同来源、同列的新编号。统计范围和排除范围不变；金额单位显示按当前已发布字段的“元”对齐，保留人民币及原始正负号，不进行换算。当前及上月窗口按任务创建时间解析，登记金额不解释为银行到账、营业额、利润或逾期本金。

收支计划来源每 360 分钟取数，但接收适配器原有效期只有 7200 秒。已在私有 binding 将该表有效期设为 25200 秒，覆盖原周期和一小时宽限，并实际刷新来源检查；其他表周期不变。

真实验收还发现采集写入与并发分析读锁触发 PostgreSQL 40P01，CollectionWorker 将其统称为适配器失败。新增对完成事务中 SQLSTATE 40P01/40001 的有限重试，总计最多三次，沿用同一适配器结果和租约，重新执行完整授权及当前性核验。不重新取数或调用模型，不重试校验错误及其他数据库错误，耗尽后保留失败。

## 验证与边界

CollectionWorkerRetryTest 三项及 CollectionIntegrationTest 三十八项通过，Maven package 成功。修正一项过时测试预期：当前字段部署已允许 UNKNOWN 空证据，该状态仍不代表业务已确认；无效状态继续拒绝。

因同目录存在其他任务未提交内容，另以 HEAD 导出隔离源码，仅叠加本任务文件，重复验证上述 41 项并构建通过；核对部署包中 CollectionWorker.class 与隔离构建一致。

本地服务更新后，真实账号发起接入成功、reason 为空，本批写入十个数据集快照。自动开关开启且 nextDue 非空。恢复后的真实账单分析成功，生成两份服务端统计回执与一份智能画报；浏览器引擎概览无脚本错误。其他未完整交付的历史任务仍保留，其中一次合同分析无适用固定方法且模型输出工具文本，不能算作成功；本次未扩展未知合同状态的业务解释。执行中是瞬时指标，成功后归零是正常空闲。

私有证据、适配绑定备份及本轮结果保存在 .local/work/engine-recovery/。停止自动输入可通过连接计划关闭，不需要删除现有数据。代码走任务 PR，基于知识读取修复 PR #143，由另一维护者合并；不将其他任务修改混入提交。
