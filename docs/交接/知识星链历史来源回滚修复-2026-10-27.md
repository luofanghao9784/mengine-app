# 知识星链历史来源回滚修复

认领 #142。美租本地曾清理旧数据集，随后重新登记十张表。十篇知识已发布，但知识页面复核旧发布记录时遇到 DATASET_NOT_FOUND。pendingReview 在内层 TransactionTemplate 之外捕获该异常，已加入外层事务的内层调用将事务标记为 rollback-only，最终返回 INTERNAL_ERROR。

将发布记录读取拆成保留事务入口的 read 和事务内 readInside。pendingReview 在自己的事务中调用 readInside 并处理预期的历史来源不可用，不再额外进入会将预期异常标记为回滚的模板。权限、来源有效性及历史内容不可见规则保持原样，真实事务错误不被忽略。

验证：NativeAutomaticContinuityIntegrationTest 共 20 项通过，新增历史失效发布与当前知识共存、所有来源撤下后返回空页面的回归场景。Maven package、npm run build 通过。本地服务更新后，用实际账号访问知识接口和浏览器页面，十篇数据口径知识正常显示，无页面脚本错误。自动接入仍暂停，未修改业务记录，未操作生产。开发机器私有验证证据位于 .local/work/knowledge-read-fix/。

代码按任务分支提交 PR，由另一维护者审阅合并。回退仅需恢复前版本服务，未新增数据库迁移。
