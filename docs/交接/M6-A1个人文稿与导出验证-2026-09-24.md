## 交付

成功 Agent 回复或文本产物可保存成个人文稿；资料库可再次进入，修改标题/正文、保存不可变版本、恢复本标签页草稿、查看旧版本、下载确切版本的 Word/PDF。来源依赖不会因编辑解除，撤权影响当前、历史、幂等重试和缓存文件。三端共用现有布局/组件，总台没有新增私人内容入口。

V12 增加文稿、版本、写入回执与导出缓存，源任务/产物复合外键确保企业及任务关联。文稿 API 1.0.0；引擎 0.8.0 / Agent 1.4 未变，排版在平台离线执行。
