# 画报数据更新与业务展示修复

范围：AI-02—AI-04、WS-08—WS-11、MAINT-07—MAINT-10；2026-10-16 用户授权修复线上画报数量、业务语言与模型接续问题。

## 已核实原因

- 8 张有效首轮成果中，审批、课程、课时、课债 4 张的原数据集随版本变化被撤下。任务成功且未隐藏，但服务端来源检查拒绝读取；订单与收款核对、退款、转店、体验转化 4 张保持可见。
- SceneService 曾用完整元数据哈希作为数据集身份，数据版本、更新时间和来源数据摘要变化也会替换 ID。
- 新业务链未配置图表状态映射；统计单位和范围落到内部兜底文案；前端把部署来源显示在卡面。
- 线上生成请求被路由到日常模型 qwen3.7-plus，供应商返回 403 / insufficient_quota，提示免费额度耗尽。现有主模型 qwen3.8-max-0902 的普通及流式请求均成功。

## 实现

- V140 定义场景表的稳定范围：只忽略数据版本、更新时间，以及 sourceBasis 内的数据版本、摘要和采集时间；保留源 ID、权限版本、字段、说明、配方及其他约束。
- 正常同步复用当前数据集 ID，采集继续追加不可变快照。原部署形成的旧 ID 只有在同企业、连接、空间、来源键和稳定范围完全一致、当前来源仍有效时可读取历史成果。没有恢复被停用的错误旧卡，没有更改历史计算证据。
- 来源撤回、政策变化、口径变化、清理和成员撤权继续阻止访问；不修改通用文件来源权限。
- 服务端按业务维度提供中文展示映射，支持多维组合状态；未知状态标记待核实。提供业务计量单位和数据覆盖时间；前端仅投影视图，不改原始数值、分组、哈希或证据。
- 卡面去掉 Codex 首轮生成来源标签，后台部署来源保留。
- 新增 AGENT_BRIEFING_USE_PRIMARY_MODEL，默认 false；本次线上启用后仅画报选择已配置主模型，其他日常工作仍保持原路由，不在失败后自动更换模型或重复收费调用，不修改供应商计费设置。

- 业务展示：组合状态、单位、截止时间、原始值不变；前端图表投影与金额显示回归。
- 引擎：32 项路由与画报测试通过。
- 主目录及线上前端基线构建通过。线上客户端仍沿现有发布基线增量构建，未混入企业端未发布改版。
