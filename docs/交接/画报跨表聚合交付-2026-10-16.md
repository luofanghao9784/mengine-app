# 画报跨表聚合交付

## 问题与实现

原有组合只独立计算多个指标，主图只显示一项，不能算跨表聚合。本次为自动 DATA 任务增加系统固定的关联计划：在任务领取前，从当前用户获权的数据中，依据企业端登记的关系，选择两张事实表和一个共同维度；验证目标关联键唯一；分别关联、独立汇总，然后按维度标识对齐。禁止两张多行事实表直接连接后累加金额。优先有已发布 SUM 指标的事实组合，COUNT 为后备；不硬编码企业或业务表名。

本批边界：三个来源、两项已发布指标，每源最多十万行、维度最多49个对象；仅组合无日期过滤、无预分组的 SUM/COUNT 口径。含日期限制、歧义归属或无有效登记关联的口径不会被偷偷改成全量统计。原有单指标路径保留，不冒充跨表结果。此功能不表示任意表都可拼接，也不包括职责推送配置。

所有来源和指标版本进入现有任务权限及失效链；执行与交付再次校验。目标键重复时拒绝方案，未匹配记录保留独立分组。同名对象按标识区分。每个指标单位独立，不推断转化率、因果或跨指标合计。画报保留完整关联结果、来源与覆盖，前端显示双指标及共同维度表。正文必须解释两项指标，数字限于后端证据；不能只将辅助结果藏在引用中。

企业端登记关系使用稳定结构指纹，既有总台导出只有完整定义指纹，导致两者无法匹配。新增导出 dictionarySchemaFingerprint，并在口径范围函数中排除这一派生字段，避免仅补同步字段撤回既有指标。原有字段、权限、定义变化仍照常失效。
