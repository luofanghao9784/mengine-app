## 实现与使用

企业端和总台“治理成果同步”页面新增业务指标目录。企业管理员选择已同步数据集，填写名称、含义、单位、统计粒度、适用范围、排除项、业务依据及 COUNT/SUM 定义，先保存草稿，再明确确认发布。总台读取同一中央目录，无额外同步副本或延迟。更改定义产生不可变新版本；旧发布版在新草稿编辑期间仍生效，直到发布新版本或撤回。

API 在既有 scene/metrics 路径提供管理功能，复用平台角色、企业管理员及源端管理员核验；保存和发布另外要求来源数据权限和目标空间读取权限。版本冲突拒绝覆盖；引用不存在或非数值的 SUM 字段拒绝保存。定义、来源范围、操作人及发布事件保留审计记录。最多 100 个指标/企业。

现有 task_context 的 dataset_search 支持按已发布指标名称检索；dataset_search/dataset_read 返回治理指标作为非权威参考，保留 metricId、version 和业务依据。每次最多三个指标，按名称匹配优先，返回 hasMore。沿用数据集权限、指定来源范围和固定快照；后台登记任务实际读取的指标版本。来源口径、授权范围、发布版本或有效租约变化会关闭使用；撤回再重发不会恢复原进行中的任务。既有历史/经验任务依赖也纳入指标权限校验，最终提交锁住引用指标避免并发发布穿透。

边界：本批是词面检索加治理口径注入，不是向量/混合检索，也不增加自动业务指标猜测。管理员发布确认口径的使用，不代表源数据或字段推断已由系统证明。复杂业务筛选、跨表规则与指标专用确定性执行器尚未实现；明确禁止用全表合计冒充此类指标。现有后端快照计算工具继续负责数字结果。源权限的五分钟同步有效期与源端旁路变更窗口沿用首批，事件化即时撤权仍待后续。

当前真实来源没有登记指标，本轮不替企业编造并发布指标。需管理员在企业端登记并确认业务定义后，RAG 才有指标可用。
