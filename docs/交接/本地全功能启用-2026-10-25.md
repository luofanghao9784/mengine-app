## 本次实例

- 目录：`~/Desktop/dreamcore-workspace`。初始 main 为 `6400ce29aad8bfa4ae6c94b7340a7efc99e17b76`，完整 Git 历史，已启用 Git hooks。

本机完整启动/停止入口（忽略文件，其他维护者需独立安装和配置）：

```bash
cd ~/Desktop/dreamcore-workspace
.local/start.command
# 另开终端查看状态
source .local/env.sh
npm run trial:status
# 停止本实例及专用可选服务，保留数据
.local/stop.command
```

通用核心启动命令；企业 UUID 需通过总台开通并激活后获取：

```bash
npm run trial:start -- --live --model-config .local/model-private/deepseek.json \
  --enable-live --automatic-work --phone-local --scene-tenant <本地企业UUID>
```

`--enable-live` 用于已有实例的显式启用，不能用来初始化空目录。首次步骤见[本地启动指南](本地启动指南.md)。启动检查只确认配置合法，不能证明云端调用成功。

## 已配置的功能开关

以下文件都属于 `.local/trial/`，JSON 文件须为本人所有且权限 600。默认配置和恢复隔离规则保留。

| 配置 | 本次值 / 作用 |
| --- | --- |
| 根目录 `.env.local` | `VITE_LOCAL_FEATURE_ENTRIES=true`，构建时展示待办、持续计划、成果转发入口 |
| 启动 `--automatic-work` | 企业信息分析、经验接收/分析/归纳、自动画报、持续计划 |
| `presentation-runtime.json` | `{"enabled":true}`，固定 PPT 渲染器 |
| `capabilities-runtime.json` | `{"presentationEnabled":true,"governanceDispatchEnabled":true}`，PPT 平台渲染/下载和治理调度 |
| `briefing-runtime.json` | `{"dailyEnabled":true,"automaticEnabled":true}`，每日与自动画报能力 |
| `experience-runtime.json` | 三项 `intakeEnabled/analysisEnabled/generalizationEnabled` 均为 true |
| `analysis-runtime.json` | `{"materialApiEnabled":true}`，本地计算素材验收 API |
| `docling-runtime.json` | `{"enabled":true}`，离线 PDF/OCR；已独立安装 Python 环境并复制离线模型 |
| `config.json.publicSearch` | `{"provider":"bing-rss","dns":"google"}`，联网资讯与公共读取 |
| `weknora-runtime.json` | 独立本机 URL、作用域服务密钥与 rerank 模型 ID，不在文档填写凭据 |
| `langfuse-runtime.json` | 本机 URL 和新项目凭据，运行追踪已配置 |

资料解析随 parser 虚拟环境就绪开启。场景服务已绑定合成企业共享空间并同步；该企业资料 ACL 和指标自动生成/定义已显式启用。每日画报、持续计划、定时采集还需要具体订阅、工作目标或数据连接，启用能力不会凭空建立业务任务或授权数据源。

## 验证与当前限制

- 前端、引擎、Maven 后端、场景服务构建通过。
- 本地启动相关测试 156 项：70 通过、86 按环境跳过；基础解析 35 项：25 通过、10 跳过。
- 显式启用离线模型后，Docling 的扫描 PDF 页码/OCR 与损坏文件检查 2 项通过（37 秒），使用合成 PDF，未调用云端模型。
- 公网路由/资讯测试 35 项、PPT 渲染与确认协议测试 10 项通过。
- 真实浏览器完成负责人登录与客户端/企业管理页面访问，未发现 JavaScript 页面错误；总台开通企业、手机号本地验证、共享空间绑定均通过实际 API。
- 合成 Markdown 上传后解析状态 `READY`；本地搜索返回对应片段。PPT 能力接口返回 `available:true`。
- 真实 Bing RSS 读取返回 HTTP 200；Langfuse 健康及项目认证 API 均为 HTTP 200，六个容器运行。该实例为 v4 events-only 模式，旧 `/api/public/traces` 查询端点不适用。
- 通过实际引擎 observability 适配器发送合成任务元数据，v2 observations API 读回 `task-attempt` 与 `platform-call` 两条记录，未发送模型请求或资料正文。
- **DeepSeek 旧密钥返回 401 authentication_error；百炼 embedding 旧密钥返回 401 invalid_api_key。** 用户已选择先运行本地功能、保留配置等待更新。不能将 AI 对话、画报、经验/治理推理或模型生成 PPT 标为真实完成。
- WeKnora 服务已启动并完成独立账号、模型、知识库和限定作用域 key 初始化；因百炼凭据失效，合成企业的远程索引目标暂时停用，普通搜索使用本地索引。更新密钥后需更新 WeKnora 中的模型凭据、重试失败索引、验证嵌入和 rerank，再重新启用该企业目标；仅修改文件不会自动改写服务中的模型。
- 技能中心 dashboard、organizer、infographic、meeting 仍为“即将开放”。候选执行实验和旧协议兼容不是本次普通业务功能，不开启。
- 外部业务采集尚无该合成企业授权来源，未接入旧业务源。全部运行仅限本机，未操作生产。

## 后续维护
