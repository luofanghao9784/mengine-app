# 资料权限首期启用（2026-10-12）

## 授权与目标

用户已确认首期规则，并明确要求验证后部署、启用 `ai.9pop.top` 客户端。仅处理资料权限、留痕和版本历史；工作目录中其他治理、数据基座和技能成果通道的未提交改动不在本次发布范围。

需求：[LIB-01—LIB-10 与 Q01—Q10 最新确认](../产品/资料库权限、操作留痕与版本历史-需求说明-V0.1.md)。上次部署 `fea2e23a` 新权限开关为关闭，故实际客户端未显示权限按钮。

## 本次实现

- V115：独立范围不绕过祖先明确禁止；文件派生来源和历史任务依赖递归复核（有环或超过 32 层时拒绝），当前文件和历史版本使用同一内容/下载资格。
- 文稿导出缓存、批量导出、AI 成果下载按来源下载权核对；系统内发布不要求外部下载资格，但检查目标受众来源阅读权。旧发布副本按其记录的来源重新核对；同文件多版本采用全部保留发布来源的保守交集。
- 计划资料候选、人工来源提交、经验引用、企业信息推断、评估、反馈与推荐成果补文件检查。原件、解析/检索、AI 授权、动态、上传/版本以及生命周期沿首批统一判断；回收预览检查全部子对象并隐藏未获权路径。
- 权限保存前预览所有成员生效权限差异，确认时重新计算指纹，过期拒绝，重复请求只返回现状态；预览在事务保存点内模拟并回滚，不留下假成功事件。
- 阻止管理员通过对象策略、部门成员、旧空间成员/维护权限和负责人转移为自己增加已有对象内容资格；新建空空间沿原创建规则。
- 客户端增加“资料权限管理”（只返回基本名称与授权能力）、“共享给我”、授权来源/逐人成员结果、访问请求留痕；普通读者仍只能看文件维护记录，管理员可看完整变更前后信息。
- 租户 HTTP 请求先追加持久起始记录，失败则返回 503；结束记录追加状态与结果，未结束为待核对。记录不存正文、查询值、请求头或凭据。业务审计与重要变更同事务。请求回执不代表业务成功或接收端已完整保存文件；服务异常后的待核对记录由管理员查看，无自动伪造完成结果。

## 实现边界与验证方法

- 不新增跨空间实体迁移、版本还原/差异、嵌套部门、大批量修改、任意 Office 在线编辑或防截图。
- 请求日志暂不自动清理；文件操作记录与完整权限日志分级。历史版本可见性以当前权限为准。
- 千条历史推荐场景在此前已部署源码中同样触发原 3 秒查询上限。当前将可读集合在单次查询内复用，并以固定任务入口阻止查询规划器跨无关任务展开递归授权图，保留原 3 秒上限；新旧开关均验证 1,001 条候选的正确计数及 1,000 条窗口，不取消服务端权限检查。
- 精确发布快照排除未发布 V110/V112/V114，仅在 V113 上增加 V115；不会倒灌其他迁移。
- 浏览器合成路由验证交互；Java 真数据库/HTTP 验证权限和持久化。公网部署后另记实际资源、运行库和启用证据。真实模型语义与用户人工验收不冒充自动验收。

精确暂存快照验证：20 个后端测试类合计 254 项通过，0 失败/错误/跳过。首次隔离构建的解析依赖软链接不符合沙箱读取范围，改为在构建目录复用依赖文件后，11 项解析回归通过；其他 243 项已通过。千条历史在旧版本亦可复现超时，补固定任务分派后，新旧开关 1,001 条场景均通过。最终权限管理增量复验通过。

前端精确快照构建通过；9 项权限与回收站浏览器检查通过。最后补充企业管理请求日志路径后，权限移动/HTTP 留痕和企业管理集成复验通过，API 打包成功。

## 使用入口

客户端 → 资料库 → 企业资料库：可用各行“权限设置”和“当前位置权限”；无阅读权的管理员从“资料权限管理”按名称定位。单文件跨部门授权后，接收者可从“共享给我”进入。文件详情 → “资料属性与版本”查看历史版本及操作记录。企业管理端 → 成员管理 → 部门维护，办理加入/调离。

## 部署回退边界

切换前保存 API、前端和数据库备份；迁移失败保持维护门禁，不自动恢复整库。上线后如果已有新策略/授权写入，不可简单关闭权限开关或换回旧代码，以免旧模式忽略明确禁止。优先修复前滚；需要恢复时先冻结写入并核对备份之后的变更。
