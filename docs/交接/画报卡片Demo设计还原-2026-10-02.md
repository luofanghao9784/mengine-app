# 画报卡片 Demo 设计还原

## 范围与调查结论

用户在真实工作空间的「五店两期收款对比分析」卡片批注，要求调查与旧 Demo 的样式差异并尽可能还原。沿用 DEC-100、DEC-101 与 CUI-05，设计基准为 `reference/frontend-9pop-2026-09-26`（`e2f59ee`），不以最初导入版作基准。

主线的 Demo 杂志卡片源码与该标签一致。差异来自真实入口的独立渲染路径：推荐卡绕过 `MagazineBody`；生成内容用普通类型文字及左侧日期，标题缩为 21px，所有生成卡统一至少 360px；固定三列与 640px SVG 缩放使窄卡数据拥挤。原 Demo 的五类标签、24/32px 标题、36/48px 数字及 24px 圆角没有完整接入真实卡片。

## 本次修改

首轮 `44e488d` 仅恢复了卡面配色和层次，仍采用自然高度瀑布流、横向条形图和静态会话按钮。用户指出网格、悬浮与详情效果仍有差异后，本轮将这些简化实现替换为以下最终方案。

- 推荐、关注和历史卡面共用 `MagazineBody` 与 `MagazineGrid`。共用 Demo 的字体、类型标签、24px 圆角及五类配色；日期使用 `briefingTime`。
- 网格采用 Demo 的 478 / 722 / 966 / 1210px 列数断点、10px 间距及正方形基准单元。四种常规尺寸为 `1×1`、`2×1`、`1×2`、`2×2`；从首个空位尝试后续卡片，自动补入可容纳的空位。末行未用完的尾部空间不代表中间漏排。
- 复用 `useBriefingCardFit` 按真实换行测量标题。完整标题与图表的最低阅读高度优先；和 Demo 一样，极长内容必要时增加整格行数。单列时只调整展示跨度，保存的加宽偏好、服务端推荐顺序及内容均不改写。DOM 顺序随可见拼版排列，已读操作本身不换位。
- 悬浮与键盘焦点恢复 4px 上浮、220ms 过渡、边框高亮和两层投影；改变宽度时使用位置过渡。减少动态效果设置关闭上浮与动画。
- 卡面与详情共用 Demo 的 `BriefingChart` / `BriefingBusinessChart`：纵向双列对比、浅蓝基期/深蓝本期、网格线、当前值、日期图例和悬浮数值提示。移除首轮额外堆叠的大合计与独立横向图表。
- 图表适配真实回执的负值、缺失值和精确十进制标签；缺失不画成零，图形坐标使用数值但提示及表格保留原始精度。超过六组的卡面明确提示预览组数，详情保留最多五十组并在窄处局部横向滚动。
- 详情恢复 Demo 的背景虚化透明度、标题栏与阴影，并直接复用会话按钮的渐变流动、扫光和减少动画适配。真实会话、已读、反馈、权限、来源与完整数据表保持原路径。
- 图片、步骤和文件封面无对应真实字段时不补造 Demo 内容。本次没有修改接口、模型、计算回执或持久资料。
