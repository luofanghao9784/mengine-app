## 已实现

- `apps/api/`：Java 21、Spring Boot 4.1.1、独立 Maven 构建与启动，平台健康接口、自有引擎适配及运行状态接口。
- `engine/`：Node 24.20.0、TypeScript 7.0.2、独立锁文件/构建/启动与版本声明；当前为 `contract-only`，能力列表为空。
- `contracts/`：OpenAPI、JSON Schema、前端类型、运行检查和合成样例。平台→引擎为真实 HTTP 调用，协议错误与不可达有独立返回。
- `src/data/`：显式 Demo/HTTP 运行状态客户端，具有超时、取消与错误处理；资料读取先抽出 Demo 只读投影，现有资料页面已使用该边界，其他业务仍为 Demo。
- Vite 开发代理 `/api`；自动验证脚本启动自己拥有的三个临时端口进程，实际在 Chromium 中使用前端模块调用平台，再停止/重启引擎验证失败与恢复。

选择 Spring Boot 4.1.1 是本轮工程决定，官方列为稳定版且支持本机 JDK 21；见[系统要求](https://docs.spring.io/spring-boot/system-requirements.html)。版本已固定并完成实际编译与启动，不代表其他配套组件已选定。

## 安装、构建与检查

在仓库根目录，JDK 21 和 Node 24.20.0 可用时：

```bash
npm ci
npm ci --prefix engine
npm run build
npm run build:engine
./apps/api/mvnw -f apps/api/pom.xml test package
npx tsc --noEmit -p tsconfig.foundation.json
npm test
npm run test:contracts
npm run test:engine
npm run test:foundation
```

Windows Maven 使用 `apps\api\mvnw.cmd -f apps\api\pom.xml test package`。浏览器检查需要 Playwright Chromium，首次可执行 `npx playwright install chromium`。`test:foundation` 使用已经构建的 API JAR 和引擎 `dist/`，修改服务源码后必须先重新构建。

本机 Maven 默认 JDK 曾为 25，Maven Wrapper 使用已配置的 JDK 21；最终平台测试及实际启动均在 Java 21.0.11 验证。团队应使用与编译目标一致的 JDK，而非依赖不同 shell 的隐式选择。

手动查看三个服务时分别启动：仓库根执行 `npm run start:engine`；另一个终端执行 `java -jar apps/api/target/workspace-api-0.1.0-SNAPSHOT.jar`；第三个终端执行 `npm run dev`。默认端口分别 18182、18181、5173。并行开发改用各任务独立端口，Vite 上游用 `DREAMCORE_DEV_API_URL` 配置。
