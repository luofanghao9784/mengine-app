## B1 当前身份实现

1. 增加独立平台账号与散列会话表，专用 Cookie/CSRF/安全链；客户 Cookie 不能访问任何总台接口。
2. 总台有独立登录组件，不经过客户手机加入、客户邀请或企业选择流程。客户两个入口移除总台跳转；平台页面无返回客户端/企业端操作。
3. 平台登录可与客户登录同时存在；退出、凭据版本和角色撤销分别生效。恢复平台角色不会恢复旧会话。
4. 兼容原审计主体 UUID 外键，独立平台登录信息不复用原客户凭据。旧平台角色不能自动登录新总台。受控 bootstrap 可创建新平台主体；未对真实账户执行。
5. 本地合成邀请预览也拆分到平台专用接口；客户端不再凭历史平台角色读取其他企业初始邀请。真实短信未启用。
6. OpenAPI 中各总台路径改为独立 Cookie 安全定义，并增加独立 auth 接口。

## B2 共享空间负责人闭环（2026-10-04 接续）

- 创建共享空间要求名称和明确选定的有效企业成员，说明选填。可明确选择创建者本人；选择他人时创建者不获得内容访问。负责人随创建同步获得阅读、资料维护及本空间成员授权；其他新成员默认只读。
- 空间负责人可检索本企业有效成员并管理自己负责的空间，不获得企业成员列表、企业邀请、账号停用、创建其他空间或更换负责人资格。企业管理侧栏按当前权限收敛，普通负责人通过“成员与空间”直接进入自己的空间。
- 企业管理员可更换负责人，页面在提交前展示接任者权限与原负责人后续权限，默认保留只读，可选择保留维护或移出。变更按版本和请求标识原子生效，失效原空间管理职责但不恢复已停用的企业成员，不移动原文件/版本/作者。
- 普通撤销授权和设为只读不能取消当前负责人的必要权限，需先更换负责人。详情可查看最近 50 条负责人变更记录。

## B3 数据库与部署采集（2026-10-04 接续）

### 页面与业务行为

- 企业数据库分为“数据管理”和“数据接入”。数据管理展示当前获权数据的总量、可用、更新中与最近失败摘要，支持名称和状态筛选、分页、当前版本预览；详情显示真实行数、采集时间及来源声明的数据覆盖时间。未提供覆盖时间显示未知，不以采集时间替代。成功的零行快照与未取得数据分开。

- 关闭自动取数只停止未来定时触发，当前有效任务继续；手动更新不改变下一次计划，执行中重复发起复用同一任务。频率变更只作用于后续调度，暂停后恢复跳过错过时段。画报生成策略未修改。
- 管理资格与内容访问分别校验：管理员没有空间授权时仍可管理连接，但不能预览数据或看到未获权的数据摘要。普通获权成员只见其空间的数据，连接说明中的权限摘要按其可见空间投影；不提供总台客户数据合集。

- 企业暂停、正式退出、人员撤权/离职、连接失效及部署范围变更使旧执行失效；本地采集进程会检查执行资格并终止，迟到结果不能入库。这不保证已发送的外部网络请求可被撤回。

清单格式为 JSON（以下 UUID 为合成占位，正式部署须替换为已存在企业/共享空间及专用连接/数据集标识）：

```json
{
  "contractVersion": "1.0",
  "tenantId": "10000000-0000-4000-8000-000000000001",
  "connectionId": "10000000-0000-4000-8000-000000000002",
  "name": "项目业务后台",
  "routeLabel": "现场只读采集 → 销售共享空间",
  "accessSummary": "仅销售空间，按部署批准的字段提供",
  "status": "READY",
  "timeZone": "Asia/Shanghai",
  "datasets": [{
    "id": "10000000-0000-4000-8000-000000000003",
    "workspaceId": "10000000-0000-4000-8000-000000000004",
    "key": "sales",
    "name": "销售汇总",
    "description": "项目批准的销售汇总口径",
    "columns": ["日期", "门店", "销售额"]
  }]
}
```

- `COLLECTION_MANIFEST_FILE` 指向绝对路径的普通 JSON 文件（非符号链接，最多 128 KiB），使用已有部署数据库配置运行 `java -jar apps/api/target/workspace-api-0.1.0-SNAPSHOT.jar --provision-collection`。该命令只导入清单，不启动 Web 服务或取数。业务事务由集成测试验证；本轮没有在客户环境执行命令。
- Web 服务的 `DREAMCORE_COLLECTION_EXECUTABLE` 指向维护人员安装的绝对可执行文件；使用 `ProcessBuilder` 直接执行，无 shell 拼接和页面传入参数。未配置可用程序时显示未部署，不接受手动更新或调度。采集器应是只读程序，不由本系统自动安装。
- 每次执行通过 stdin 接收一个 `1.0` JSON 对象：`tenantId`、`connectionId`、`runId`、`datasets[{id,key,columns}]`；stdout 只能返回 `{"contractVersion":"1.0","snapshots":[{"datasetId":"…","coverageThrough":null,"rows":[["2026-10-04","示例门店","100"]]}]}`。每个已批准数据集必须恰好返回一次，单元格为字符串或 null；覆盖时间可为 ISO 时间或 null，不能声称未来覆盖。数据含义和脱敏由该项目部署口径约束。
- 程序非零退出、超时、超限或不合法结果分别进入固定失败原因；stderr 和原始异常不进入用户记录。工程默认超时 120 秒、响应上限 20 MiB、并发 2，仅为可调整的资源保护值；不等于用户确认的业务取数频率。单数据集最多 10 万行、总计最多 100 万单元格、单元格最多 8192 字符。
