# iPad 局域网登录兼容修复

用户授权通过同一 Wi-Fi 的电脑访问梦擎，随后要求修复页面空白。本次仅处理该入口兼容性，未执行首期治理、发布或采集操作。

## 原因与修改

普通 HTTP 局域网地址不提供 `crypto.randomUUID`，登录组件初始化调用导致 React 根节点为空。保留原生实现；缺失时使用 `crypto.getRandomValues` 生成 UUID v4，不使用 Math.random，不降低随机性。新增 `public/browser-compat.js`，七个独立 HTML 入口在模块脚本之前同步加载，包含 iframe 原型入口。

电脑另有绑定 `192.168.2.63:18480` 的独立 SSH 转发；原 `127.0.0.1:18480` 转发保留。局域网入口依赖电脑开机、当前 IP 和隧道存活，未配置自动重启。服务器仍只监听回环网站端口。本次未改变源 9POP 服务器。

## 验证与部署

- `node --test tests/browser-compat.test.mjs`：3 项通过，覆盖安全随机字节、UUID 版本/变体、原生保留、重复加载与无 Web Crypto 时不伪造随机值。
- 上线前通过注入同一脚本核对 Chromium、WebKit 登录页；最初 HTML 请求拦截测试触发测试环境地址空间限制，改用真实页面加初始化脚本验证，没有关闭浏览器安全限制。
- 上线后不注入、不拦截：Chromium、WebKit 使用 iPad 视口实际访问企业端、员工端、总台共 6 项，均显示密码登录表单，无页面运行时异常。WebKit 截图已核对。这不是用户实际 iPad 的登录验收，未提交账号密码或业务表单。
- 仅向现有线上 web 目录添加兼容脚本、向现有 HTML 插入脚本标签，未重编译或替换现有业务 JS，未混入其他未提交改动。API JAR 和三个服务 PID 在本次部署前后保持不变；未重启后端或 nginx。
- 备份：`/opt/mengine/ipad-lan-compat-20261022/`。回退时按需移除这一个脚本标签，避免用旧 HTML 整体覆盖后来其他部署。
- 本次部署时 API JAR SHA256 为 `df226c673feab473f467f97287f1f35aa47964a63c15c1f4cdec55b5c24da860`，本补丁没有更改它。
- 私有验证证据在 `.local/ipad-lan-20261022/`。源码与测试未提交、未推送。
