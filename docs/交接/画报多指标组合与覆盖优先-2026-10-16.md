# 画报多指标组合与覆盖优先

## 已实现范围

面向所有企业的自动 DATA 画报，一次计算工具调用可执行最多三个已发布指标。模型可显式选择不同获权数据集的指标；未选择辅助指标时，平台只自动组合相同数据集、快照、分组、日期范围、时区和缺日处理的不同度量。每个指标单独执行后端固定计划，保留独立回执，不将独立汇总误作跨表逐行关联或转化率计算。

平台检索优先提供当前用户尚未收到过成功画报的指标，其次提供较早交付的指标。默认主图也遵循这一顺序；显式指标组合保留选定主指标。模型收到主计算及辅助计算，按各自单位、范围解读；现有画报主图仍显示一个指标，辅助指标用于正文。

治理画报的重复内容正常返回 NO_NEW_CONTENT，修复去重返回空文档后写入治理回执触发空指针的问题。保留去重规则，不靠重复内容增加数量。

每个计算仍经现有 API 检查发布版本、来源权限、租户、固定快照和任务状态。任何计算被拒绝，组合工具不返回部分结果。画报仍是当前用户的私有成果，打开时继续执行现有来源权限检查；未增加岗位主动推送、短信、邀请或外部通知。

**范围限制**：本次不是任意跨表 JOIN 引擎，也未完成新岗位职责配置界面、衍生敏感性发布授权或多图排版。`analysis/governed` 中先前的关系计算和分发策略基础模块尚未接入线上，不将其 13 项单元测试记为线上功能验收。
