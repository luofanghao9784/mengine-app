## 运行与配置边界

新克隆先按 [README](../../README.md) 和[开发启动说明](开发启动说明.md)安装依赖、构建前端、引擎和 API。V152 位于共享迁移目录，沿既有迁移谱系升级，不通过删除旧迁移或手改 Flyway 历史安装。

```sh
npm ci
npm run build
npm run build:engine
./apps/api/mvnw -B -f apps/api/pom.xml -DskipTests package
python3 scripts/local/live_model.py configure --provider deepseek --config .local/model-private/deepseek.json
```

最后一条需要本机交互终端隐藏输入密钥，并会进行显式模型连接检查；不应在 CI 中自动执行。试用启动及实例目录选择沿现有 `trial.py`。可选集成配置仅由相应实例目录下的私有文件启用，脚本会校验格式与归属。

`scripts/local/weknora_service.py` 与 `scripts/local/langfuse_service.py` 仅管理已经准备好的本地实例，不是全自动安装器。它们依赖 `.local` 内的外部二进制、服务配置及本机容器环境；这些内容不进入主仓库。新机器须按[开源接入说明](第一批开源接入-WeKnora-2026-10-18.md)部署服务并配置独立凭据，不能仅凭本次源码推送宣称服务已安装或模型已就绪。

源码、迁移、契约、测试与维护文档进入 Git；本地密钥、账号口令、企业数据库、上传原件、合成数据运行副本、依赖、模型文件、构建结果和验证日志保留本机。官网 `website/` 继续作为独立仓库维护。本次不部署线上。
