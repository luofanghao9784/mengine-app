## 实现决定

| 页面/层级 | 已实现变化 | 业务边界 |
| --- | --- | --- |
| 公共壳层 | 七项入口按“平台管理 / 梦核引擎”分组，设置保留底部；品牌“梦核引擎 / Mengine”；统一标题、页头操作、按钮、输入、面板、次要文字和焦点样式；总台专属颜色与尺寸规则 | 不新增业务入口、权限或管理操作 |
| 概览 | 用一条平台状态摘要、需要关注与本月用量建立层级；长口径按需展开；按验收标注移除底部常用入口 | 企业接手仅检查最近开通的最多 20 家，明确检查范围；等待、待核对与保留异常分别呈现，不冒充人工待办 |
| 企业管理 | 桌面列出企业、负责人、成员、开通日期与服务状态；删除重复企业标题与逐行装饰图标，搜索提交并入输入框尾部，状态筛选右侧，桌面行高 64px；窄屏转为逐项摘要；支持清除筛选 | 负责人接受状态与企业暂停状态保持独立；详情保留精确开通时间，初始邀请流程保留 |
| 账号管理 | 复用统一搜索/筛选控件，增加清除筛选 | 现有账号查询、状态与权限不变 |
| 系统运行 | 保留深色四区，缩小中央装饰，移除重复标题，刷新进入页头；统计口径与最近记录按需展开 | 执行数来自已接入运行记录，保留失败可能含历史尝试；自进化、资源、备份的未接入状态保留 |
| 经验库 | 刷新进入总台页头，统一选择态、输入和空状态 | 自动积累和内容调整规则保留，不增加人工审核 |
| 引擎管理 | 两个 URL 导航页面“能力与规则 / 版本与更新”；现有方法工作台嵌入版本页 | 固定排序方法按现有版本能力展示；模型、工具与主规则明确为此页面尚未接入展示，不推断为正常、停用或已部署 |
| 用量与成本 | 成本接入状态前置，期间/刷新进入页头，指标以分隔条呈现，全零趋势收为紧凑状态，详细口径按需展开 | 未上报调用、未配置额度与未接入成本仍是未知；每日数值完整保留，不估算单价或合并账单 |
| 设置 | 复用统一面板、页头操作、表单与选中态 | 邀请、资格撤销、本人账号和管理记录保留原接口及资格约束 |

总台视觉调整以 `.admin-platform` 或总台独有类隔离。企业端原 `telemetry.css` 未改，用量样式完整保留原 baseline。两个共用的交互改进需要说明：移动壳层导航在两个管理端都支持焦点循环、Escape 和关闭后恢复焦点；每日趋势在两个管理端都用紧凑空状态表达无已知非零观测，保留未知提示及每日表。客户端/智能画报未修改。
