2026-10-21，当前 main 本地源码。需求和后续优先级见 [开发任务书](../技术/智能画报质量优化-开发任务书-V0.1.md)。未启用真实模型、未采集业务数据、未重启运行实例或部署。

## 实现结果

- BQ-01：INSIGHT/SUGGESTION/RESULT 可以绑定本任务本尝试的计算产物；沿原文件、数据集、固定跨店及治理融合验证、权限和版本检查，保留原类型，chart=null。保留计算 ID/哈希、来源和范围；INFO 不允许借内部计算冒充资讯。治理指标回执验证同样适用于文字卡，重放不能改类型、计算依据或正文。前端读取校验与公开契约支持新文字证据，旧文字卡继续有效。图表形态 COMPARISON/SINGLE_FACT 在规划阶段要求 DATA，方案对比仍为 OPTIONS。
- BQ-02：生成提示词按固定来源、执行边界、近期参考分区预算；单来源提示限120字、来源区400字、近期区800字，裁剪明确标识。总上限仍为2000字，关键边界与近期参考不会因长文件名被整体尾部截断。以上为技术预算，不改变选中来源或用户输入上限。
- BQ-03：服务端声明 briefingEvidenceSupplementVersion=1.0 后，非资讯生成任务才注册 request_briefing_evidence。检索关闭/计算完成后一次申请、最多两次只读工具调用，理由非空且最多300字；原55秒、8次模型调用及工具总预算不变。仅允许既有 task_context 的 profiles/profile_read/dataset_search/dataset_read 和来源检索读取；仍重新鉴权、使用原固定来源，不能重新选题或重复计算。预算按尝试内工具调用计数，失败读取也计入；补证申请不授予来源权限。旧平台不开放补证或文字计算能力。补证理由进入当前工具结果，不声称新增了跨任务持久化的语义审计账本。
- BQ-04：建立三岗位×四种决定共12个合成案例；含同问题合并、口径缺失、无权门店、不凑卡、待核对不等于逾期、确认不等于到账。提供观测输入评分器和错误注入测试。默认报告12项 NOT_RUN、语义质量 NOT_ASSESSED；它证明基准就绪，不是模型选题达标。
- 共享表达规范升至1.5.0；能力协商对旧服务端明确拒绝不支持的文字计算交付，不静默改成 DATA。

## 可运行检查

从项目根目录执行：

```bash
npm run build:engine
node --test engine/tests/briefing-generation.test.mjs engine/tests/briefing-evidence-budget.test.mjs engine/tests/briefing-topic-strategy.test.mjs engine/tests/briefing-delivery.test.mjs engine/tests/briefing-presentation.test.mjs engine/tests/harness.test.mjs tests/briefing-quality-baseline.test.mjs
python3 scripts/with-test-postgres.py ./apps/api/mvnw -B -f apps/api/pom.xml -Dtest=GovernedFusionIntegrationTest,BriefingTextCalculationIntegrationTest,BriefingTaskPromptTest,BriefingEditorialPlanTest,BriefingPresentationIntegrationTest,MetricCatalogTest test
node --test tests/contracts/*.test.mjs
node --experimental-strip-types --test tests/briefing-content.test.ts tests/briefing-presentation.test.ts tests/briefing-reading.test.ts
npm run build
node scripts/evaluation/briefing-quality-baseline.mjs
```

定向结果：API 40项、引擎/Harness及基准检查68项、契约150项、前端内容/呈现/阅读13项通过；前端及引擎构建通过。API使用临时独占PostgreSQL，结束即清理；Harness注入合成模型、仅访问本机假平台，无服务商请求。不同测试有重叠，不合并成独立业务案例数。验证了正常文字依据、自动选题必须计算、幂等、不同任务/尝试与篡改拒绝、撤权/清理失效、融合口径不变、补证额度及补证中撤权拒绝。

过程发现并修复：Harness工具schema不接受maxLength，改为工具入口实际校验；评分器错误注入测试曾误共享输入数组，改为独立输入；契约补充无计算ID时不得携带计算范围、ID与哈希配对。融合旧样例缺少岗位版本、编辑计划与版式参数，补齐真实前置后通过，未降低生产门禁。

扩展回归边界：曾运行 BriefingDatasetGenerationIntegrationTest，其19项中2项未通过：textInsightCanUsePinnedDatasetEvidenceWithoutInventingFileSource 缺编辑计划；automaticDatasetBatchRunsActualHarnessAndPublishesPrivateCard 的旧合成作者没有匹配当前岗位/整批规划/已发布指标前置。它们不在上述全绿定向集内，本轮未改这些旧样例，不能宣称所有自动生成端到端回归全绿。后续应更新这些样例及真实服务商验证，不以关闭规划或指标要求解决。

## 十二案例基准用法

输入位于 `tests/fixtures/briefing-quality/baseline.json`，执行脚本不调用网络/模型。默认生成 `.local/briefing-quality/baseline-report.json`，12项未运行。

可选传入本地观测数组文件：

```bash
node scripts/evaluation/briefing-quality-baseline.mjs <本地观测JSON路径>
```

每项字段：caseId、execution（SYNTHETIC_REPLAY/REAL_MODEL）、traceRef、decision、cardCount、reads、gapReason、businessType、calculationVerified、sources、assertions、claims。claims逐条含factId/value/unit/period。评分仅比较结构化观测与预期：决定、数量、权限范围、数字/单位/期间、必要依据、禁止断言、补证预算；traceRef真实性及自然语言业务价值仍需人工核对。`REAL_MODEL`标签由观测者提供，不能用标签自行证明调用发生。不得用预填标准答案的评分结果冒充真实模型验收。
