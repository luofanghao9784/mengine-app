# 画报生成入口卡片化（2026-10-02）

## 用户确认

- 生成更多和说明成为一张标准 1×1 画报卡，位于网格末尾。
- 生成中呈现渐变流光占位卡，成功后占位卡原位呈现新画报，末尾保留生成入口。
- 首期取消页面自动生成设置。所有已有暂停空间也恢复自动生成，新空间继续默认开启。

## 实现

- 生成状态由画报页面统一持有，切换推荐筛选或刷新推荐列表不重发生成请求。手动任务以及页面打开后观察到的自动任务使用相同占位与交付流程。
- 生成卡作为网格末尾项参与排版，不用它们回填旧卡的空洞，避免新增卡改变已有内容布局。占位和交付卡保持同一批次节点；真实内容沿用现有卡片自适应尺寸。
- 轮询保留已有内容，成功后读取经权限校验的真实画报。和推荐列表按卡片 ID 去重；新卡仍在本页时，刷新不让它重复出现。接口仅保留最近五次空间生成摘要时，对仍在展示的较早批次单独核验，避免卡片消失。读取批次和卡片不创建任务。
- 排队/运行显示流光。等待资料、额度、模型能力显示实际状态，可以取消。失败、无新内容和取消结束加载，在入口说明结果；生成成功但读取失败可重新读取。网络结果未知保持原请求 ID 和内容进行重试。减少动态效果时禁用流光动画。
- `V48__resume_briefing_generation.sql` 仅将历史 `enabled=false` 的策略恢复为 true，并递增 revision。保留来源指纹、权限 epoch、历史批次及预算边界；重复执行无额外改动。服务端保留原有独立策略能力，首期页面不再提供开关。

## 验证与运行边界

- 构建：隔离工作树、main 工作区和包含并行资料库/账号改动的组合预览均通过。
- 浏览器：5 项合成回执专项，覆盖桌面和手机方格、占位节点替换、旧卡稳定、末尾入口、重复读取去重、等待/失败/取消、相同请求重试、读取失败重读、权限撤销、自动生成和减少动态效果。较早批次读取另在同组回归覆盖。
- 布局：2 项检查覆盖不回填旧卡空洞、真实卡片扩展、1–5 列布局和入口保持末尾。
- 后端：`BriefingGenerationIntegrationTest` 25 项通过，包含 V48 存量恢复、幂等性、权限、预算、取消及现有状态机。使用隔离临时 PostgreSQL 与合成结果，未调用真实模型。
- 本机 `55167`：只读核实 1 条策略、0 条暂停，现有空间已经开启，不需要恢复数据写入。前端实看生成入口约 285×284px（1×1）、说明与历史失败状态可见、自动设置消失、没有横向溢出及控制台错误。
- 运行实例仅更新工作空间前端入口和哈希资源，保留并行资料库工具栏与账号入口调整；后端未重启、数据库未改、未主动触发真实生成。V48 已加入源码，后续常规后端升级时执行；当前实例的默认开启要求已由只读核实满足。
- 备份、精确源码增量、构建源码归档与资源哈希位于运行实例 `.local/frontend-overrides/generation-cards-*`。回退时恢复对应 `workspace-index-before.html` 并保留旧哈希资源。源码已同步 main 工作区，尚未提交或推送；实现完成不等于用户体验确认。
