# 本机自动功能开启

用户要求开启自动取数、画报等现有业务功能。当前企业“萌物志宠物服务工作室”，本机 `.local/trial`。

## 已生效设置

- 经营数据库经正式权限接口启用每小时取数，Asia/Shanghai；连接 READY、已有下一次计划。即时重复采集不作为开启调度的必要动作。
- 实例配置 `automaticWorkEnabled: true` 显式覆盖本机手动模型验收限制，启用企业分析、经验发现/分析/通用化、事件驱动画报与持续计划执行。通用化仍须满足各来源资格和既有授权，启用工作进程不构成经验准入或跨企业发布。
- 通过既有私有 `analysis-runtime.json`、`briefing-runtime.json` 启用分析素材接口与每日画报运行能力。每日画报的订阅必须由企业负责人在指定空间设置；总部支持访问不能冒用负责人，当前未代为建立每日订阅。
- 明确配置公共联网搜索为 bing-rss，使用本机已有代理。仍沿用公开关键词、网页访问和企业/空间隔离限制。
- 安装资料解析固定依赖；沙箱只读许可兼容当前 Python 基础运行目录，其他任务文件、写入与网络隔离保留。当前未验收 OCR 外部工具。
- `.local/start.sh` 保持既有百炼 live、测试短信、采集适配器配置，普通重启保留全部上述设置。Key 不写入本说明。

## 实测与边界

启动器/模型边界测试 28 项、文本解析与沙箱隔离 2 项通过。服务重启后安全提取 API 进程的布尔开关核对，企业分析、经验发现/分析/通用化、自动画报、计划、素材、每日画报、解析与联网均为 true（不打印环境凭据）。

实际派发了两项自动画报，经验发现已有候选；企业分析为 IDLE，当前没有企业资料分块，因此开启不代表已有分析结果。画报及经验的最终成功仍以真实任务回执为准，不能用开关开启冒充交付成功。

后续状态核对已有一项画报 SUCCEEDED；另有一项 TASK_LIMIT 失败及一项在运行。保留失败状态，不宣称所有任务均成功。
