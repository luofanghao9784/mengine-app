## 已核实的现状

- 前端为 React/Vite，构建包含客户端、企业管理端和总台。当前本地启动器使用 Vite preview 并代理 `/api`；云端需提供正式静态资源与 API 反向代理。
- API 为 Spring Boot，项目要求 JDK 21；独立引擎的 package.json 要求 Node `>=24.20.0 <25`。README 的当前数据库基线为 PostgreSQL 18，另有 Python 解析/OCR 依赖。目标环境需核对版本可得性与兼容性。
- PostgreSQL 保存业务、身份、任务及会话；原件使用私有文件目录。数据库与私有文件都需持久化和备份，不能只复制前端或数据库。
- API 默认仅监听本机，Cookie 默认 Secure、HttpOnly；云端应保持 HTTPS 和同源 API，核验两个账号体系及 CSRF。
- main 有尚未提交的业务变更，最新定时画报记录说明本地运行至 V98。发布前需核对并固定精确源码、构建产物和数据库迁移，不将当前 HEAD 当作本机全部运行能力。
- 本地已有小时采集与每日画报。迁移切换必须明确唯一调度执行端，避免本机和云端同时运行。

## 已发现的云端适配项

1. `workers/parser/sandbox.py` 明确拒绝非 darwin 平台，并依赖 `/usr/bin/sandbox-exec`；`LocalTableCalculator.available()` 同样检查此程序。Linux 部署前需实现并验证等效隔离后端，覆盖解析及表格计算，不能以取消沙箱绕过。
2. 引擎已有 Linux rootless OCI 执行实现及历史本地验证，目标节点仍需验证资源限制、取消、网络隔离和失败清理。该执行器不自动解决 Python 解析器的兼容问题。
3. 初查没有发现完整云端部署编排。需补充进程托管、反向代理、私有配置、持久目录、日志轮转、健康检查及发布回退流程。
4. 当前本地记录明确完整恢复验收尚有限制。迁移前须检查备份覆盖全部新增模块，并在独立环境验证恢复，不把已有备份文件视为可恢复证明。
