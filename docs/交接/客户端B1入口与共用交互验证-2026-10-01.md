# 客户端 B1：入口与共用交互验证

日期：2026-10-01。起点：`main` 的 `3634afa`；任务分支：`codex/platform/client-b1-interaction`。用户在统一任务书确认后要求“开始实施”，本批执行 B1（CUI-01/09、CUI-02 基础），实现决定记为 DEC-118。B2—B6 尚未实施，自动验证不等于用户人工验收。

## 本批改动

- 主导航继续为会话、智能画报、资料库；更多入口保留工作空间、我的计划及当前企业获权管理。我的档案与偏好移入个人设置，仅展示本人档案；企业档案留在企业端。单企业显示名称，多企业只在顶部切换。
- 管理链接保留当前企业及可映射的空间/来源；返回链接只接受白名单对象标识和确切版本，不带正文、草稿或任意外部 URL。无有效返回引用时进入该企业智能画报，管理资格不触发静默跨企业切换。
- 资料库阅读复用会话的 DeckCard 和布局、调宽、折叠、全屏逻辑；正文保留，资料属性与历史版本按需另开卡片。会话来源属性按引用 ID 配对，关闭属性不关闭来源正文。
- 浏览器标签页内按账号、企业和对象保存视图状态：资料筛选、阅读版本、打开的来源/属性卡、卡片宽度和顺序、纵向阅读位置。回到卡片带时重新展开原活动卡。会话输入继续复用原草稿机制；正文、权限及执行回执重新请求 API，不从视图缓存恢复。退出、账号变化和撤销企业成员身份清理相关视图状态，迟到的清理回调不能再写回失效身份。
- 客户端经验入口及旧路由被收起；旧链接提示暂未开放并返回画报。反馈表单不再整理或打开经验候选；客户端反馈 API 在校验身份后拒绝候选动作，历史候选回执在服务端分页前过滤。内部服务和经验历史保留，原有授权内的引擎经验使用不变。
- 不新增数据库迁移、不变更引擎协议；反馈契约保留历史种类，补记客户端 `409 EXPERIENCE_CLIENT_DISABLED`。旧经验 UI 验证脚本改查未开放提示；经验种子验证改由 API 建立候选，避免用已撤出的客户端入口。

浏览器主路径：个人设置入口 → 真实上传两版合成文件 → 固定版本阅读 → 属性卡打开/关闭 → 全屏与 Escape → 浏览器刷新恢复旧版 → 企业管理返回保留搜索 → 会话引用属性 → 管理返回保留未发送草稿与来源卡 → 已接收的 RUNNING 任务不锁导航 → 双企业不同管理资格 → 旧经验链接失效。返回后活动卡完整展开另有断言。

解析片段和任务 SUCCEEDED/RUNNING 状态由脚本在自有临时库明确注入，证明的是交互及接口读取，不声称实际解析器或模型完成了业务任务。文件上传、版本查询、身份、管理返回和权限接口使用真实服务。手机号采用本地合成短信，未发送真实短信、未调用云模型，未导入 9POP 私有演示包。

本机证据位于 `.local/client-b1/`（result.json、桌面/窄屏截图）、`.local/phone-flow/`、`.local/client-b1-*.log` 和 API 的 surefire 报告；这些目录不提交。旧版全量 Agent/三端脚本没有在本批重新完整执行，其历史验证结论不升级为当前版本的全量证明。
