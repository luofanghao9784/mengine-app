# M4-A1 会话与本地任务验证

2026-09-23，基于 M3-A1 提交 `24bb955f7843919cb5670ea9cb7930ad217807a5`，独立分支 `codex/platform/M4-A1-conversations`。只使用新建本地环境的合成账号和文件；此前任务目录、数据库与试用端口保留。用户确认先完成本地能力；未调用云模型、未导入客户数据、未发邮件、未部署或合并主线。

## 交付范围

真实客户端新增“会话”入口：发送后建立私人会话，选择获准资料范围，后台查询关键词并给出固定版本引用；支持任务取消、明确重试、刷新后恢复草稿和不确定发送、服务重启保留会话。会话归属共享空间也不向同事、企业管理员或总台公开。

独立引擎 0.2.0 提供经服务间密钥保护的本地来源结果协议；平台持有授权、检索、任务和引用事实。界面明确“本地资料检索 · 未调用模型”。这是 M4-A1 首个本地切片，**不是完整 AI/Agent 或 Harness 验收**。实现边界、取消语义和第三方核查见[技术说明](../技术/M4-A1会话与本地任务边界.md)、DEC-056。
