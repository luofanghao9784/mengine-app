# 画报表达与模型版式选择 · 2026-10-06

沿 CUI-05、AI-11—AI-13、DASH-01—DASH-04。用户确认采用“模型选表达＋模型组合版式＋系统验证和渲染”，本轮在主目录 main 顺序实现。

## 原问题与交付

真实画报只交付 GROUPED_BAR，前端固定为 columns；五类标签没有完整承接 Demo 的多种内容表达。本轮保留核验计算协议，增加可选 presentation（briefing-presentation-v1），将数据依据与视觉选择分开：

- 数据表达：两期分组柱形、哑铃对比、增减条、本期数值排序、精确表格。重点数字从核验总计或指定真实分组取本期值、差额、变化率，可与图表组合；不接受模型填入数字。
- 内容组合：分析分区、行动步骤、方案对照、引用来源封面。模型引用已有 analysis 的段落索引与语义角色，不能通过排版字段增加新的事实。完整阅读保留未选段落、全部分组和来源证据；卡面只显示有限段落／分组并提示详情范围。
- SOURCE 是引用依据封面，不是产物生成成功证明。未接入真实文件缩略图与通用成果预览；无来源不补造封面。资讯沿现有原文配图链路。
- 图表依据仍为完整固定快照／获权文件两期计算。尚不支持以两期合计生成长期趋势、占比、漏斗或目标进度。后续须先增加相应核验计算，再开放表达。

## 验证与权限

平台先执行现有企业／空间／任务／来源授权，再校验版式、数据适用性、真实分组及段落索引。STEPS 仅用于建议的行动／注意项，COMPARISON 仅用于洞察／建议的实际方案。非法类型、越界／重复段落、未获权分组返回可纠正的 BRIEFING_PRESENTATION_INVALID。字段不接受 HTML/CSS/JS、图片 URL 或任意数值；不开放模型代码执行。

请求重试必须复用同一内容和版式；改版式不能覆写已准备的附件。内容去重继续使用核验来源／计算，视觉选择不参与指纹，不能换图重复生成同一内容。没有 presentation 的历史附件继续读取，不修改历史内容、哈希、偏好或来源。

API 授权检查通过可选 briefingPresentationVersion=1.0 协商能力；旧 API 不向模型暴露新字段。实际 Harness JSON Schema 子集只支持单一 type、oneOf、enum 等，本轮使用其原生校验器验证，不以普通 AJV 检查替代。数组上限、文本长度和数据语义仍由平台校验。
