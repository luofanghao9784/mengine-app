## 拉取与恢复

```bash
git pull --ff-only origin main
npm run setup:git
npm ci
npm run trial:build
npm --prefix integrations/mengine-wiki ci
npm --prefix integrations/mengine-wiki run build
mkdir -p .local/handoff-download
gh release download dev-9pop-20261020 --repo luofanghao9784/dreamcore-workspace \
  --pattern '9pop-dev-20261020.tar.gz' --dir .local/handoff-download
python3 scripts/ninepop/dev_bundle.py restore \
  --bundle .local/handoff-download/9pop-dev-20261020.tar.gz \
  --directory .local/ninepop-colleague \
  --sha256 4f0b31d009e35952149ae5c2ab0a9a198c1dce9e493fa0b0f00cd395e30dfd57
python3 scripts/local/trial.py start --directory .local/ninepop-colleague --phone-local
```

要求当前项目指定的 Node、Java21、PostgreSQL18及 Maven。`trial:build` 命令依README；首次依赖需正常联网安装。目标目录必须不存在，不能覆盖已有实例。启动后使用终端实际输出的端口，不照抄发起方59339。

企业管理端为 `/tenant-admin/#tenant=04b44066-ceb7-46dd-af0b-f5328cc6ceb3`，员工端为 `/workspace/#tenant=04b44066-ceb7-46dd-af0b-f5328cc6ceb3&view=briefing`。企业管理端默认新版，不加旧版参数。
