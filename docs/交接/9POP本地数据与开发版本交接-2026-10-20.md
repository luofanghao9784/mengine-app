代码位于 `main`，本次冻结版本同时以私有 Release `dev-9pop-20261020` 标记。只用于获准同事在本地调试，不部署或回写云端。

## 拉取与恢复

```bash
git pull --ff-only origin main
npm run setup:git
npm ci
npm run trial:build
npm --prefix integrations/mengine-wiki ci
npm --prefix integrations/mengine-wiki run build
mkdir -p .local/handoff-download
gh release download dev-9pop-20261020 --repo dimmm1125-coder/dreamcore-workspace \
  --pattern '9pop-dev-20261020.tar.gz' --dir .local/handoff-download
python3 scripts/ninepop/dev_bundle.py restore \
  --bundle .local/handoff-download/9pop-dev-20261020.tar.gz \
  --directory .local/ninepop-colleague \
  --sha256 4f0b31d009e35952149ae5c2ab0a9a198c1dce9e493fa0b0f00cd395e30dfd57
python3 scripts/local/trial.py start --directory .local/ninepop-colleague --phone-local
```

要求当前项目指定的 Node、Java21、PostgreSQL18及 Maven。`trial:build` 命令依README；首次依赖需正常联网安装。目标目录必须不存在，不能覆盖已有实例。启动后使用终端实际输出的端口，不照抄发起方59339。

企业管理端为 `/tenant-admin/#tenant=04b44066-ceb7-46dd-af0b-f5328cc6ceb3`，员工端为 `/workspace/#tenant=04b44066-ceb7-46dd-af0b-f5328cc6ceb3&view=briefing`。企业管理端默认新版，不加旧版参数。

恢复后每人随机生成新的本地密码，账号清单仅在 `.local/ninepop-colleague/accounts.json`，不提交或贴入共享文档。原手机号保留作登录标识；云端密码、原本地密码、会话和桥接密钥不随包传递。新版数据服务使用重新生成的本地桥接密钥。

## 接入方式与调试边界

冻结数据已经进入正式平台表及新版数据基座，无需重新采集才能打开页面、读取知识或跑已实现计算。原始云端接入方式仍是经授权的只读字段投影、完整分页、历史归属和门店/敏感类别过滤，再登记本地来源、治理、同步到获准空间。实现见 `scripts/ninepop/README.md`、`scripts/ninepop/local_connection.py`、`ssh_reader.py`、`full_collector.py`、`history_scope.py`、`scoped_scene_export.py` 和第三/四阶段 handoff。

本包不安装可运行的云端采集器、不复制SSH/MySQL凭据、不重新下载数据。云端连接密钥清空、自动采集/计划/画报调度关闭，模型模式off。要测试真实模型或再次取数，另行配置本机私有凭据并确认操作范围；不要直接恢复旧私有连接文件。

首次部署Codex与模型的通用选题、整批规划、合并、组件、交付校验见 [通用规划记录](../协作/企业首次接入/画报通用整批规划与交付校验-2026-10-20.md)。现有数据不变时，应允许返回“无新增内容”，不要为看到新卡绕过重复检查。
