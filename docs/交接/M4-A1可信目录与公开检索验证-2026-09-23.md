# M4-A1 可信目录与公开检索验证

日期：2026-09-23。第四个本地切片；按用户“继续”执行。沿用 Spring Boot 平台、独立梦核引擎、React 和无云模型配置的安排。业务依据 AI-01—AI-04、AI-12—AI-13、POS-05 不变；实现决定见 DEC-059 和[技术边界](../技术/M4-A1可信目录与公开检索边界.md)。

## 交付范围

- 随引擎发布的可信目录：模型可以发现可用能力、按精确版本启用，验证 SHA-256；启用前隐藏公开工具，并在实际执行时再验授权。陌生依赖安装仍未交付。
- 可选公开检索输入：独立于工作要求保存，参与请求幂等；模型无权改写联网查询或直接传任意 URL。
- SearXNG HTTP 适配、受限 HTTPS 网页读取、DNS/IP/跳转校验、取消与撤权传播、真实文本摘要和来源快照。
- 网页来源区分检索线索与已读页面；保留时间、截断和所用能力版本，普通文本显示且可刷新恢复。
- V9、Agent 协议 1.1、会话 OpenAPI 1.2.0、引擎 0.4.0；已有本地资料检索仍可使用。目录元信息不与前端/平台具体版本清单耦合。

## 复验与证据

在本任务独立 worktree 中安装根及引擎依赖、运行 `npm run setup:parser`，使用临时 PostgreSQL 和合成账号/资料。没有修改原试用库，也没有新增云模型、邮件或付费搜索调用。

引擎验收包含内网、保留 IP、IPv4 变体/IPv6 映射、混合 DNS 答案、逐跳校验、固定连接地址、压缩/格式/大小限制、文本截断、能力文件篡改和符号链接、未启用能力强行调用、附加模型查询、任意 URL、跨任务句柄、并发去重、撤权中断正在读取的请求。

浏览器合成工作要求包含私密标记，检索 HTTP 实际请求只含单独填写的公开主题；确认标记未出现在检索请求中。来源经平台事务保存、刷新可恢复，普通文本中的诱导安装语句未变成执行动作。此处模型是固定传输夹具，不据此推断真实模型抵抗提示注入或自主研究质量。

本地证据在 `.local/m4-agent/result.json`、`research-desktop.png`、`research-mobile.png`；实际模型 HTTP 合成调用共 9 次（原计算 3、取消 1、研究 5），`cloudModelCalled=false`。截图经桌面/390px 窄屏查看，页面无横向溢出。临时服务与数据库由本次脚本清理。

另使用正式 `PublicReader`（真实 DNS、固定 IP 的 HTTPS 请求，无测试 transport）读取 `https://example.com/` 成功：标题 `Example Domain`，文本 127 bytes，SHA-256 `feb057ddba5ac313506909af05c17370808a81030f057346499d045c25534dbf`。仅证明一次真实公开页面读取，不代表搜索供应商或云部署通过验收；内容后续可能变化。
