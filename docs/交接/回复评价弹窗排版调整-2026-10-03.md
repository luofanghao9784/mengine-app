# 回复评价弹窗排版调整

根据会话回复下“改进建议”的页面批注，调整该弹窗的排版和位置。

- 两种评价采用整行可点击的单选项，按钮与文字水平对齐，并显示选中状态。
- 补充建议独立标注“可选”，底部以蓝色主按钮提交；已有评价的撤销入口保留在底部左侧。
- 弹窗宽度为 320px，窄屏保留两侧 12px 间距；从评价图标左侧对齐，避免向左覆盖会话列表。
- 默认评价、提交载荷、修改、撤销和不确定结果重试规则沿用原实现。

实现涉及 `src/conversation/ReplyFeedback.tsx`、`src/conversation/conversation.css` 和 `src/shared/ActionPopover.tsx`。共享弹窗增加可选 `align` 参数，原有调用默认仍向右对齐。合并时保留了同时进行的会话标题单行省略样式与完整标题提示。

验证完成：

- `npm run build`、根目录 `npx tsc --noEmit` 和相关路径 `git diff --check` 通过。
- 现有“完成回复集中操作，点踩再展开建议，评价加载不占正文”E2E 通过，覆盖提交和其他回复菜单。
- 临时合成检查在 Chromium、WebKit 的 1324px、390px 视口共 4 项通过，验证控件对齐、弹窗边界、整行选择、创建、修改、撤销及 Escape 关闭。
- `55167` 本地验收实例已更新工作空间入口，实际页面确认新布局；现场仅展开弹窗，没有提交真实评价。
