# 模型治理与知识来源实施计划

> 执行采用superpowers:subagent-driven-development，按任务完成实现、相关测试和独立审阅。

**Goal:** 让口径与语义检查进入真实模型链，并让三类知识来源统一受AI可用状态约束。
**Architecture:** 复用治理模型任务与原生发布，扩展表/资料模型审阅及自动调度；知识服务只投影当前合格来源，不复制原始数据。
**Tech Stack:** Java 21、Spring Boot、PostgreSQL、TypeScript、React、现有模型运行时。
**Spec:** ../技术/模型治理与知识星链统一来源设计-2026-10-27.md

## 全局约束

企业/空间/资料权限、当前版本、逐批硬检查和引用证据必须保留。模型不扩大权限、不执行来源指令、不伪造已确认事实。已授权全自动技术选择自主完成，生产部署另行授权。本任务基于独立既有克隆feat/model-governance-knowledge-sources，认领Issue #207。

- [x] 扩展GovernanceModel支持MATERIAL授权片段，保留DATASET无原始行契约。
- [x] 增加可验证的模型质量评审、明确程序检查与模型检查，拒绝引用不实、硬规则失败却宣称通过。
- [x] GovernanceModelService提供materialAnalysisReady(actor,tenant,material)；analysisReadiness对结构化数据考虑当前模型评审。
- [x] 对已有自动许可企业补齐当前版本的模型任务和安全自动发布，幂等且不自动重放结果不明调用。
- [x] 覆盖材料模型调用、评审校验、缺模型与硬校验失败、版本变更、幂等和权限测试。

## Task 2：统一知识来源与界面

- [x] NativeKnowledgeService所有知识来源受上述结构化/资料就绪接口约束，保留已有AI经营知识及合法成果。
