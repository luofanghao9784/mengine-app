日期：2026-09-23。第三个切片已实现本地能力并完成合成联调，待审查；不是整个 M4 完成或真实模型验收。

## 范围与代码

用户要求“继续下一步”，沿用尚无模型配置、先做本地能力。本轮将独立引擎接到 Spring 持久任务及 React 会话，加入 DeepSeek HTTP 适配、逐步资料授权、取消传播、回复/来源/工具产物保存与私有下载。没有外部模型调用、客户资料、邮件外发或生产部署。

分支 `codex/platform/M4-A1-agent-gateway`，从前序 `85283236952013365830bc17193df7e6fd4f598b`（Draft PR #11）建立独立 worktree。依赖前序未合入 PR，main 的完整差异包含历史批次。原目录的用户调研文档及既有 55362 试用服务保持原状，不能把那个旧页面当成本轮 Agent 验证环境。

取消验证在模型 HTTP 已发送响应头、仍挂起正文时执行：等待网页实际显示 RUNNING，再点击取消；平台返回成功，供应商夹具实际收到连接关闭，状态保留 CANCELLED，没有回复/产物和自动重试。数据库另验撤权/停用、过期/替换执行凭证、精确来源集合、无效摘要原子回滚、等待行锁后过期拒绝、私人下载以及验证/真实执行模式隔离。引擎独立测试验证撤权中止模型请求、输入输出边界、超时/重定向拒绝及重复执行拒绝。

联调修复：回调错误统一纳入受控异常响应；活动权限检查在完整事务退出后转换为不可继续，避免嵌套回滚吞掉结果；测试夹具读取所有返回片段，避免只算首片段；任务操作冲突后刷新当前状态，但不会替用户自动重试。

截图和合成结果位于本工作树 `.local/m4-agent/`，不提交运行日志或凭据。普通 `trial:start` 仍提供无模型的本地资料检索；不会因继承环境变量而意外开启模型。Agent 合成入口只存在于 `engine/tests/fixtures/`，正式引擎没有测试回答回退。

## 复验

从仓库根执行，先具备 README 所列 JDK 21、PostgreSQL 18、Node 24 及 macOS 本机解析依赖：

```bash
npm ci --ignore-scripts
npm ci --ignore-scripts --prefix engine
npm run setup:parser
npm run build
npm test
npm run test:engine
npm run test:contracts
npm run test:api
npm run test:agent
npm run test:conversations
npm run test:git
npm run test:trial-safety
```

`test:api` 构建最新 API jar；`test:agent` 使用自己的临时数据库、端口及合成账号，关闭时只清理所属进程。测试脚本不读取真实模型密钥。上述检查已按本轮变更范围执行；API 先跑全量，再对最后修改的能力状态运行相关检查，没有把不同时间的相同测试重复计数。

## 未完成与下一步

真实模型尚未调用，当前不承诺模型理解质量和费用计量；仅落地供应商响应的 token 用量保存。真实模式只允许查找已解析资料片段，代码工具只在本地合成验证中开启；本轮不是云端任意代码执行验收。当前任务没有跨轮完整会话上下文、流式 token 或正式成果编辑/共享。
