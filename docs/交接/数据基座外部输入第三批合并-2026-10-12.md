2026-10-12。本地实现与合成验证完成；未提交、未部署、未连接客户来源、未调用付费模型。沿单 main 在本目录处理，没有新增 worktree 或并行代理。

## 本批范围

按调查后的用户确认，数据基座承接梦擎的外部输入：连接在部署工具配置，字段含义由部署时的外部 AI（如 Codex）调查并记录，不使用产品内置 AI 生成。人工建表不需要。重合功能按同事版的资产/来源组织吸收，权限和采集执行沿当前系统。

- 企业导航改为“数据基座”，提供“数据资产”“数据来源”入口；保留更新状态、最近成功、业务覆盖时间、只读预览、频率/自动开关、立即更新及撤下清理。
- 数据详情展示部署字段说明：类型、含义、单位、依据与来源有据/部署推断/尚不明确。旧来源未提供时如实说明，不自动生成。
- 部署 manifest 增加可选 `fieldDefinitions`；V114 迁移增加字段存储。字段说明与数据集身份绑定，语义变更使用新 ID，历史任务不被新定义覆盖。清理正文同步擦除字段说明。
- 梦擎现有数据工具在相同来源、权限和列分页内接收说明，仍标记为参考输入。无凭据、SQL、模型生成或口径编辑接口。
- 部署采集器支持 SQLite / PostgreSQL / MySQL 固定表或视图投影，保留列白名单、精确数值和 NULL，超限整批拒绝，按 tenantId+connectionId 分发多个已部署来源。PG/MySQL 验证 TLS 和只读事务。
- 继续复用当前调度、版本、租约、失败保留旧数据和撤权围栏；未搬入同事版内存同步调度、企业管理员读私有资料、角色分级或双人审批。
- 元数据列表、统计、连接可见范围和任务搜索补充当前空间权限函数过滤，避免旧成员关系绕过最新空间读取限制；未启用真实企业的新权限开关。

当前源库只读投影由部署明确指定，不自动发现后将整库授权给模型。资料库文件的独立授权也不会自动给出业务数据集权限。现有 9POP 专用采集器继续保留，本轮没有替换其实例配置。

## 交付边界与后续部署

本次完成代码合并和本地验证，不等于客户来源已经部署或业务口径已经核实。真实环境接入时需使用该环境的完整连接清单，避免遗漏旧来源；明确网络、只读账号、源视图与目的空间并保存固定版本回执。一个实例只有一个采集可执行入口，既有专用采集器与新增通用来源需要部署侧明确分发，不可直接覆盖旧入口。

通用读取器是全量快照，不做 CDC、自动类型漂移判断、自动币种/单位转换或 SQL 生成；无法证明业务截止时间时维持未知。字段含义改变需新身份，可能影响原数据选择配置，部署时须一起核对。旧数据集保持旧解释直到按明确计划替换；不对现有 9POP 资料隐式补写语义。
