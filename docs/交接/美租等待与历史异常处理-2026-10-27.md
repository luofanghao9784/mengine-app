# 美租等待与历史异常处理

用户授权处理美租引擎的等待和保留异常，认领 #149。本轮只操作本地实例，未操作生产。

## 处理依据

处理前十二条等待全部为 PARTIAL 任务：八条关联已清理来源，四条此前分析缺方法或交付不完整。二十二条保留异常包括十六次采集失败、两条来源已删除任务和四次已清理来源的治理失败。

已清理来源不再重试。采集失败只有同一企业、同一连接存在后续成功记录才归档。其余分析先补齐可核验的来源记录 COUNT 方法，按快照原值分组，不解释合同原始状态码、不把记录数当有效合同或入住数、不进行跨表去重或金额外推。新增二十个私有固定方法，原财务八个方法保留；重新分析已成功出卡。

另一重试完成真实计算及服务端去重，但因此前工具调用失败，运行时仍给出 PARTIAL。新增批次收敛判断：必须同一企业、实际执行人、当前 attempt_id 上有 TASK_BRIEFING_DUPLICATE 成功审计，以及 deliver_briefing 成功回执，且没有错误码和未决核对，才能按 NO_NEW_CONTENT/DUPLICATE_CONTENT 结束批次。模型文本、别的任务审计和无回执的部分完成不能触发此判断。任务的 PARTIAL 执行事实保留。本地已凭同一实际回执纠正此次重试批次的分类，并单独归档该诊断。

## 归档方式

沿用 engine_diagnostic_archives，不删除或伪改失败记录。V177 为 COLLECTION 增加诊断种类及 engine_unarchived_collections 视图；状态、原因、完成时间精确匹配才隐藏相应历史诊断，后续新记录或新版本仍显示。遥测及平台待处理列表使用同一视图。

本轮冻结记录清单后归档三十五条：十五条任务（含新确认的重复内容诊断）、四条治理失败、十六条采集失败。写入独立操作编号和管理审计。执行状态不被改为 SUCCEEDED，旧来源和原始业务数据不被恢复、删除或改写。

## 验证与恢复

OperationsIntegrationTest 十六项、BriefingGenerationIntegrationTest 五十九项全部通过，Maven package 成功。新增测试覆盖历史失败仍保留、错误企业的归档不生效、后续新失败和改变的记录版本重新显示、真实去重回执与模型自述的区别。

本地 V177 生效后，实际账号遥测为 waiting=0、failed=0、unknown=0；浏览器引擎概览通过，无脚本错误。自动接入维持每小时开启。本轮相关私有证据、原配置、数据库备份、三十五条归档对象及操作编号在 .local/work/engine-resolution/。

恢复诊断展示可按本次 operation_id 删除诊断归档；原始执行记录始终保留。固定方法可恢复私有配置备份。代码提交任务 PR 由另一维护者合并，不混入其他任务修改。
