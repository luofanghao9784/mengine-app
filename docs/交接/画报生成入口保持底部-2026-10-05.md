# 画报生成入口保持底部

用户要求“发现新内容”卡片随新增画报始终位于最底部；随后明确：追加到最后一排末尾，有剩余空间就并排，放不下才另起一排。

生成入口在逻辑列表中原本已是最后一项，但杂志布局会用小卡片补齐前面的空位，导致生成入口出现在较大的新卡片上方。新增 atEnd 放置标记：内容卡片先正常排布，入口从最后一排最右侧已占用单元之后开始放置，仅在剩余宽度不足时换行。测量高度、新增卡片和列数变化都重新计算。入口保持原有 DOM 节点，不播放从旧位置移动的补间动画。其他内容继续按原有规则补空位。
