# 画报生成入口保持底部

用户要求“发现新内容”卡片随新增画报始终位于最底部。

生成入口在逻辑列表中原本已是最后一项，但杂志布局会用小卡片补齐前面的空位，导致生成入口出现在较大的新卡片上方。新增 atEnd 放置标记：内容卡片先正常排布，入口从全部内容的最大底边另起一行；测量高度、新增卡片和列数变化都重新计算。入口保持原有 DOM 节点，不播放从旧位置移动的补间动画，避免短暂回到内容中间。其他内容继续按原有规则补空位。

验证：5 项排版单元检查通过；1 项浏览器动态检查通过，覆盖新增卡片、节点保持及 390/944/1440 宽度重排；前端构建通过。54803 工作空间入口已更新，实际页面确认入口排在新增建议卡片下方，截图 `.local/generation-tail-20261005/live.png`。没有新增模型调用。
