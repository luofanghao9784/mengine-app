## 本地复现

先在 `integrations/mengine-wiki` 执行 `pnpm install --frozen-lockfile`，需 Node 24+。根目录前端命令仍为 `npm run dev` / `npm run build`。实际业务启动配置沿 [企业接口对接](企业数据基座与总台接口对接-2026-10-13.md)，不能仅启动 Vite 就认为后端和企业绑定已配置。

```sh
npm run build
npm test
npm run test:contracts
npm run build:engine
node --test engine/tests/company-analysis.test.mjs
python3 scripts/with-test-postgres.py ./apps/api/mvnw -B -f apps/api/pom.xml -Dtest=SceneBridgeIntegrationTest,UnifiedIdentityIntegrationTest,PlatformIdentityIntegrationTest,HeadquartersSupportIntegrationTest,SceneWorkLoopTelemetryTest,CompanyAnalysisIntegrationTest test
CI=true PLAYWRIGHT_PORT=5295 npx playwright test tests/e2e/tenant-scene-integration.spec.ts tests/e2e/tenant-database.spec.ts tests/e2e/platform-engine-dashboard.spec.ts
```

Wiki 专项（在 `integrations/mengine-wiki` 下）：

```sh
pnpm typecheck
pnpm exec tsx --test apps/api/test/access-control.test.ts apps/api/test/data-reliability.test.ts apps/api/test/platform-bridge.test.ts apps/api/test/scene-foundation.test.ts apps/api/test/wiki-intelligence.test.ts apps/api/test/source-lease.test.ts
```

入口：登录 `/tenant-admin/` 默认显示新版；`/tenant-admin/?view=business#tenant=<企业ID>&admin=overview` 为完整管理功能。场景直达 `/tenant-admin/prototype/?tenant=<企业ID>` 仍需有效账号和服务端授权，不能用 query 参数代替企业访问权限。
