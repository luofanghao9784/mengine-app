# 总台企业列表简化

用户要求高效简洁、遵循整体样式并消除重复无效元素。

移除列表内重复的企业标题和逐行装饰图标；搜索提交并入输入框尾部，支持回车，状态筛选保持右侧；数据行收紧到 64px，开通时间按日期展示，精确时间仍在详情；保留企业、负责人、有效成员和服务状态列及整行详情入口。窄屏沿用有标签的数据行，并让搜索独占一行。无接口、权限或数据变更。

源码：src/platform/PlatformHome.tsx 与 src/platform/platform.css。前端类型检查、构建及 diff 检查通过。增量补丁用于并行整合。

浏览器验证：搜索无匹配、清除筛选恢复列表、整行打开企业详情及返回通过。窄屏浏览器实际 CSS 宽度 443px，document scrollWidth 与 innerWidth 相等；搜索与状态筛选分行正常。已恢复默认桌面视图，截图见[调整结果](总台企业列表简化-2026-10-04.png)。尚未进行用户人工确认。
