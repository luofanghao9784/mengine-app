# 会话联网快捷能力

用户确认以输入框“联网”快捷按钮替换“查找公开资料（可选）”表单：勾选要求本次联网，未勾选允许模型按需调用。授权范围为模型拟定通用公开关键词，内部文件、业务明细、人员信息不作为外部检索内容。

沿现有 publicQuery 字段和服务端权限校验，以 `web:optional:v1` / `web:required:v1` 表示新模式，保留旧固定检索词与网址任务。原请求指纹及重试语义不变。无联网能力或只用所选资料时不发送模式授权；当前任务补充/恢复不能通过按钮修改原任务授权，按钮禁用并沿用原状态。

Harness 根据任务服务端回传的模式开放公开关键词工具；要求联网时依次强制 activate_skill、public_search、read_public_page，并以成功搜索及原文阅读的实际记录核对完成条件。自动模式可以不使用联网；网页仍以任务来源句柄阅读，不开放任意 URL、登录、上传、Cookie 或脚本。自动模式不额外授予实验候选工具。每任务最多两个不同关键词搜索及两次原文读取。

关键词发送前拒绝显式 URL、邮箱、长号码、常见凭据标记、控制符，以及已读取内部资料中的长原文片段与结构化人员/企业名称。此检查结合模型公开检索规则；不是完整的语义脱敏系统，也不能保证识别未知的敏感实体。原公网地址、DNS、重定向、安全阅读与权限复核机制继续有效。

验证：前端类型检查和构建通过；250 项 Harness 检查及依赖许可核对通过，最后候选工具约束调整后 13 项联网检查通过。浏览器自动检查验证未勾选/勾选提交不同任务模式及旧表单移除；实际 54803 新会话输入框已核对按钮显示与切换。工作空间与 Harness 模块已部署，API JAR 未改变，既有模型手动验收与采集配置保留；重启前核对无运行任务。未新增真实模型调用或外部检索，云端实际回答仍待用户使用验收。
