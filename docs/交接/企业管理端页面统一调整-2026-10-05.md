# 企业管理端页面统一调整（2026-10-05）

用户要求按总台页面逻辑整体调整企业管理端，包含引擎仪表盘、数据库、资料库、经验库以及独立运行与用量页。本轮为现有功能布局与导航统一，不新增业务权限或执行能力。

## 页面组织

- 左侧分为梦核引擎（引擎仪表盘、数据库、资料库、经验库）和企业管理（企业概览、运行与用量、成员与空间、企业信息）。客户端返回入口及侧栏实际操作者保留。用户随后要求收敛总部提示：移除内容区总部管理模式横条，将本次操作记录移入侧栏；随后按用户要求移除返回总台企业概览按钮，原总台标签页仍保留。权限与后台留痕不变。企业端所有共用标题栏移除企业名称小字，左侧栏保留企业名称。
- 引擎仪表盘复用总台科技感汇流布局：输入、处理、输出汇入中心，保留登记执行趋势、等待/异常状态和 DNA 自进化示意。数据仅来自当前企业运行快照，可见时每 3 秒读取；当前页面最多保留 5 分钟采样。独立自进化执行器未接入，仍显示未启用，不生成虚构执行量。
- 数据库保留数据管理与数据接入，采用统一栏目切换、指标卡片和紧凑列式列表；数据集及连接详情保留原有操作。
- 资料库分为处理概览、文件与目录，回收站保留单一入口；处理列表统一列头、时间及状态展示。
- 经验库收敛为一排三个入口：企业经验、通用经验、积累与改进。前两个呈现内容资产及使用状态，第三个呈现本企业自动积累和更新过程。取消企业经验下重复的经验内容子标签；筛选、列表与空状态统一置于独立内容卡片，刷新移至标题栏。通用经验平台侧观察页保持原逻辑；版本、空间、核验来源和详情弹窗保留。
- 成员与空间统一为企业成员、成员邀请、共享空间、职责与交接四个栏目，取消独立职责链接与重复按钮导航。列表采用白底列头、紧凑行、独立筛选与分页；邀请有效期、角色和状态各列展示，空间负责人及授权成员数独立列展示。沿用现有权限裁剪、详情与变更流程；窄屏仅列表横向滚动。
- 运行与用量独立为一级页面，包含期间选择、四项指标、趋势与构成、独立每日数值卡片及折叠计量说明。概览入口统一指向该页；旧 `admin=engine&detail=usage` 链接兼容。未知回执、未配置额度和不完整计量继续明确展示。

## 权限与安装边界

普通企业管理端继续客户身份；总部支持入口继续独立标签页、实际总部身份与目标企业支持上下文。导航仍按现有职责权限裁剪，企业内容读取、写入与撤权仍由原服务端规则执行。

共享管理端外观使用 `admin-control` 样式范围，客户工作台不纳入。本地 54803 仅更新普通企业管理与总部支持两份 HTML，并新增对应哈希资源，保留其他入口已有前端产物与数据库。真实走查发现总部支持未放行资料处理只读接口、独立支持页面缺少上传队列上下文；补齐精确 `GET knowledge/processing` 白名单与按支持访问 ID 隔离的 UploadProvider。后端仍执行原企业权限；禁止跨企业、POST 与额外子路径。API 同一 V87 更新，不执行新迁移，旧 API 包保存在本地 `.local/tenant-redesign-before-api/`。源码与运行产物分开记录于本地 rollout 文件。

## 总部支持成员邀请链接修复

现象：成员邀请创建后状态为等待接受，但查看本地邀请链接提示登录失效。总部支持使用独立平台登录，原预览请求仍走普通客户端 `/api/v1/auth/phone/local-invitation/{id}`，平台 Cookie 无法通过该接口认证。

修复：总部支持预览改为当前访问上下文代理的企业范围 `GET /api/tenant-admin/v1/tenants/{tenant}/invitations/{id}/local-link`。服务端检查实际操作者管理权限、目标企业、待接受且未过期状态及本地预览开关；响应禁用缓存，读取事件由既有总部访问审计记录。普通客户端与总台初始负责人预览接口保持原逻辑；不新增权限，不把总部账号写入企业成员，不发送外部短信。

验证：4 项总部支持服务端集成测试通过，包含本地链接读取、旧客户端接口未登录拒绝、跨企业路径及跨企业邀请拒绝、过期邀请与关闭访问拒绝；1 项浏览器检查通过，确认支持页读取链接成功。真实本地只读核对用户标记的邀请确为 PENDING，没有重建或接受邀请。构建与差异检查通过。
