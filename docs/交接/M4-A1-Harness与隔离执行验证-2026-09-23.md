## 实际验证

在 macOS、Node 24.20.0、Python 3.14.6 上执行：

| 命令 | 实际结果 |
| --- | --- |
| `npm ci --ignore-scripts --prefix engine` | 锁文件全新安装成功，18 个 Harness 包版本统一；没有运行安装脚本 |
| `npm run test:engine` | 构建成功；17 项检查通过、0 跳过，其中新增 Harness/沙箱 15 项，既有 HTTP 边界 2 项 |
| 引擎 `npm run licenses:check` | 23 个生产依赖的 notices 与已安装版本/锁文件一致 |
| `npm run test:contracts` | 13 项通过；保留既有 schema strictTypes 提示，没有新增契约字段 |
| `npm run test:git` | 9 项通过 |

重点证据：

1. **真实 Harness 循环**：用仅存在于测试文件的确定性模型传输夹具发起 `read_input` / `run_javascript`；官方核心实际调度工具、保存工具结果并进入下一次模型调用。不是只检查包能导入。
2. **真实计算与产物**：三行合成 CSV 输入为 1001、-250、999 分；隔离 Node 进程用整数计算得到 1750 分，写出 `summary.json`。测试在模型工具上下文及外层 RuntimeResult 执行回执中分别读取真实文件字节，并核对行数、总额与 SHA-256。固定模型答复不承担计算证明。
3. **缺失/错误能力**：没有授予的代码工具、其他文件句柄、带额外路径字段的参数被拒绝；工具失败不伪造成功；原始异常路径/模拟凭据不进入模型历史。没有安装新工具，因此“候选工具自主扩展”仍待实现。
4. **隔离**：两个并行任务使用相同句柄但不同内容，输入和输出不串用；能读取授予副本，不能读取/覆盖真实存在的外部合成文件、通过相对路径逃逸或覆盖输入；localhost 监听器收到连接数为 0；父环境的合成密钥未继承，子进程调用被拒绝。
5. **真实取消**：等待沙箱脚本实际写下 PID 并进入长循环，再通过 Harness 的取消信号中止；原进程 PID 已不存在，临时目录清理，未发生第二次模型调用，也不返回迟到文本。单独验证执行总时间限制。
6. **上限与回执**：模型次数、工具次数、模型输出、stdout、输出数量和不安全文件类型均有失败检查；多工具调用分别保留成功/失败回执；模型未发出有效完成标记不能成功；重复工具 call ID 被拒绝，不能重复执行。
7. **兼容**：默认无模型时为配置错误；现有 HTTP 仍只声明已实现的本地来源检索，不新增 Agent /模型能力；网页与平台契约不变。

验证中的两个实现问题已修复并复验：npm peer 依赖混装通过显式版本覆盖解决；上游底层工具注册没有自动校验参数，通过适配层显式 schema 校验解决。Node 沙箱只补充实际系统运行依赖，未回退为宿主任意目录读取。
