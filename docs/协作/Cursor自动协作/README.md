# Cursor 自动协作试用

关联 [Issue #103](https://github.com/luofanghao9784/mengine-app/issues/103)。目标是快速交付可用功能，并用证据逐步补齐 B 端产品能力。此目录提供 Cursor 原生协作规则，不是新调度服务；不会接管或启动既有试点。

## 开始使用

在包含本配置的分支/独立副本打开新的 Cursor Agent 会话，输入“按梦擎标准研发流程完成：<你的需求>”。`.cursor/rules/mengine-delivery.mdc` 自动引入简短规则；协调者按需选择 `.cursor/agents/mengine-*.md`。角色数量不固定，全部继承会话模型，不修改账号设置。

首轮可以使用 [隔离试用指令](试用指令.txt)。业务开发仅处理新获准的需求，先查 GitHub 认领；不得从其他平台导入历史暂停/UNKNOWN 任务。当前配置分支不代表 main 已接受本流程。

## 交付流程

| 关口 | 必须解决的问题 | 输出 |
|---|---|---|
| 需求 | 谁在什么条件下得到什么业务结果 | 范围、验收、依据、真正待决项 |
| 产品 | 入口、操作、状态和异常是否形成闭环 | 用户路径与验收映射 |
| 架构 | 边界、权限、数据和演进是否合理 | 最小方案、契约、兼容/恢复策略 |
| 开发 | 是否实现获准范围内的真实链路 | 改动与必要测试 |
| 质量 | 独立视角能否发现正确性和架构缺口 | 问题、证据和复查结果 |
| 测试 | 实际行为是否满足验收 | 命令、退出码、覆盖与失败 |
| 运维交付 | 能否运行、观察、升级和恢复 | 配置、版本、发布/回退准备 |

测试设计和运维约束前置；实现后质量和测试可以并行。失败退回开发，复查受影响项后继续。小改动可以引用现有产品/架构结论，说明依据；不为了流程逐轮重复写文档或启动全员。

## 并行与连续推进

不设置全局并行人数上限。可写任务各有独立目录/分支和文件所有权；协调者独占任务卡、Git、公共契约和迁移号整合。只读调查可以并行。资源实际可用性、平台权限和余额仍可能阻断执行，但配置不人为设置人数上限。

常规技术选择、开发、测试修复、复查和交接自动推进。无进展时记录真实阻塞，让该任务等待事件；其他任务继续。没有新输入时不重复调用模型查状态、不重复验证未变化的代码，不编造新需求来维持运行。

若要离线后持续接单，使用原生 Projects/Cloud Agents，并为新任务配置明确的触发器。配置文件不会自行建立云端机器或后台常驻任务；不要把规则自动续跑等同于已部署 7×24 调度。首次环境安装、仓库/Secrets 权限和模型余额必须实测。

## B 端产品验收

使用 [能力检查表](b2b-readiness.template.json) 对当前版本记录证据；成熟度不按岗位数、PR 数或页面数量计算。每个功能至少检查：界面/API/数据、服务端权限与隔离、状态与异常恢复、可观测性。跨模块变更再检查架构/兼容/迁移与性能影响。

每个维度明确标记 `unverified`、`partial`、`verified` 或带理由的 `not-applicable`。关键项未验不能宣称产品成熟、可上线或客户验收通过。

## 记录与门禁

复制 [任务卡模板](task-card.template.json) 到 `.local/cursor-workflow/tasks/<task-id>/task.json`；协调者是唯一写入者。原始日志写在同目录，交接只传摘要与路径，避免复制全部历史。

交付前运行：

```sh
python3 scripts/cursor-workflow/validate.py --config
python3 scripts/cursor-workflow/validate.py --task .local/cursor-workflow/tasks/<task-id>/task.json
```

第二条只做结构和证据门禁：检查验收覆盖、当前提交、检查状态、独立审查与未验项；不能替代真实测试或人类审阅。自动化无权改动旧 CI 来绕过失败。仓库现有 `test:e2e:frontend` 仍是 SKIP 时，不能记为浏览器验证通过。

## 回退与现有状态

本套配置仅在独立试用分支生效，现有主线、预览、Grok Bot、Paperclip、DQ、OpenHands 和账号设置不变。退出本会话或切回原工作副本即可停止使用；不要清理、停用或恢复其他试点。按仓库规则由非作者审阅合并，生产发布另行授权。

官方格式依据：[Subagents](https://cursor.com/docs/subagents)、[Rules](https://cursor.com/docs/rules)、[Projects](https://cursor.com/docs/agent/projects)、[Cloud 环境](https://cursor.com/docs/cloud-agent/setup)。提示词约束不替代系统权限隔离。
