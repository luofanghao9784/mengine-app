# 任务看板

> 规则见 [协同规范](协同规范.md)。**认领 = 在下方表格加一行并推送到远端，推送成功才算。**
> 状态只用五个：`待认领` / `进行中` / `待合并` / `已合并` / `已暂停`

---

## 使用方式

**认领一个任务**（由 AI 执行，你只需要说"我要做 X"）：

```bash
# 1. 编辑本文件，在表格里加一行
# 2. 提交并推送
git add docs/协作/任务看板.md
git commit -m "chore: 认领任务 T-005 画报导出 Excel"
git push origin main
```

推送成功 = 认领成功。如果被拒绝，说明对方刚推送了新认领，先 `git pull --ff-only` 再看。

**认领前必看**：表格里是否已有同一个人认领了同一功能的"涉及范围"。有重叠就先商量顺序。

## 状态说明

| 状态 | 含义 | 谁改 |
|---|---|---|
| `待认领` | 已想好要做，还没人认领 | 任何人 |
| `进行中` | 已认领并推送，正在做 | 认领人 |
| `待合并` | 分支已推送，PR 已开，等对方合并 | 认领人 |
| `已合并` | 已进 `main` | 合并的人 |
| `已暂停` | 中途停下，原因写在备注 | 认领人 |
