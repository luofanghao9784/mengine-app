## 该价格能承载的范围

- 一个编码任务与独立 QA 顺序执行；重型 Java/API 测试、前端构建和矩阵测试放到 GitHub CI。4 GiB 并未完成云端负载实测，不承诺两个开发者并行或生产高可用。
- 控制服务、数据库与编码工作区使用不同受限系统身份及 Linux 执行隔离。不得把 Docker socket、主机 SSH、GitHub 写凭据或生产凭据交给模型；本机 macOS 权限通过不能替代 Linux 验收。
- 管理界面通过 SSH 本地转发访问；服务只监听回环地址，云防火墙仅允许用户指定来源的 SSH。对外/多用户访问前必须另行启用 authenticated/private 并验证未认证拒绝，不将 local_trusted 直接公网暴露。
- 数据库采用原生 pg_dump 每日加密上传，保留 7 日与 4 周副本，目标备份总量不超过 100 GiB；每周主机备份作为补充。自动任务、异机恢复、备份失败告警及完整文件/私钥恢复均要在云端实际验证后才启用无人值守。禁止静默退回已发现精度问题的 JavaScript 备份引擎。
- 候选主机地区为新加坡，备份桶候选独立地区；尚未登录供应商核实库存/区域支持，不承诺跨区流量免费。区域不满足或费用超限时停止在报价阶段，重新提交用户确认。
