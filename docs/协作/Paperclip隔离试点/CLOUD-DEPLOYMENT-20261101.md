## 可审查复建配置

[云端模板](../../../config/paperclip-pilot/cloud/templates/) 与 [渲染器](../../../scripts/paperclip-pilot/render_cloud.py) 只生成本地文件，不采购、不 SSH、不触碰现有主机。渲染目标必须为空且不能是符号链接；IP/主机名先校验，拒绝命令注入。输出包含固定 npm lock、恢复补丁与 helper、独立环境过滤补丁、HTTPS/数据库/备份/恢复/公司增量初始化脚本。

```bash
python3 scripts/paperclip-pilot/render_cloud.py \
  --ipv4 <已批准服务器IPv4> --hostname <已批准主机名> \
  --output <新的私有审查目录>
```

仅用于已批准的新 Ubuntu 24.04 amd64 试点主机。审查后将生成文件放到该机 `/root/paperclip-install`，在受控维护窗口依次执行 install → database → https → backup-timer。首次人类管理员由用户在浏览器完成，再使用 `/etc/paperclip.env` 的私有环境运行 bootstrap-company；最后 seal-and-reboot 会确认无运行与管理员已建立，再关闭新注册并重启。bootstrap-company 只处理专属空任务公司，发现外来/活动岗位或已有任务则拒绝，不创建或覆盖历史任务。

这些步骤在本机云试点分别真实执行；新整理的完整渲染包尚未在第二台干净服务器一键复建。局部修复后的脚本不是“第二次完整部署已验收”的证据。重新 npm ci 会重置补丁，必须停服并重新应用两个固定哈希补丁，再核对状态。恢复补丁 helper 已增加显式补丁路径与监听端口参数，用于云端 3100 端口的停服保护。
