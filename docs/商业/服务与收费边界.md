# 企业AI办公系统 服务与收费边界

> 开发资料副本：2026-09-17 从知识库导入，保留原有需求状态与编号，链接已适配本目录。来源与后续维护方式见 [资料来源与同步约定](../交接/资料来源与同步约定.md)。

> 当前商业形态为云端产品与实施、培训、陪跑相结合。服务方向已有确认，收费单价、套餐、额度与合同范围尚未冻结。本文不是对外报价单。

入口：[企业AI办公系统 项目地图](<../../README.md>)；需求：[企业AI办公系统 产品需求基线 V0.1](<../产品/产品需求基线-V0.1.md>)；立项条件：[企业AI办公系统 立项说明](<../产品/立项说明.md>)。

## 已确认的服务对象与方式

- 首批以 10—30 名实际使用者、1—2 个部门起步的小微企业为对象。
- 配置产品已有能力，搭建关键资料底座，培训并跑通典型工作。
- 上线后按固定频次复盘与培训；新增实施另行收费。具体频次、时长与包含次数待定。
- 用户本人负责技术、产品与 FDE；合伙人主要负责商务与培训。
- 基础功能降低使用门槛，企业可以先开始使用，再购买更深入的资料治理与落地服务。

## 标准服务流程与交付建议

“流程”来自已确认服务方向；下列具体交付物是本次整理建议，需转化为套餐时进一步确认。

| 环节 | 工作内容 | 建议交付物或完成依据 |
| --- | --- | --- |
| 需求诊断 | 理解一项典型工作、资料来源、参与者和当前问题 | 场景范围、现状流程与试点目标 |
| 环境配置 | 配置账号、工作空间、成员权限和已支持的工具 | 可以开始工作的企业环境及权限清单 |
| 资料底座 | 组织完成典型工作所需的资料，明确归属、版本与维护责任 | 关键资料清单、空间结构与维护约定 |
| 培训 | 教会员工提需求、调用资料、审阅成果与回存共享 | 培训材料与实际操作练习 |
| 典型工作落地 | 带员工完成真实工作，并检查是否能独立重复完成 | 可复用的工作方法、成果样例及问题记录 |
| 持续陪跑 | 按约定频次复盘使用障碍、资料质量和下一步改进 | 复盘记录、改进清单与约定范围内的培训 |
| 新增实施 | 评估新增部门、工具对接、复杂治理或业务功能 | 单独范围、报价与验收条件 |

是否需要搭建管理系统应由场景决定。不能把审批、CRM、ERP 或全企业流程重建自动纳入每个标准实施包。

2026-09-28 补充：用户认可并要求固化[输入板块业务数据获取方案](输入板块-业务数据获取与交付方案-V0.1.md)。按目标任务的数据可获得性评估交付，不以是否有 API 作为唯一客户门槛；接口、文件交付、界面自动化及最小业务记录按客户条件选择。产品沉淀可复用来源管理能力，FDE 承担约定范围的调查、映射与维护；完整管理系统建设属于本产品之外的额外业务。具体渠道、首期功能、价格和支持承诺仍按项目确定，不将全部方案自动纳入标准包。

## 收费形式的状态

| 费用项 | 当前状态 | 仍需定义 |
| --- | --- | --- |
| 产品基础费＋使用席位 | 用户初步设想，尚未确定最终组合 | 基础费包含什么、按开通或实际使用席位计费、最低购买量 |
| 存储容量与扩容费 | 用户初步设想 | 包含容量；原件、版本、索引和备份如何计量 |
| 前期诊断与实施费 | 确认需核算 FDE 和资料搭建成本，计价方式待定 | 套餐范围、交付物、包含工时、超范围变更 |
| 培训与固定频次陪跑 | 已确认服务形态，价格待定 | 单独收费或包含于服务包，次数、时长、支持方式 |
| 新增实施费 | 已确认新增实施另行收费 | 新部门、资料治理、对接或功能定制的报价规则 |
| AI 用量或执行资源费 | 需纳入成本设计，未确认对客户如何收费 | 包含额度、企业总额度或个人额度、超额处理方式 |

建议对外减少零碎收费项，先明确“开通与落地”“持续产品使用”“持续服务”“额外变更”各自的边界。最终组合应在试点成本与付费意愿明确后确定。

## 已确认的成本输入

| 输入 | 数值或口径 | 使用限制 |
| --- | --- | --- |
| 用户本人劳动成本 | 15,000 元／月 | 作为工资或机会成本计入，不能因本人承担就视为零成本 |
| 云端资源方式 | 多企业共享基础设施，数据与任务隔离 | 不能简单把一台服务器全部费用重复计入每个客户，也不能假定新增客户无边际成本 |
| 首批客户规模 | 10—30 名实际使用者、1—2 个部门 | 为测算场景，不是合同保证 |
| 团队投入资金 | 50,000—100,000 元 | 为可投入资金，不是已花费金额或客户价格 |
| 合伙人投入 | 商务与培训 | 尚无薪酬、工时与机会成本数值 |

需要补齐的成本包括：有效可交付工时、售前投入、资料整理与校验、培训准备、差旅、软件开发与维护、共享基础设施、单客户增量资源、模型与文件处理、客户支持，以及实际发生的经营支出。

## 成本计算口径建议

以下是后续更新测算时使用的口径，不是本次重新计算的金额。

- **人员单位工时成本**＝对应月综合人工成本 ÷ 合理的月有效工时。不能默认全部工作时间都可对客户收费；售前与内部维护也需要计入或分摊，避免重复计算。
- **单客户前期交付成本**＝诊断、配置、资料治理、培训准备与交付的人工成本＋差旅与实际增量支出。
- **单客户持续成本**＝共享运行成本的合理分摊＋该客户模型、执行、存储等增量成本＋约定陪跑与支持人工。
- **完整经营测算**还应包含产品研发与日常经营投入，并与单客户贡献分别呈现，避免把早期研发全部压给首个客户或完全遗漏。

部门数量可以用于报价分档，但不能单独代表资料治理难度。建议结合资料来源与质量、权限关系、流程数量、集成数量和维护责任是否明确估算工作量。成本不是售价，售价还需覆盖经营投入和合理利润。
