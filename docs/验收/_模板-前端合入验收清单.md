# 前端合入验收清单（模板）

> 用途：每个前端相关 PR / 任务合入前由开发填写、测试审查核验。  
> 规则：只写**已实际执行**的结果；禁止填写未跑的「已通过」。不粘贴凭据、客户原始资料或 `.local` 内容。  
> 硬门禁：必跑 A `npm run build` · B `npm test` · C `npm run test:e2e:frontend`。全量 `npm run test:e2e` 不进入默认 PR workflow；选跑是否触发见下文，触发则必填结果。
