## A. 定位与信息架构

### A.1 一句话

企业数据基座控制台让有权限的人：**找能力（平台登记）→ 在本企测能力 → 配流程 → 发配置 → 看运行**；企业员工在 workspace **看见真实阶段、问题与可用版本**，不把管理调试塞进会话「需你」。

### A.2 表面归属（同系统异表面 · **已锁定**）

| 页面 | 表面 | 壳 · 挂载端 | 说明 |
| --- | --- | --- | --- |
| A1 能力目录 | D′ | AdminShell · **platform-admin** | 平台能力**登记/准入**视图；只读浏览 + 有登记权可操作；**不展示客户正文** |
| A2 单模块调试 | D′ | AdminShell · **tenant-admin（可写主路径）** | 本企获准样本试跑；调试 ≠ 发布；**勿画在总台** |

## B. 横切硬要求（规范级 · 每页强制）

### B.1 三态分列（禁笼统文案）

| 状态族 | 契约键 | 回答的问题 | 枚举 / 值（英 ↔ 中） | 禁止 |
| --- | --- | --- | --- | --- |
| **任务运行态** | `runStatus` | 程序是否跑完 | 见 §E.1（queued↔等待 …） | 「全部完成」「处理完了」笼统代替 |
| **质量结论** | （建议 `qualityVerdict`） | 数据是否满足本次使用要求 | 见 §E.2（pass↔通过 …） | 用运行「成功」暗示质量通过 |
| **发布态** | `publishStatus` | 哪个版本对用户可用 | `unpublished`↔未发布 / `published`↔已发布 / `superseded`↔已替代 | 「AI 已可用」在未发布或有未确认项时 |
| **过期标记** | `isStale` | 源数据变更后旧结论是否失效 | `true`↔已过期 / `false`↔未过期（布尔；**勿**用字段名 `stale`） | 已过期结论仍当发布依据 |

规则：检查模块**运行成功**且质量**不通过** → 不得发布；界面三列/三徽章并排，不合并成一色灯。

### B.2 模拟徽章

| 项 | 约定（建议） |
| --- | --- |
| 文案 | **「模拟执行」**（模拟模块/假输出）；真实为 **「真实执行」** 或不打真实徽章、仅打模拟 |
| 位置 | 页眉右侧、任务行首列旁、调试结果卡标题旁 —— **至少一处首屏可见** |
| Token | 模拟：`--state-warn` 字 + `--state-warn-soft` 底（`.badge`）；真实成功点缀可用 `--state-ok`（勿常驻整页） |
| 报告/导出 | 同一标注必须出现在导出抬头 |

仅有两个模拟模块不能证明模型效果（评审稿 §8）—— UI 不得用「已验证」字样覆盖模拟。

### B.3 企业切换清空

切换企业或空间时：

1. 清空列表数据、选中项、筛选器、打开的详情抽屉/深链参数中的业务 id  
2. 丢弃客户端缓存的跨企结果预览  
3. 若深链指向他企资源 → **越权拒绝态**（见下），不闪一下正文  
4. 平台管理员默认**无**客户正文；需单独「数据访问权」且审计（A1 登记面亦不展示正文）

**越权拒绝态（建议）**：EmptyState 图标 + 标题「无权查看」+ 说明「该资源属于其他企业或未授权空间」+ 无「仍要打开」；技术日志仅管理视图。

### B.4 其他横切

| 项 | UI 要求 |
| --- | --- |
| 权限三分 | 按钮/菜单标注受控类型：数据访问权 / 能力配置权 / 发布权（见 §C） |
| 配置不漂移 | 运行中任务详情展示「锁定的配置版本」；切换配置横幅：「仅影响新任务」 |
| 用量 | 并排 **估算费用** / **已确认费用**；失败调用也计入展示 |
| 已过期 | 契约字段 **`isStale`**（勿用 `stale`）；源数据变更后旧质量结论徽章 **「已过期」**（`--state-warn`），不可再当发布依据 |

## E. 状态词典与建议文案

> **契约字段与架构对齐**：`runStatus` / `inputVersionId` / `isStale` / `publishStatus=unpublished|published|superseded`（中文展示可并列，键名以英文为准）。

### E.1 任务运行态 · 契约键 `runStatus`

| `runStatus` 枚举 | 展示文案 | 色 token |
| --- | --- | --- |
| `queued` | 等待 | `--ink-2` / 中性 badge |
| `running` | 运行中 | `--accent` + loading |
| `awaiting_human` | 待人工确认 | `--state-warn` |
| `succeeded` | 运行成功 | `--state-ok`（点缀） |
| `failed` | 运行失败 | `--state-error` |
| `cancelled` | 已取消 | `--ink-3` |

### E.2 质量结论 · 建议键 `qualityVerdict`

| `qualityVerdict` 枚举 | 展示文案 | 色 token |
| --- | --- | --- |
| `pass` | 质量通过 | `--state-ok` |
| `fail` | 质量不通过 | `--state-error` |
| `pending` | 待确认 | `--state-warn` |

> **过期不是质量枚举值**：源数据变更用独立布尔契约字段 **`isStale`**（`true`↔已过期 / `false`↔未过期）；UI 徽章文案「已过期」、token `--state-warn`。**禁止**字段名 `stale`。

### E.3 发布态 · 契约键 `publishStatus`

| `publishStatus` 枚举 | 展示文案 |
| --- | --- |
| `unpublished` | 未发布 |
| `published` | 已发布 |
| `superseded` | 已替代 |

> 固定枚举：**`unpublished` | `published` | `superseded`**。中文标签可并列书写，例如 `publishStatus=unpublished` ↔ 未发布。

### E.4 能力目录状态

| 建议值 | 展示文案 |
| --- | --- |
| candidate | 候选（未通过固定样本评测） |
| available | 可用（可进企业配置） |
| deprecated | 停用 |

## F. 首版最小界面清单（对齐评审稿 §8）

演示闭环对应：

1. 导入样本 → 原始版本可见（衔 B6 来源）  
2. 解析字段与行列（A5 步骤 / B7 定位）

8. 配置回退 + 跨企拒绝（A4 + 越权态）  
9. 平台侧仅登记能力（A1），不替代企业调试
