## 打开

在项目根目录运行（已实际运行）：

```bash
python3 -m http.server 5188 --bind 127.0.0.1 --directory docs/产品/原型/engine-observatory
```

浏览器访问 http://127.0.0.1:5188/ 。仅绑定本机。也可直接打开本目录 `index.html`；HTML、CSS、JavaScript 均本地引用，无构建依赖、无网络字体、无业务 API 请求。

## 本轮设计选择

- 银灰深色、柔和球体、薄线关系图；原创 SVG 和 CSS 实现，不复制参考项目代码、图片或视频。
- 总台环境示意，左侧图标仅营造页面环境，不提供伪导航。主区域为固定能力节点，右侧为所选分组详情，底部为近五分钟完成的合成汇总。
- 输入对应 COLLECTION、KNOWLEDGE、RETRIEVAL；处理对应 TASK、COMPANY；输出对应 RESPONSE、EXPORT；经验积累对应 EXPERIENCE、GENERALIZATION、GENERAL_ADJUSTMENT。将现有处理区的经验类别拆成视觉分组，十类记录不重复计数。正式分组仍待确认。
- 独立自进化始终为未启用，不把日常经验积累解释为独立自主执行。
- 图谱连线表示能力关系；球体慢旋转为装饰，不表示真实任务流转、服务健康或模型并发。
- 原型中运行类别的细条仅辅助比较同组执行数量，不是任务完成进度。
- 运行中、空闲、异常、断开四种场景都为固定合成数据，时间为示例快照，不进行假刷新。断开时当前数字一律显示未知。
- 保留异常常驻顶部，点击定位首个存在失败记录的分组；所有存在异常的节点也可分别点击。输出回执未知单独展示。
- 支持键盘按钮操作、手动暂停装饰动效和系统减少动态效果。以桌面一屏为主，窄屏改纵向排列。
