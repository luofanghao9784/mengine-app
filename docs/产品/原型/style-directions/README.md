# 三端视觉风格方向原型

2026-10-06。用于比较客户端及两个管理端的视觉风格；只用合成数据，没有改动正式页面、接口或数据。

## 用户决定（DEC-130）

- **客户端：D 克制版。** 以“D 梦境流光”为基础，颜色收敛：背景是低饱和的冷色柔光，不带粉色；全页只用一种靛蓝强调色；类型标签统一用中性灰；关键数字为纯墨色。渐变只用在输入框流光边框上，表示“AI 在场”。保留毛玻璃面板、悬浮导航条和胶囊分段控件。
- **企业管理端与总台：D′ 梦核日光。** 与[引擎仪表盘原型](../engine-observatory/README.md)共用一套视觉语言，是它的白天版本：
  - 暖色背景，带香槟金和霜蓝光晕；
  - 颜色语义与仪表盘一致：香槟金代表梦核与处理，品牌蓝代表操作与品牌，琥珀金代表输出，珊瑚红只用于异常；
  - 关键数字用 Cormorant Garamond 细衬线，页面标题用宽字距衬线；
  - 使用双轨道标志，以及“梦核正在……”脉动状态点。
- 两种风格用于区分使用场景：员工日常工作用 D，管理和运营场景用 D′。页面结构与交互逻辑本轮不调整。

不采用的方向：现状，A 纸本编辑，B 精工中性，C 柔雾层次，E 深空引擎，F 色块海报，以及未收敛的 D。它们保留在原型里作为对比。

具体颜色值、字号、圆角等数值是本原型的实现建议，落地时会写成共享的样式变量，并按真实页面校准。引擎仪表盘本身的风格确认状态见其原型说明，本条不替它扩大确认范围。

## 查看

直接用浏览器打开 `index.html`，顶部可以切换风格和页面（画报/会话）。也可以带参数打开，例如 `index.html?s=calm&v=conv`：
- `s` 选风格：`current`、`editorial`、`precise`、`soft`、`aurora`、`calm`、`dawn`、`night`、`poster`；
- `v` 选页面：`brief` 画报，`conv` 会话。

标题和数字字体从 Google Fonts 加载，离线时会退回到系统字体。

## 现状诊断（改造依据）

统计 `src/**/*.css`：共有 778 个不同的颜色值、45 种字号、45 种圆角、70 种阴影。实际使用的主色是饱和钴蓝 `#1769e0`，与浅蓝极简 V2 提案“克制浅蓝、不要亮钴蓝”不一致。落地顺序：先建立共享的样式变量，再按页面逐步替换。
