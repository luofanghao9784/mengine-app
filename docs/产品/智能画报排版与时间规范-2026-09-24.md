## 信息结构与字号

固定阅读顺序：类型与时间 → 主标题 → 内容/媒体及必要限定 → 来源与图片署名。

| 元素 | 当前实现 |
| --- | --- |
| 类型、时间 | 12px，类型靠左，日期时间靠右；图片卡沿用同一对齐线 |
| 标题 | 宋体风格，24px / 1.35；宽高均充足的大卡使用32px，最多两行 |
| 摘要 | 14px / 1.6，通常两行；短卡一行，完整内容由详情承接 |
| 核心数字 | 36px / 1.1；大卡48px，单位紧邻数字，数字采用等宽数字特性 |
| 必要说明 | 12px / 1.55，最多两行；保留模拟、情景、待确认等限定 |
| 来源与图片署名 | 12px / 1.5，分行置底，各最多两行，详情保留完整出处 |
| 间距 | 网格卡统一20px内边距；区块12px，相关文字8px；最短卡区块收至8px |

尺寸适配采用固定字号与内容取舍，不按照片、图表、文档模板任意改变标题字号。宽高均达到380px时采用大卡字阶；高度不超过300px时，带数字、图表或必要说明的卡片标题可收为一行，减少摘要、步骤、点阵与封面。短而窄的数字卡优先保留数字、单位、统计口径和说明，完整图表在详情阅读。长标题可通过悬停与详情查看全文。

会话类型保留左上角标签，“AI 最新回复”并入底部信息，不额外占用标题与正文之间一行。详情保留正文阅读字号，主标题桌面32px、窄屏24px。

## 同一标题贯穿阅读

列表卡片、详情全文、会话内精简引用与右侧全文共用同一标题选择函数：用户自定义标题优先，其次为当前内容对应的杂志标题，最后为原始标题。

例如零售卡在四处均展示“过去7天，零售向上。”，完整事实仍保留原金额、订单数、比较周期及限定。源事实改变时不再套用旧版杂志标题；读取旧快照时仍根据该快照内容显示，不改写已存数据。

## 日期含义与格式

| 含义 | 位置与格式 |
| --- | --- |
| 卡片内容时间 | 右上角：今天09:26、9月20日09:26；日期与时分之间留空格，跨年补年份 |
| 快照内容时间 | 详情：内容截至2026年9月20日09:26；日期与时分之间留空格 |
| 统计周期 | 紧邻图表：统计期：9月13日—9月19日；保留指标口径与单位 |
| 资讯原文发布日期 | 来源：贵州网 · 发布于2026年9月14日；与卡片内容时间分开 |
| 演示情境日期 | 来源：模拟底表 v1 · 9月20日情境 |
| 活动/截止时间 | 保留正文的业务描述，不使用卡片内容时间代替 |

卡片时间沿用当前记录或所读快照的时间，按现有浏览器本地时区显示；今天按本地日历日判断。所有列表保留日期，避免切换分组或会话引用后脱离日期上下文；窄卡可换行，不隐藏日期。日期缺失或无效显示“时间待核实”，不补造当前时间。打开、关注、刷新和调整排版不重写这些时间。

对现有明确的日期文本只做显示格式转换，保留原来源文本。图表统计周期不再在同一卡的说明中重复出现；“截至某日”等时点说明仍保留其原有含义，不改写成统计区间。
