# 资料库卡片与阅读视窗 V0.1

2026-09-20。用户已确认按建议设计一版放入前端 Demo；界面体验等待用户反馈。延续 WS-03、WS-06—WS-08、WS-12—WS-16 与 AI-02、AI-03，企业与空间权限、发布范围及归属语义不变。

## 浏览与排版

- “个人空间／企业资料库”继续作为两个顶层入口。企业根目录展示获准工作空间的资料集卡片，复用画报的文档封面叠放；子文件夹继续以面包屑定位。
- 默认资料卡片展示类型、真实文本摘录、标题、简介、最新版本确认状态、维护人与日期；企业汇总和搜索结果附资料路径。封面摘录取自当前 Demo 正文，不生成未经核实的内容。
- 企业根目录展示最近更新的六份可见资料，提供全部资料入口；同一目录支持卡片／列表切换、状态筛选及最近更新／名称排序。同日更新以名称和身份稳定排序。
- 资料卡片保持规整等宽网格；不采用画报的大小自由拼版。搜索范围仍为当前目录及子目录，企业汇总排除个人资料。
- 本次网页内记住各目录的搜索、状态、排版、排序与阅读位置。返回列表恢复原位置；刷新通过原有目录和查询 URL 恢复可表达的范围，排版和滚动不承诺跨刷新保存。

## 统一资料阅读

- 资料库点击条目后在模糊背景上展开白色阅读卡片，关闭返回目录；资料库、会话文件卡片和展开详情共用一个阅读组件。
- 正文为主，顶部切换明确版本；最新、待确认、已确认与使用状态分别表达。不存在的引用版本显示不可用，不悄悄替换为最新版本。
- 资料属性、版本记录与关联资料按需打开。桌面作为相邻信息卡片；窄屏及会话中的窄文件卡片在当前卡片内切换，关闭后回到正文。
- 编辑与共享沿用已有最新版本流程；阅读历史版本时明确提示这些操作作用于最新版本。导出与基于资料提问使用当前查看版本。
- 版本确认、资料状态、移动目录、个人修订和发布申请继续沿用现有演示规则。关联资料也按当前读取权限过滤。

## 资料与会话衔接

- “基于资料提问”打开现有新会话视窗，并列显示该资料，保留已有新会话草稿与工作归属，将当前查看版本加入引用。
- 打开或输入草稿不创建会话；发送后才创建记录。引用身份和版本随用户消息保留，新增资料版本不会改变该次引用；资料和会话的归属不因引用而互相改变。
- 移除新会话中的引用会同步移除相应自动阅读卡片。返回关闭会话后可继续原资料阅读。
- 原有会话引用没有版本字段时继续使用原行为；本次增加可选版本映射，不批量迁移历史消息。

## 当前能力边界

仍为浏览器本地前端 Demo，没有真实 AI、云存储或服务端权限实现。现有资料为文本演示内容，本版未增加 PDF、Office、图片原文件上传及原生预览；后续可在同一阅读组件接入对应格式查看器。卡片、过滤和引用版本检查仅证明前端演示流程。

验证结果见 [Demo 使用与验收](前端Demo使用与验收-V0.1.md)；技术说明见 [开发决策记录](../技术/开发决策记录.md)。
