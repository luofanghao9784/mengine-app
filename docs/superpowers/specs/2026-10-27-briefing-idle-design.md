# 多企业自动简报空闲收敛

用户已确认：空闲检查最长 60 秒，保持多企业隔离与生产/消费效率，仅本地实现，不改生产。

选择：按策略持久化空闲退避（5、10、20、40、60 秒），已有批次绕过退避；每轮按企业交错、同策略最多五次，仅有进展继续。不采用全局延长轮询（会拖慢消费）；暂不引入全量事件总线（改动过大）。

实现决定：在现有策略增加调度时间和退避秒数字段；持有既有企业/用户锁和策略行锁，调用现有推进逻辑前后二次读取有限的活跃批次状态判断进展。等待执行中且没有待派发批次时，在昂贵来源指纹之前退出。权限不缓存，任务消费者与配额规则不变。

60 秒是空闲策略的再次检查间隔上限，不是过载情况下的完成 SLA；20 个候选/轮的容量保持不变，通过交错企业和最久未检查优先避免单企业独占。新自动来源最多等待退避时间加调度排队；手动与已有批次立即具有候选资格。

验收：空闲重复调用不更新检查时间；退避不超过 60 秒；企业之间独立；已有批次绕过退避且可派发/消费；撤权拒绝；无重复任务；多企业候选交错；现有简报配额与流水线回归通过。
