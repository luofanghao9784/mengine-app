## 阻塞合并的问题（交 Claude，未改前端）

- 清空有效期：定时 → 新建 → 清空“有效期到”，渲染期间 toConfig().toISOString() 抛 Invalid time value，整页空白。[真实浏览器截图](images/2026-10-27-native-admin-ui/expiry-cleared.png)。需将空/无效日期作为可修正的输入状态，并验证重新填写可恢复。
- after 单次被改为循环：API 已存在的 after 任务暂停后进入编辑，只改名称并保存，fromConfig/toConfig 将 `{kind:'after',afterSeconds:3600}` 转为 `{kind:'every',everySeconds:3600}`。需保留语义或明确限制不支持的编辑，不得静默重复运行。
- UTC at 时区丢失：`2026-10-28T09:00:00Z` 进入 Asia/Shanghai 编辑表单后变为本地 09:00，保存实际提前 8 小时。需按时区转换或原样保留绝对时间。

后二项为纯配置投影复现；不声称已在真实时间触发错误派发。运行 `node --experimental-strip-types scripts/review/native-schedule-rule-probe.ts` 查看三个边界。#190 暂不合并，已在 #120 提供现象、步骤及预期，待 Claude 修复后复验。

## 可重复运行

准备当前 engine 构建与本地合成验收镜像，按此前真实 SDK 验收文档设置宿主地址；本机为 192.168.5.2。

```bash
NATIVE_ADMIN_UI=true \
NATIVE_BROWSER_IMAGE=$(docker --context colima-dh120 image inspect dreamcore-dh-browser:local --format '{{.Id}}') \
NATIVE_SDK_PLATFORM_HOST=192.168.5.2 \
python3 scripts/with-test-postgres.py ./apps/api/mvnw -B -f apps/api/pom.xml \
-Dtest=NativeSdkBrowserIT#fullBrowserAcceptance test
```
