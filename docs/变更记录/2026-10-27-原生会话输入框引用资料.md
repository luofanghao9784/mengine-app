## 2026-10-27 · 原生会话输入框可以引用梦擎资料

**改动级别**：L1 本地改动

### 改了什么
- 原生会话输入框加了“添加资料”：打开梦擎的文件版本选择器，可从自己有权阅读的各个空间里选资料，一次最多 20 份；同一份资料只保留一个版本，选另一个版本会替换。
- 选中的资料显示在输入框里，可逐个移除；发送成功后清空，发送失败时保留，便于重试（重试沿用同一个请求编号）。
- 消息里显示“引用资料 N 份”，不把平台附加给运行时的引用说明当作员工输入。
- 选择器的说明文字可由调用方替换（`OriginalPicker` 新增可选 `note`），原生会话写明“一次最多 20 份、按你当前的阅读权限读取、引用不会给 AI 下载权限”。
- 本次附上给 Codex 的交接说明：审阅 #163 / #164、真实运行环境验收清单、#144 的两个问题、B8 / B5 / B7 / B4 / B6 顺序。

### 为什么改
发送接口（附录 C，B2）已支持带资料版本，平台会核对员工当前的阅读权限；界面上补上入口。对齐稿里输入框有“添加资料”。

### 影响范围
- 涉及哪个端：客户端（原生会话页）
- 共享组件：`src/conversation/OriginalPicker.tsx` 新增可选参数，旧会话不受影响
- 是否涉及数据库迁移：否；不改后端

- [x] 前端构建通过；单元测试全部通过
- [x] 本地预览：选空间 → 选文件 → 选版本，输入框出现资料，发送后显示“引用资料 1 份”并清空
- [x] 本地实例真实接口：带资料发送通过平台的资料权限核对，停在本机未启动的运行环境（502），文字与资料保留；测试留下的未完成操作记录已删除
