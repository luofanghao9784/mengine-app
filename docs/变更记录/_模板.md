# 变更记录模板

> 复制本文件，按 `YYYY-MM-DD-简述.md` 命名，放在 `docs/变更记录/` 下。
> 三条记录以内的小改动可以合并成一条周记。

---

## 2026-MM-DD · 一句话标题

**改动级别**：L1 本地改动 / L2 部署 / L3 数据权限（删掉不适用的）

### 改了什么
用业务语言描述，不写代码细节。

### 为什么改
问题是什么、谁提出来的、不改会怎样。

### 影响范围
- 涉及哪个端：客户端 / 企业管理 / 总台
- 涉及哪些功能
- 是否涉及数据库迁移（是/否，迁移编号）

### 怎么验证的
- [ ] 本地构建通过
- [ ] 关键路径实测（列出实际点了哪些）
- [ ] 线上验证（仅 L2 填）

### 怎么回滚
一句话说明退回上一个版本的方法。L2 必须填。

### 备注
已知限制、后续要补的事、相关文件路径。
