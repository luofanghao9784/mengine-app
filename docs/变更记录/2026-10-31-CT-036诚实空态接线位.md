# CT-036 诚实空态接线位

认领：[Issue #23](https://github.com/luofanghao9784/mengine-app/issues/23)。正式前端岗：`ec838a2d-d838-48cd-a789-e1af1424a7f3`。

本片仅实现 D6 接线位。企业管理端「智能服务」上方新增「已开通」分区，固定显示「暂时不能查看已开通功能（后台开通中）」，不展示功能记录。原智能服务的读取、开关和错误处理继续沿用。

工作空间增加「质量检查」主导航与 `view=quality-check`：进入说明、提交检查材料、处理结果三步壳。提交按钮禁用，说明与结果均显示后台开通中；不上传材料、不生成结果、不显示成功状态。登录、成员与企业访问边界沿用 AccessApp；切换企业与管理端返回保留质量检查路由。

没有新增 HTTP 请求、Cookie 或接口契约；没有修改 API、第四端或生产配置。真读口等 CT-035/#21、CT-034-P1/#22 合入且「本租户已开通」读模型落地后再接。同步时 #21 已合 main，#22 仍开放；这两片的登录与登记写鉴权不作为企业已开通列表的依据。

## 验收入口

在实际运行服务的域名后使用以下路径，将 `<企业ID>` 替换为当前账号获权企业的真实 ID：

- E1：`/tenant-admin/#tenant=<企业ID>&admin=abilities`
- E2：`/workspace/#tenant=<企业ID>&view=quality-check`

E1/E2 当前均为空态验收，不代表功能开通、真实检查执行或生产部署。
