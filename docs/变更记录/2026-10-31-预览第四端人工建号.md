# 预览第四端人工建号

预览环境缺少第四端账号，新增人工 CLI `--bootstrap-agent-admin`，复用现有 bootstrap 的非 Web 执行方式。必须显式开启 `DREAMCORE_PREVIEW_AGENT_BOOTSTRAP=true`，active profiles 非空且全部为 `local`、`trial`；守卫及输入校验在 Spring 刷新、连接数据库和迁移前执行。

口令只读取 `AGENT_BOOTSTRAP_PASSWORD_FILE`：普通文件、NOFOLLOW_LINKS、恰好 0600、最多 512 字节。登录名使用 `PlatformIdentity.loginName` 规范化。单事务创建 ACTIVE 账号、独立哈希凭据、`AGENT_ADMIN` 角色及仅含账号 id/动作的身份审计。已有任意 AGENT_ADMIN 或跨端同登录名账号即拒绝，不改口令或凭据版本。无 HTTP 创建口、自动建号、迁移、企业成员关系或功能授权变更；安全链和前端未改。

[人工运行用法](../../scripts/preview/README.md)；[仅预览技术债及种子脚本待办](../codex-tasks/QUEUE.md)。生产仍需正式发号流程。审查：质量 + 安全。

验证于隔离临时 PostgreSQL：

```sh
python3 scripts/with-test-postgres.py ./apps/api/mvnw -B -f apps/api/pom.xml test \
  -Dtest='AgentAdminBootstrapIntegrationTest,CapabilityRegistryIntegrationTest,CapabilityTenantGrantIntegrationTest'
```

结果：35 项通过（新增类 7、目录回归 19、授权回归 9），0 失败、0 错误、0 跳过。本机使用已有 JDK 21 和 PostgreSQL 工具；系统 `java_home -v 21` 未登记该 JDK，实际以本地工具路径设置 `JAVA_HOME`、`POSTGRES_BIN`。新增测试直接运行 CLI 子进程检查退出码和无写入，覆盖 local/trial 成功、正常 HTTP CSRF/登录及独立 cookie、客户/企业/总台拒绝、重复及跨端同名冲突、审计失败整笔回滚、异常与日志不含口令。本次未部署或改动运行中的预览/生产实例。
