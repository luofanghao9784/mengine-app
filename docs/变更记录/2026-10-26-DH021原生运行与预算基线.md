## 复验与回退

引擎：`npm --prefix engine ci --ignore-scripts`，再运行以上检查。完整原生测试依赖 devDependencies；不使用省略开发依赖的安装冒充完整 profile。

独立容器环境：

```bash
colima start dh120 --activate=false --cpu 2 --memory 4 --disk 24 --vm-type vz --mount none --ssh-agent=false --ssh-config=false --template=false
npm --prefix engine run test:native:container
colima stop dh120
```

容器脚本只构建合成测试镜像，不绑定宿主目录、不发布端口；按镜像 ID 运行非 root、只读根、无网络、capabilities 清空的容器，并检查独立卷及取消回收。它不证明生产 rootless 或企业接口已验收。完整 CLI 的额外依赖许可须在未来原生生产产物发布前单独完成分发审查；当前 notice 覆盖现有生产依赖。

当前没有部署或业务迁移，回退为撤销本任务提交并按对应 lock 重装引擎。不要删除旧会话、现有 `.local`、历史 worktree 或已有验收实例。仅停止专用 dh120 profile，不改变其他 Docker context。

## 容器兼容处理

官方 VM 镜像按发布的 SHA-512 校验后启动。Node 基础镜像已按 registry 返回的 digest 固定。Docker/Buildx 的网络请求使用现有系统代理，限定本次命令与专用 VM，没有改全局网络设置。

首次容器测试发现 native addon 将二进制缓存复制到 `noexec` 临时目录后无法加载。使用上游已提供的 `NARB_DISABLE_NATIVE_CACHE=1`，直接从只读安装目录加载；保留临时目录执行限制、capabilities 清空和网络隔离。该变量也必须进入 SDK 显式子进程环境，不能只设置外层容器环境。

校验后的 VM 源镜像保存在本机 `~/.colima/_images/`，专用 profile 的 `diskImage` 已同步更新，不依赖 `/tmp` 保留。容器模型网关测试使用注入的合成传输；它证明协议与计量行为，不证明已部署独立网络网关。
