## 2026-10-25 · 企业管理端：成员与权限、用量与运行、企业信息、经验库按新风格重做

**改动级别**：L1 本地改动

### 改了什么
以前这四个板块是把旧版管理台整块嵌进深色玻璃卡片：有的白底、有的浅灰、标题用艺术衬线字，成员与权限还有两层导航，和数据基座、知识星链不是一套。现在四个板块都改成和数据基座、知识星链一样的做法：

- **一排页签**：每个板块的子栏目放在卡片顶部一排，不再有左侧栏 + 内层页签两层导航。
- **清单卡 + 详情卡 + 概况卡**：左边清单（只有清单区域内滚动），中间所选一项的详情和操作，右边概况。
- **数字用正文字体**，不用艺术衬线数字；功能一个不删，动作都接回原有流程。

各板块：
1. **成员与权限**：成员 / 邀请 / 共享空间 / 职责与交接 / 数据访问 / 岗位与关注（有资料部门、离职办理权限时另加）。成员详情里可以停用与恢复、紧急安全停用、办理离职、身份与负责人交接、跳到岗位与关注；邀请可以新建和撤销；共享空间的详情沿用原有空间管理。数据访问拆成左边资源（或审批、部门与成员、审计），右边对应设置。右侧是成员概况和最近管理记录。
2. **用量与运行**：本月 / 上月 / 近 30 天是页签；左边“全期汇总 + 每日”清单，中间所选一项的数值、计量明细，底部是可以点的每日柱状图；右边用量构成与口径。
3. **企业信息**：企业背景 / 企业设置 / AI 内容偏好 / 资讯来源 / 管理记录 / 保留与退出（按权限出现）。企业背景是左边四项背景与整理建议、右边所选一项的条目与调整；其余栏目是一张宽卡片里的原有功能。
4. **经验库**：企业经验 / 通用经验 / 积累与改进。经验详情（停用与恢复、调整、版本、依据）直接放进详情卡，不再弹窗。
5. 各板块的栏目和选中项都记在地址里，刷新回原处；换板块时清掉上一个板块的参数。弹窗也换成了深色。

### 为什么改
用户 2026-10-25 看过成员与权限的本地样张后确认“就按这个思路做”。规则沿用 2026-10-12～15 定下的：核心页面一屏展示完、内容多用标签切换、只有列表区域内滚动、不要艺术衬线数字、不删功能。

### 影响范围
- 涉及哪个端：企业管理
- 涉及哪些功能：成员与权限、用量与运行、企业信息、经验库四个板块的界面；底层组件与接口没有改
- 是否涉及数据库迁移：否
