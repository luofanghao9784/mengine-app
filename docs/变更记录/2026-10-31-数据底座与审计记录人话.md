## 实现边界与审查

质量审查：白名单使用 `Object.hasOwn` 防止继承键被误当作标签；未知代码不回退原值；审计身份调用 #56 的 `roleLabel`，只处理明确的旧身份后缀，保留显示名的空格、完整文字及普通括号昵称。当前审计契约只提供姓名时不凭当前成员角色猜测历史身份，按定稿回退到完整姓名。

UX 审查：保留既有页结构，删除冗余英文页眉和专属样式；版次统一；字段选择显示业务标题并保留原请求代码；北京时区选项仍提交标准时区。实际业务数据单元格、来源原文与人工编辑的业务筛选值属于业务内容，不伪装为展示标签翻译。未知标签只显示其他记录，未知动作只显示其他操作；不据此推断业务含义。

未覆盖的位置：本次目标页的已识别 kind/category/stage/action 原值入口已处理。计划页 `src/plans/Plans.tsx:197`、`:436`、`:625` 的时区文字/编辑框及原生会话计划 `src/native-conversation/NativeSchedules.tsx:390`、`:420` 的时间/cron 标签仍可能显示标准时区；这两页不属于本片数据底座/审计页。平台运维其他页的诊断标识、请求编号及第四端样例编号不扩入本片。企业存量“数据基座”审计需交付重灌。

### 统一函数

| 函数 | 规则 |
|---|---|
| `recordLabel(code, metadata)` | 优先非空 metadata.title；否则查询记录白名单；未命中其他记录 |
| `actionLabel(code, metadata)` | 优先非空 metadata.title；否则查询动作白名单；未命中其他操作 |
| `fieldLabel(code, title)` | 优先业务标题；已有中文字段名按标题处理；其余走记录白名单 |
| `displayText(text)` | 定稿短语与版次转换；已知代码查白名单；未知机器词替换为其他记录；保留中文正文 |
| `versionLabel(N)` | 数字或 vN → 第 N 版；无有效数字版本时尚无版本 |
| `settingsLabel(N)` | 零为尚未修改过设置；其余第 N 版设置；按企业分别保存 |
| `timeZoneLabel(zone)` | Asia/Shanghai → 北京时间；未知其他记录 |
| `actorLabel(name, identity)` | 姓名（共享身份映射）；系统→系统；未知身份只显示完整姓名 |
| `auditDetail(action, detail)` | 部署治理抽取检查条数并输出定稿说明，不显示部署编号；其余走展示转换 |
| `isDeploymentIdentifier(text)` | 部署编号整段识别；在知识表中过滤整行 |
| `classificationLabel(N)` | 0–3 → 公开 / 企业内部 / 机密 / 严格受限；未知其他记录 |
