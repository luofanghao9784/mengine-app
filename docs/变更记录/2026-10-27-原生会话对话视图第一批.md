## 2026-10-27 · 原生会话对话视图（第一批前端，待接通平台事件转发）

**改动级别**：L1 本地改动

### 改了什么
- 新增原生会话在梦擎会话卡片里的对话视图：
  - 对话流：员工输入、AI 回复（思考过程可折叠）、按轮次展示，轮次结束时标明“已停止 / 被拦下 / 出错”。
  - 工具过程卡：每次工具调用一行（中文名称 + 关键参数 + 进行中 / 完成 / 失败 / 未完成），展开可看参数与结果。
  - 审批卡、AI 提问卡：需要员工处理时用强调边框；处理后变为已处理样式。
  - 成果文件卡：一轮结束时列出交付的文件，并提示到“私人成果”下载与确认发布。
  - 状态栏：运行中 / 空闲、整理上下文或重试提示、已用费用与提醒、上限（数据来自平台，未提供时不显示）。
  - 输入框：发送、运行中可停止；回复评价（赞 / 踩）。
- 有对话视图时，原来的“会话执行、私人成果与发布”移到旁边的“执行与成果”卡片（桌面三栏并排，手机左右滑动切换，可关闭后从顶栏再打开）。
- DH 事件按 `SessionEvent` 原样解析：只显示员工本人输入的消息，注入的技能说明、系统内容不显示；未知或格式不对的事件跳过，不影响界面。
- 平台的事件转发与操作接口（清单 B1–B3）尚未提供，所以真实会话目前仍显示现有布局；相关按钮在接口提供前保持不可用并说明原因。
- 本地开发可在地址里加 `nativePreview=1` 用合成数据预览整套界面（页面顶部标注“预览数据”），生产构建不包含这部分。
- 前端调用约定写入 `docs/技术/DH原生会话前端对齐清单.md` 附录 B，供后端定稿。

### 为什么改
按对齐清单推进第一批前端。后端接口未就绪前，先用 DH 实际事件结构完成界面与解析，接口提供后直接接通，减少等待。

### 影响范围
- 涉及哪个端：客户端（原生会话页）
- 未开启原生会话或没有事件数据时，界面与改动前一致
- 是否涉及数据库迁移：否；不改后端
