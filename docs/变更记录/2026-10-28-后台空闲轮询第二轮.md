## 2026-10-28 · 后台空闲轮询第二轮

**改动级别**：L1 本地改动（合并后需再发 API 才作用于生产）

### 改了什么
在第一轮 IdleGate 基础上，进一步减少空闲空转：经验接入无活时拉长扫描间隔；会话回执恢复改为约 15 秒一次；企业分析空闲发现改为 2 分钟；WeKnora 空闲时跳过重维护（租约到期与可领取任务仍立即维护）；会话标题领取加空闲门禁。

### 为什么改
第一轮后生产 CPU 有缓解但仍间歇偏高；为后续接入 4–5 家企业预留余量。约束为不改前端、不改业务规则、有任务时仍快领。

### 影响范围
- 涉及哪个端：平台 API 后台
- 涉及哪些功能：经验接入、任务回执恢复、企业信息分析、WeKnora 索引、会话标题
- 是否涉及数据库迁移：否

### 怎么验证的
- [x] `IdleGateTest`、`ExperienceIntakeIntegrationTest`、`CompanyAnalysisDiscoveryTest` 通过
- [ ] 有任务时领取与回执恢复仍可用（RESULT_UNKNOWN 最坏约多等十余秒；合并发版后观察）

### 怎么回滚
回退本 PR 对应提交并重新发 API。
