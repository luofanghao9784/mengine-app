# 原生状态快照与派发登记修复

关联 #120/#144；依赖真实 SDK 浏览器修复 PR。V179 已事先登记，仅隔离数据库验证。

状态存储从无限追加改为 `native_conversation_status` 每会话一行；迁移保留旧最新状态、初始化独立事件游标并删除历史 status。普通事件仍按原回执去重，冷历史不含 status，SSE 合并最新状态与持久历史并排序分页。旧状态重试不回退新状态，游标不因清理状态而重复。桥接 SQLite outbox 对 status 合并，断网时也不会无限积累快照；正常会话事件完整保留。

派发只有明确的连接前失败才释放未决登记（ConnectException/HttpConnectTimeoutException/UnknownHostException）；普通响应超时、派发后断连及未知回执不释放。再次点击使用相同 requestId，成功后的重复请求仍回放原回执。生成授权前失败同样按未派发处理。

验证：平台集成首轮 19/19，包含有界状态、统一游标、冷历史、SSE 登录续传、权限、并发去重及已知/未知派发区分；SDK/桥接 4/4，包含重启、状态合并和审批/提问。新增真实拒绝连接测试与打包结果另见末尾。没有生产迁移、部署或收费模型。

回退：应用版本与数据库迁移须配套。V179 已将旧 status 汇为快照，不能承诺恢复已删除的冗余状态；普通会话历史未删除。生产升级仍由部署负责人另行决定。

最终追加验证：真实本机拒绝连接测试 1/1 通过；Maven package 成功。此前 19 项和追加 1 项合计 20 项检查通过，SDK/桥接 4 项通过。
