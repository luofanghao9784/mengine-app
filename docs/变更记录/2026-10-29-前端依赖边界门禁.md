# 2026-10-29 · 前端依赖边界门禁

**改动级别**：L1 本地改动

### 改了什么

给前端加了 dependency-cruiser 门禁。正式代码不能新依赖演示内核，`shared` 不能新依赖会话，feature 之间不能新引用对方的页面文件。已经存在的违规边记在允许清单里，现状命令可以通过。

### 为什么改

[前端模块边界 ADR](../architecture/ADR-前端模块边界-演示与正式分家.md) 要求下一份变更只加导入检查和允许清单，不改业务行为。没有这道门，后面搬目录时新的环会继续长出来。

### 影响范围

- 涉及哪个端：客户端 / 企业管理 / 总台的前端源码依赖方向。运行时行为不变。
- 涉及哪些功能：无功能改动。
- 是否涉及数据库迁移：否

### 怎么验证的

- [x] `npm test` 513 项通过，其中包含这条门禁
- [x] `npm run depcruise` 在干净工作区通过
- [x] 临时加一条 Live→Demo、一条 shared→identity，以及一条已经不存在的允许清单条目时失败；探针未提交
- [ ] 本地构建：未跑。这次不改 `src` 业务代码，也不改构建配置
- [ ] 关键路径实测：不涉及页面行为
- [ ] 线上验证：不涉及

### 怎么回滚

撤回本变更即可。没有数据迁移，也没有运行时开关。

### 备注

操作说明见 [dependency-cruiser.md](../architecture/dependency-cruiser.md)。仓库没有 GitHub Actions 前端 job，门禁挂在 `npm test`。
