# 2026-10-29 · 前端 e2e 两条用例稳定

**改动级别**：L1 本地改动

### 改了什么

会话弹性滚动的采样改成跟动画帧对齐：仍按 16ms 一格读位移，但只在这一格已经画出来之后再读。空谷三张资讯卡的配图请求改由测试里的本地图片应答，卡片上的原文地址不变。

### 为什么改

[PR #4](https://github.com/luofanghao9784/dreamcore-workspace/pull/4) 的 Frontend gate C 步（`npm run test:e2e:frontend`）被这两条挡住。它们在 main 上就会偶发失败，不是那份门禁改出来的。固定 `setTimeout(16)` 有时落在弹簧绘制之前，早期采样仍等于峰值；外链图片则取决于 `gzw-img.sjw.net`、`gywb.cn`、`k.sinaimg.cn` 是否及时解码。产品回弹和配图逻辑没有改。

### 影响范围

- 涉及哪个端：无运行时改动。只动 Playwright 用例和一张测试用图片。
- 涉及哪些功能：无。
- 是否涉及数据库迁移：否
