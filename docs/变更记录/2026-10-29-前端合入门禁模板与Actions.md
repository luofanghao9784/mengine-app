# 2026-10-29 · 前端合入硬门禁模板与 Actions

**改动级别**：L1 本地改动（仅文档与 CI 配置）

## 改了什么

指向 `main` 的 pull request 增加前端硬门禁：A `npm run build`、B `npm test`、C `npm run test:e2e:frontend`。验收清单、缺陷记录模板和索引放在 `docs/验收/`。全量 `npm run test:e2e` 不进默认 workflow；选跑条件写在验收清单里。

## 为什么改

前端合入此前没有统一的必跑命令和缺陷记录位置。只写在口头约定里，合入时容易漏跑。

## 影响范围

- 不改客户端、企业管理、总台、引擎或平台 API 的业务代码
- 不涉及数据库迁移
- 每个指向 `main` 的 pull request 会多跑这一道 CI

## 怎么验证的

- [x] 本机 Node v24.20.0（与 `.node-version` 一致）执行 `npm ci` 与 `npm run build`，退出码 0；产物入口校验打印 `Production entries and referenced assets verified.`
- [x] actionlint 1.7.7 检查 `.github/workflows/frontend-gate.yml`，无报告
- [ ] 未跑 `npm test`、`npm run test:e2e:frontend` 或全量 `npm run test:e2e`
- [ ] 关键路径界面（本变更无界面）
- [ ] 线上验证（不涉及）

## 怎么回滚

撤销本提交，或删除 `.github/workflows/frontend-gate.yml` 与新增的验收文档。无数据迁移。

## 备注
