## 前端待修：最终输出优先级

交 Claude 处理，已在 #120 留言。`chat/work.ts` 的 progress() 在已结束判断前，用 childEvents 最后回复覆盖 task.output，导致 finished.lastAssistantMessage 丢失优先权。

复现：started(child) → child assistant/message 内容 previous child reply → finished(child, status=ok, lastAssistantMessage 为 selected final output)。实际展开显示 previous child reply，预期 selected final output。两者相同的自然成功链路不能覆盖这个边界。

```bash
node --experimental-strip-types scripts/review/native-subtask-finish-probe.ts
node scripts/review/native-subtask-ui-probe.mjs
```

第一条当前故意退出 1，打印 expected/actual；它是独立审阅探针，不加入自动通过测试。第二条渲染现有 NativeWorkPanel 生成截图：[输出优先级复现](images/2026-10-27-native-review/child-finish-priority-probe.png)。这是合成投影边界，不是真实 SDK 自然出现输出不一致的证据。本次没有改前端源码；完整验收仍有该待修项。
