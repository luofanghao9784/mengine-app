2026-09-24，M4-A1 第九切片；对应 AI-01—AI-04、POS-05/POS-06。用户确认百炼优先、千问为主候选；此前 DeepSeek 官方适配保留为独立实现。用户确认沿用现有阿里云账号、为梦核新建专用业务空间，本轮费用上限 0，只做本地适配；实际空间配置与模型质量仍待验收。

## 接入与替换

引擎 0.10.0 的 `ModelPort` 继续隔离自有任务协议与供应商。`BailianModel`、`DeepSeekModel` 分别校验配置和设置模式参数；内部共用 `ChatCompletionsModel` 负责消息、工具 call ID、回复格式和累计用量，不共用生产地址或 Key。Harness 核心不变；新 provider 只通过 `configuredModel` 的显式选择进入正式入口，没有跨供应商 fallback。

- 百炼生产地址由已校验业务空间 ID 构造为北京专属 HTTPS `/compatible-mode/v1/chat/completions`。正式配置不能自定义 endpoint、端口、代理地址或重定向；测试构造器仅允许准确路径的 IPv4 回环 HTTP，不从环境变量开放该入口。
- 当前评估候选快照：qwen3.7-plus-2026-05-26、qwen3.7-flash-2026-07-15、qwen3.8-max-0902。允许列表描述适配器评估范围，不是上线质量批准；更新列表须核对模式能力和回归用例。主候选 Plus 未经真实调用证明。
- 请求显式 `enable_thinking=false`、非流式，保留受限自定义工具；不发送 DeepSeek 的 `thinking` 字段、不接供应商会话记忆、内置浏览器/代码执行或知识库。返回非空推理内容按不兼容拒绝；推理回放、流式、JSON Schema 与视觉消息尚未接入这个模型端口。
- 沿用单次 12 秒头部和正文共同期限、256 KiB 输入/128 KiB 响应、每次最多 4 个工具调用、单任务 8 次模型/工具及 25 秒总预算；超限不是成功，取消和权限撤销传播到网络请求。真实任务若超时，需有证据调整，不自动重发收费请求。
- token 用量缺失后整个尝试保持未知；这里只记录供应商 input/output token，不等于按地域/缓存/时段核算的人民币费用，更不是企业额度控制。

平台、任务/回调/Runtime 协议及数据库不变；正式执行仍拒绝代码/候选试验能力。前端不访问供应商 Key，业务权限在平台及工具层继续执行。百炼空间不是梦核的租户隔离替代物。

## 预检与官方依据

根目录 `npm run model:check` 只构建并检查当前环境的配置结构，不联网，不校验 Key 真实性。默认 off；显式选择 bailian 时须有 workspace/model/key。使用方法及首轮合成任务范围见[接入准备](../交接/百炼接入准备与首轮验收.md)。
