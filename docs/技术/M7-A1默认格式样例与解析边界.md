# M7-A1 默认格式样例与解析边界

2026-09-24，DEC-072；对应 M7-A1 默认格式覆盖、M3-A1 资料解析与固定引用、需求基线资料库及 POS-03/POS-06。第四切片以可重复生成的合成文件验收现有能力，不引入模型费用或扩大自动工具安装权限。

## 运行与样例

执行 `npm run setup:parser -- --with-tests` 安装既有固定依赖；完成 `npm run build`、`npm run test:api` 并安装 Chromium 后，运行 `npm run test:formats`。测试使用一次性 PostgreSQL、随机端口和两个合成企业，真实调用上传、解析工作进程、检索、引用及下载接口，邀请只写本地测试 outbox，不启动引擎任务或访问云模型。当前解析环境仍是 macOS Apple Silicon；Linux 文件解析执行器尚未验收。

样例生成器为 [fixtures.py](../../scripts/knowledge/fixtures.py)，完整流程为 [verify-formats.ts](../../scripts/verify-formats.ts)。21 份样例、文件 SHA-256、状态/警告预期、关键词与定位写入忽略目录 `.local/m7-formats/fixtures/manifest.json`；最终报告和截图在 `.local/m7-formats/`。生成文件不提交，不使用客户材料。

| 样例 | 预期与核验点 |
| --- | --- |
| 中文 TXT（含大写扩展名）、Markdown、UTF-16 | READY，中文和行定位；HTML 仅显示文本，不执行 |
| GB18030 中文 TXT | PARTIAL，明确编码回退提示；原中文可检索 |
| CSV 空行、多行单元格、前导零 | READY，空记录跳过，原字符串 `00123.4500` 与多行单元格保留；位置按 CSV 记录序号，不是物理文本行号 |
| DOCX 正文、表格、页眉 | PARTIAL，正文/表格可读，页眉等正文外内容有未完整提取提示 |
| XLSX 公式无缓存 | PARTIAL，工作表/单元格定位；公式不重算，缺缓存不伪造数字 |
| XLS 旧表格 | PARTIAL，仅保存值，不校验公式/运行宏 |
| PDF 文字层、扫描件 | 均为 PARTIAL；按页定位，扫描件标记 OCR；不宣称完整理解图表与复杂布局 |
| 中文 PNG、JPEG、带 EXIF 旋转的 JPG | PARTIAL，金额样例可识别且标记需核对；方向信息在任务副本中应用，原件不变 |
| XLSX 范围标记小于实际数据 | READY，仍能检索到真实 B3 单元格 |
| 全空 CSV、空 TXT | FAILED / NO_TEXT_FOUND，无虚假可检索片段 |
| 损坏 PDF、DOCX | FAILED / PARSE_FAILED，无检索片段，原件保留 |
| PPTX 扩展名哨兵 | UNSUPPORTED，仅验扩展名路由与原件保留；该哨兵不是有效演示文稿，也不代表 PPTX 解析支持 |
| 超过 500 片段的 Markdown | PARTIAL / CONTENT_LIMIT、RESOURCE_LIMIT；保留前 500 片段，明确未完整提取 |
| 实际列坐标超限、声明范围较小的 XLSX | FAILED / RESOURCE_LIMIT，不能利用错误范围标记绕过资源上限 |

另外以解析器回归用例检查超 20,000 行、非标准 worksheet relationship 目标、ZIP 膨胀、其他任务文件/写入/网络拒绝等边界。样例证明本地典型流程，不代表所有 Office 变体、加密文件、低清扫描件或复杂版式均已通过。没有把合成金额识别当作真实财务准确率。

## 实现与替换边界

本地解析器实现版本从 `local-1` 更新为 `local-2`，输出结构不变。平台适配器明确接受这两个版本，拒绝未知版本；错误/警告码限制为大写字母开头、字母数字下划线、最多 64 字符。修复此前 `ENCODING_GB18030` 中数字导致合法结果被适配器拒绝的问题，仍不透传工具 stderr、文件路径或自由错误文本。

Excel 先沿固定版本 openpyxl 实际解析出的 worksheet 关系目标，用 defusedxml 校验行/列坐标及行内单元格数量，再重置不可信的声明范围读取。保留实际 20,000 行/200 列限额、输入/展开量/片段/CPU/墙钟限制。调用固定依赖的 `_worksheet_path` 定位真实部件；升级 openpyxl 时必须回归非标准部件路径与范围上限，不只测试标准文件名。

手机图片只在当前任务目录生成应用 EXIF 方向的临时 PNG，OCR 后删除；上传原件及 SHA-256 不变。没有修改沙箱白名单、联网限制或每个任务的独立目录。CSV 跳过全空/空白记录但不改变其他单元格字符串和记录定位。

没有数据库迁移，仍为 V14；Knowledge 公共接口、梦核引擎 0.9.1、Agent 1.4、来源 1.0、回调 1.3 不变。历史片段不批量重写或自动重解析；显式重新解析产生新批次，旧固定引用继续使用旧片段，并在读取时复核当前权限。默认检索只取最新文件版本的最新解析批次；最新版本失败时不悄悄回退旧内容。

## 页面反馈与未覆盖范围

失败状态明确原件保留、当前没有可检索内容；损坏或无法解读时提示检查能否打开、加密与扩展名，没有把这些候选原因当作已诊断的事实。空内容提示检查空文件或扫描清晰度。不支持格式提示可下载及转换后上传，移除“Agent 模块接入后自动寻找工具”的笼统承诺。现有 Agent 的授权原件/可信配方仍可用，资料库尚未提供通用自动转换调度。

OCR 需人工核对，公式未重算、PDF 布局未完整理解等警告保留。DOC、PPT、音视频、新工具自动准入、复杂表格计算不在本批新增范围。WeKnora、云模型、生产隔离/容量、客户样例及 Safari/iOS/安卓/鸿蒙/Windows 真机仍需相应验收。实际结果见[验证记录](../交接/M7-A1默认格式样例验证-2026-09-24.md)。
