# M4-A1 可信目录与公开检索边界

日期：2026-09-23。第四个实施切片，沿用 AI-01—AI-04、AI-12—AI-13 和 POS-05。用户已确认可信目录自动使用、公开候选隔离试验及公开搜索/阅读的方向。本批落实**随引擎发布的可信能力包发现、按任务启用、公开检索/阅读与来源留存**；远程依赖安装和未知候选隔离试验仍待后续实现，不将本批启用说明文件称为完成自动安装。

## 平台与引擎分工

Spring 持有任务、企业/空间/发起人、不可变的公开检索输入、执行状态和来源快照；引擎保留自有 `ModelPort`、`TaskTool`，经短期尝试凭证取得授权。React 只调用业务 API，不依赖 Harness、SearXNG 或能力包内部结构。引擎仍不连接业务数据库。

`find_skills` 只返回本任务已具备权限的目录条目。`activate_skill` 要求精确 ID 和版本，加载前验证普通文件、大小及 SHA-256。目录随引擎发布，固定目录、文件名、工具声明和摘要；不接受模型指定路径、npm 包、下载地址或安装脚本，不装载用户主目录配置。当前包含“资料核对”和“公开资料研究”两个自有指南。来源 `dreamcore-bundled`、许可 `project-internal` 仅表示本项目内维护，不是第三方开源许可。

公开工具在能力包启用前不向模型展示；即使模型猜中工具名，执行器也检查启用状态及平台授权。能力包只能组合已经授权的工具，不能扩大权限。每任务独立上下文、来源句柄和启用记录；目录 ID/版本/摘要来自实际加载，网页内容不能修改它们。

业务 API 对能力记录只约束 ID、语义版本格式、摘要和数量，不把目录清单或具体版本固定在 Spring/React。更新指南、算法或目录可以独立发布引擎；新增业务写入权限、工具类型或协议结构仍需对应契约验收。平台信任经过服务鉴别的引擎回执，并校验任务权限、工具类别、来源摘要和状态；不宣称能在平台侧独立证明远程抓取事实，故引擎部署与密钥属于可信执行边界。

## 公开检索的最小授权

当前可逆实施选择：会话的 Agent 工作要求之外，增加可选的 `publicQuery`。用户填写公开关键词（最多 200 字）或 HTTPS 网页地址（最多 2048 字），留空不授予联网能力。该字段不由模型从企业资料中自动生成。默认 `AGENT_PUBLIC_WEB_ENABLED=false`，平台与引擎都需显式开启；开启不启用模型，云模型默认仍关闭。

- 平台保存并在每次授权回调返回原输入；幂等键覆盖此输入，改变它不能复用同一次发送。格式不允许控制字符；SOURCE_LOOKUP 不接受公开输入。
- `public_search` 不接受任何参数，只使用平台已保存的输入。模型不能传自己的查询、URL、文件正文、Cookie 或凭据。若填写网址，只建立该网址的待阅读句柄，不伪装成搜索命中。
- `read_public_page` 只接受本任务取得的来源 ID，不接受任意 URL。检索默认最多 3 条结果、每任务最多读 2 页；并发或重复调用同一查询/来源共用实际请求与快照，不重复发网。
- 公开输入会发送给配置的检索服务，关键词检索服务可能转发给它启用的搜索引擎；指定 URL 直接访问目标站。网页 UI 提醒不要填写企业机密。这里的限定只约束搜索/阅读出口；配置真实模型后，工作要求和获准片段仍会按模型协议发送给模型供应商，不能把公开检索隔离理解为资料完全不出云。
- 模型每步、工具执行前及运行中继续检查企业、空间、任务和租约；撤权或取消中断实际网络请求并禁止迟到写回。已发送的请求无法撤回，不承诺字节级即时回收。

## 搜索与阅读适配

本项目只实现 SearXNG HTTP 适配，没有嵌入、修改或分发 SearXNG 服务端代码。按 [官方 Search API](https://docs.searxng.org/dev/search_api.html)（2026-09-23 核对）使用 `GET /search?q=...&format=json&safesearch=1`。服务必须启用 JSON 输出；未选择任意公共免费实例，未新开付费服务。部署方提供 `AGENT_SEARCH_ENDPOINT=https://<已配置的公开服务>/search`，不附带查询参数。当前不支持需要自定义鉴权头的搜索服务。

未配置搜索地址时，明确填写的公开 HTTPS 网页仍可读取；关键词检索返回配置失败，不用演示结果填充。实际生产 SearXNG 服务、检索质量、吞吐与运营许可义务仍需随部署验收；HTTP 合成服务验证不等于这些项目通过。

网页读取器固定 GET、HTTPS/443，拒绝凭据、片段、私有/回环/链路本地/保留/组播地址及内部域名。解析全部 DNS 答案后逐一检查，真实 TLS 连接固定到已检查地址，保留原主机证书验证；最多 3 次重定向，每一跳重查。不读取代理环境变量，不传用户 Cookie、Authorization 或 Referer，不执行网页 JS、表单、下载程序或登录操作。

请求（含 DNS、跳转和正文）最多 7 秒，响应头 16 KiB、正文 512 KiB；拒绝压缩正文，页面只接受 UTF-8/ASCII 的 HTML/纯文本。用 [parse5](https://parse5.js.org/) `8.0.1` 提取文本，跳过脚本、样式、表单、隐藏节点等；地址分类用 [ipaddr.js](https://github.com/whitequark/ipaddr.js) `2.5.0`。均已固定版本及 MIT 许可文本。解析节点和文本量受限，每条最多保存 4000 字，并记录截断，不等于完整网页或文件理解。

网页及搜索摘要均为不可信资料，工具结果与指南明确标记；安全动作由工具参数和服务端权限限制。没有把提示词当作权限隔离，也不声称已经验证真实模型对所有提示注入的抵抗能力。

## 结果、协议与升级

真实工具回执产生 `webSources`：来源 ID、最终 URL、标题、文本摘录、SHA-256、获取时间、SEARCH/PAGE 和截断标记；已读页面替换同一来源的搜索摘要。SEARCH 是检索线索/待读网址，PAGE 才是本次实际读取的页面。SHA 只校验保存文本的完整性，不证明网页事实正确。网页按普通文本渲染，链接使用 HTTPS 与 `noopener noreferrer`，不渲染来源 HTML。

Spring 校验任务已授权联网、能力启用/工具回执、数量、字段、URL 与摘录摘要；来源、能力记录、回复和产物同一事务提交。私人会话读取继续检查本人、租户、空间及文件引用，管理员与总台无内容旁路。失败/取消不交付半成品快照；重试生成新尝试，并保留原公开输入。

引擎版本 `0.4.0`；Agent 结果协议升级到 `1.1`，旧 `1.0` 任务协议明确拒绝。来源检索和能力元信息协议仍为 `1.0`。公共会话 OpenAPI `1.2.0` 增加公开输入、来源及能力记录，V9 为任务表增加字段，不修改旧迁移。每任务上限从 4 次模型/工具调整为各 8 次，以容纳发现→启用→查询→读取；25 秒总时限和产物 64 KiB 限制不变。这是可逆技术上限，不是已批准的客户费用预算。

升级前关闭 Agent 提交并排空/取消运行任务，再部署匹配协议的引擎、平台和网页后启用；保留历史 V9 数据。降级同样先关闭任务、保留数据库增量，不在线混用 1.0/1.1 Agent 执行器。没有生产升级/回退演练。后续能力包或算法更新如保持协议与已有工具权限可仅升级引擎。
