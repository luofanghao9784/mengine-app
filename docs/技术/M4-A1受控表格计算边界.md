# M4-A1 受控表格计算边界

2026-10-01，针对 9POP 主模型分析中的金额、变化率和排名复核问题，对应 AI-01—AI-13。用户同意先实施受控读取与计算，再逐项处理图表、完成判定和画报收录；本切片不实现后三项。

## 输入和执行

引擎 0.12.2 根据平台 `/check` 的可选 `tableComparisonVersion=1.0` 注册 `compare_table`。模型先检索获准资料，再传入来源片段 ID、工作表、含单行表头的范围、分组/期间/数值列字母及两个期间原文。模型不能传入文件路径、文件字节、企业身份或程序。旧平台未声明能力时不注册工具。契约见 [table-comparison](../../contracts/engine-api/table-comparison.schema.json)。

平台复核运行中的任务、短期凭证、工具登记及 STARTED 回执、当前空间与资料权限，并从本次检索固定的版本及解析批次取得原件。新版本上传不会替换计算输入。计算后再次复核权限与取消状态，才存入私人 JSON 计算回执。下载沿用会话本人、来源与空间权限以及已交付尝试状态；不会发布到资料库或共享空间。

固定 `table-compare-1` 配方直接读取 XLSX XML 数值，以 Decimal 计算两期分组汇总、差额、变化率及降序竞赛排名（并列占用名次）。百分比四舍五入至两位。缺失期间不是零；基期小于等于零不计算变化率；分组覆盖不一致不计算总变化率。公式、布尔、错误值、空数值或含千分位等有歧义文本拒绝计算，不取缓存结果。

原件最多 2 MiB，指定范围最多 500 数据行、20 列、50 分组；解压、XML、单元格及输出均有界。使用现有 macOS OS 沙箱启动独立固定 Python 程序，无网络、无依赖安装、无模型代码，CPU 5 秒、进程墙钟 8 秒、Java 外层 10 秒、HTTP 12 秒。Linux 尚未实现此执行器，不宣称跨平台可用。注册目录容量调整为 15，任务仍最多 8 次工具及 8 次模型调用。

## 回执与分析边界

JSON 回执保留输入单元格、精确十进制字符串、计算方法、范围/期间/列、来源版本与 SHA-256。相同任务尝试和参数产生同一回执，合并现有产物后仍最多 8 个、64 KiB。模型收到去掉逐行输入后的计算结果及回执信息，负责解释业务意义。工具成功只证明选定范围的计算，不能证明完整业务覆盖、计量单位或变化原因。

9POP 示例比较的是 2026 年 8 月与 9 月各 1—23 日；`receipts_yuan` 为收款元，包含待财务确认子集，未抵减退款，不是净收入或利润。资料中这类口径必须随解释保留，固定配方不会自行推断。
