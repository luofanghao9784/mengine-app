| `engine/src/runtime/catalog.ts` | TrustedCatalog、固定 SHA256、授权工具过滤 | 仅允许 source=dreamcore-bundled、license=project-internal、单 markdown 且 16 KiB 上限；上游多文件包不能直接注入 |
| `engine/src/runtime/agent-task.ts` | find_skills/activate_skill、模型调用、取消和回执 | 通用路径约 55 秒/8 次模型调用的预算需要按技能配置；不全局放大其他任务预算 |
| AgentTaskService 与 agent-task.ts | 私有产物回传与下载 | 双端产物总量 64 KiB、最多 8 个；普通 PPT 与打包 HTML 会越限 |
| TaskOriginals、MaterialAccess、DocumentService | 固定原件版本、权限检查、私人文稿与显式发布 | 文件型成果要与现有版本/生命周期对接，不能把 HTML/PPT 塞入文字文稿替代 |

关键结论：先补文件型成果通道与经审查的 Skill 包加载，再开放“立即使用”。只增加按钮、把 skill 名写入 prompt 或提高单侧 64 KiB 限制，都不能算接入。

资料权限新模型当前在并行未提交改动中，相关开关保持现状。本功能必须同时覆盖现行有效权限路径与新模型启用路径；未验证不得替其他任务打开新权限开关。

| personal-space-organizer | ComposioHQ/awesome-claude-skills：file-organizer | 当前提交未找到许可文件；README 的 Apache 声明不足以完成本轮打包审核 | 本地文件调用改为平台个人空间 API；保持候选，不拷入发行包 |

源包存放 `engine/skill-sources/upstream/`，不在 `engine/catalog/manifest.json`，所有记录 runtimeEnabled=false。准备目录内脚本作为待审查源码，不执行安装、下载模型或调用云服务。来源完整性校验不是许可证法律结论，也不是代码安全审计或业务验收。

后续使用固定镜像预装依赖，禁止每个任务临时 npm install 或跟随上游 main。上游文档里的工具名、提示确认、文件路径与运行命令要适配到梦擎；第三方内容无权扩大用户资料范围或触发外发。

## 4. 页面和调用流程

### 4.1 技能中心

建议路由沿当前 hash 规范增加 `skills` 视图（准确键名在 UI 批次统一）；通过正式客户端 WorkspaceNavigation 挂载。发现页展示五个技能卡片、成果格式、示例和真实可用状态。只有上线能力就绪才显示“立即使用”，候选技能标“接入中”。示例使用合成数据并显式标明。

我的技能显示服务端保存的启用、收藏与最近使用；按账号和企业隔离。连接页仅显示已实现的连接，不编造第三方账号接入；首批可以呈现无需额外连接的空状态。平台运行依赖由管理端配置，不向普通用户索取 Python、模型 Key 等。

### 4.2 会话

技能按钮和 `/` 复用选择面板；一个请求显式选择一个特色技能。选择只填入草稿，不立即创建会话或发送请求。输入框展示技能标签、已选文件、设置，移除技能不删除文字或附件。

从中心进入新会话；从现有会话保留上下文；从资料菜单带稳定 ID 与固定 versionId。自然语言明确指令允许路由到同一服务端 skill selection，不确定则给推荐卡片。选技能不隐式把 sourceScope=SELECTED 改为 AUTHORIZED_LIBRARY。

执行状态复用现有 QUEUED/RUNNING/WAITING_INPUT/WAITING_CAPABILITY/PARTIAL/RESULT_UNKNOWN 等，不另造与持久状态不一致的进度。长任务显示真实阶段，离开页面可恢复；错误保留输入并提供重试。

### 4.3 五项细化交互

| 技能 | 必要参数 | 中间交互 | 成果及继续修改 | 首发边界 |
| --- | --- | --- | --- | --- |
| PPT | 主题或选定资料；用途/受众/页数/风格可有默认值，模板可选 | 可编辑大纲，也支持直接生成 | 页面预览、定位某页修改；保存 pptx + 源文件/素材 + 缩略图 | 不承诺任意模板无损还原或图片变可编辑对象 |
| 看板 | Excel/CSV、工作表、关注问题 | 预览字段；仅歧义指标需要确认口径 | 隔离网页、筛选/明细；固定数据版本；替换数据生成新版本 | 不承诺实时同步/业务数据库接入/多人写入 |
| 整理 | 个人空间文件夹或文件集、分类方式 | 展示原/新路径、命名、重复依据；可逐项取消并确认执行 | 变更记录、失败项重试、冲突可解释的撤销 | 默认不删除、不覆盖，不以相似度认定完全重复 |
| 一图 | 资料或文字、用途 | 关键内容、布局/风格/尺寸可修改 | 图片预览、版本、文字摘要；可调整重生成 | 位图输出；长内容拆图；精确数据图表用看板 |
| 会议 | 音视频；主题/人名/术语可选 | 转写、校对；无法识别的负责人/日期保留待确认 | 录音定位、逐字稿、纪要、待办关联保存 | 不自动入会或录音，不自动派发提醒；说话人分离单独验收 |

成果先作为任务私有草稿保存，用户显式保存至个人空间；按现有发布规则共享。任务重试不重复创建成果，修改保留旧版。公开分享不随保存自动发生。

## 7. 发布前验收

1. 现有无 skill 的会话请求兼容；草稿、租户切换、输入法、斜杠选择、取消、重试可用。
2. 跨租户/跨用户原件与成果不可读；来源撤权、任务执行期间撤权、停用企业、过期 attempt 必须生效。
3. PPT 可编辑可预览，指定页修改不意外改动其余页；看板指标及交互准确，使用固定数据快照。
4. 整理只作用于选中个人范围，预案和执行一致，冲突跳过并能解释；禁止自动删除。
5. 图像重要数字/文字核对；会议不编造决议、人名与截止日。真实质量验收和自动测试分开记录。
6. 关闭页面不丢任务；保存、重试不会重复发布；分享不扩大源资料权限。
7. 首批依赖/许可和最终包摘要可追溯；运行产物与固定源码一致；恢复旧版本不丢新成果。
