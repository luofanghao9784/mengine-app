# M6-A1 Excel 统计成果边界

2026-09-24，M6-A1 第三切片，DEC-067，沿用 AI-02—AI-04、WS-08—WS-11、WS-14。用户已授权继续既定开发；本批为可逆实现选择，不新增云模型费用、企业共享或后台运行授权。实际检查见[验证记录](../交接/M6-A1Excel统计成果验证-2026-09-24.md)。

## 当前可用流程

用户明确选择 CSV/TSV 原件版本并提出统计要求，Agent 激活 file-processing 1.1.0，经 read_original 加载后调用 csv_summary。仍使用原有完整文件统计规则：计数、精确十进制求和、分组及完整字符串筛选；成功时同时交付 table-summary-N.json、table-summary-N.xlsx 和 processing-report-N.json。TXT/Markdown 提取仍只生成文本及报告。

Excel 是实际计算结果的快照，包含“汇总”和“来源与口径”两张表：原件行数、匹配行数、参与求和行数、明确跳过的空值、总计及分组；另记录原件名称、版本/ID/摘要、配方版本和参数。它不含原表全部明细，不把每份原件复制给模型，也不是可编辑后联动重算的模板。需要重算时对明确原件版本发起新任务。

页面沿用私人任务成果下载入口，浏览器核验附件和摘要。原件上传新版不会改变既有任务输入或下载文件；刷新仍取同一持久成果。资料权限、企业停用、私人所有权继续由平台执行；管理员不能借成果链接读取私人文件。Excel 不自动进入企业资料库；前一切片的文稿发布入口没有被扩大为任意二进制共享。

## 精度、文本和版式

计算仍采用 BigInt 定点十进制，结果 JSON 和报告保留规范十进制字符串。XLSX 中计数以及不超过 15 位有效数字的合计为数值单元格；超过该范围的合计使用文本单元格保留完整值，并在口径页说明。不得通过 Number 转换长整数/高精度合计。该选择依据 [Microsoft 数值精度说明](https://support.microsoft.com/en-us/excel/format-numbers-as-text)，不代表 Excel 能对超精度文本继续精确运算。

分组名称、文件名、列名和筛选值始终以 inline string 写入。前导零、`=1+1`、URL、XML 特殊字符及合法换行不会成为公式、宏或外部链接。OOXML 转义形式的字面字符串保留原文。空分组保持空白，避免与真实名为“（空值）”的分组混淆；未分组时明确标记全部匹配记录。源输入无公式执行或区域数字猜测。结构参考 [Microsoft SpreadsheetML 单元格](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.cell)。

样式采用简洁中文标题、浅蓝表头、冻结汇总前十行和分组筛选，数字列明确对齐；合计横跨宽区域，分组长值适当换行。非法 XML 字符或会导致行高超限的文本明确失败，不悄悄删字符、裁切或只返回部分 Excel。字体按阅读器可用字体回退，不嵌入额外字体或联网资源。

## 运行与隔离

生成器是引擎随版本发布的受限 OOXML/ZIP 实现，无新增运行依赖。计算和表格生成函数作为只读任务输入模块进入既有 TaskSandbox；执行脚本只导入该固定模块与 Node 内置库，不加载用户提供的 JS 包/路径。原件和工具代码均只读，输出仅在该任务目录；macOS 的真实隔离执行本批已验，Linux 路径沿相同端口，未重跑 Linux 实机。

XLSX 单文件默认上限 24000 字节；任务原有 8 份/64 KiB 产物总量和工具响应 64 KiB 上限不放大。原件仍限单份 256 KiB、共三份/512 KiB；CSV 仍为 20000 行、200 列、100 组，JSON 摘要 12000 字节。长单元格显示高度超过 400pt 明确 TASK_FILE_LIMIT；不可表示字符 TASK_FILE_DATA。失败不持久成功回复或半成品，这些均为当前可逆的验证上限。

处理报告沿用 output 描述 JSON/文本，并兼容增加 workbook 的文件名、字节数与 SHA-256。完整文件保留在内部工具执行回执，由平台校验后持久化；通过 TaskTool.modelOutput 将 csv_summary 提交给模型的内容限定为计算摘要、源版本及文件元信息，排除这些产物的 Base64。text_extract 仍按原有方式提供文本产物给模型，其他工具保持原有行为。本投影不代表统计摘要不包含业务信息，真实模型的数据范围和费用仍待配置确认。
