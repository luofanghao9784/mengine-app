# M5-A1 会话成果画报边界

2026-09-23，首个实施切片，DEC-064。沿用 AI-01、AI-11、DASH-01—DASH-04 和私人会话权限；用户授权自主推进既定模块。本批从已持久化的成功任务生成私人画报投影，不新增模型调用。

## 结果与时间

- 每个会话在当前范围内只出现一张卡片，选择最后一次成功的 AGENT 回复。排队、运行、取消和失败都不会替换上一次成果，SOURCE_LOOKUP 不伪装 AI 回复。
- 卡片携带原会话、确切任务、空间、完成时间、执行类别、引擎版本及来源/原件/产物数量。正文只取回复前 600 个 Unicode 字符，超出有省略标记；完整内容在原会话查看。不将摘要另送模型，不解析 HTML。
- 最新按任务实际完成时间倒序；关注不改变完成时间。按日期查看时使用浏览器 IANA 时区的本地日边界，选择该日每个会话最后一次成功回复。后台接口默认 Asia/Shanghai，拒绝无效日期和时区。
- 日期卡片打开确切历史任务，即使会话已有超过一页的新任务，也不跳成最新回复。历史视图可返回原会话继续；不会创建副本。现有成功任务事实不可通过重试覆盖。
- 这是已有任务结果的日期回看，不是定时主动分析、每日画报整版快照或引擎自进化。上述能力继续保留在 M5。

## 私人偏好与权限

关注、隐藏/恢复、标准/加宽尺寸保存在平台数据库，同一会话所有日期共用偏好；隐藏不删除会话或停止后续工作。写入包含 requestId 和 expectedRevision，重复请求不重复修改，并发旧版本返回 BRIEFING_REVISION_CONFLICT。偏好不影响原始内容和来源。

读写均检查当前账号、企业成员状态、企业状态及会话所有者；读取卡片还复核空间、引用和所选原件权限。只读空间成员可维护自己的画报偏好，不能借此更新企业资料。同一空间的其他成员、企业管理员和总台均无私人内容旁路。V11 复合外键绑定企业、空间、会话和所有者，不能写入跨范围偏好。

列表在权限、空间、日期和视图过滤后分页，单页上限 30（网页 20），不返回对象存储路径、任务凭证或原件正文。响应 private/no-store，变更需要 CSRF；恢复页签可见、窗口聚焦或手动刷新重新获取授权范围，拒绝后清除旧画报。已展示或下载内容不能从用户设备远程撤回。

## 前端与升级

真实客户端 `/workspace/` 新增智能画报入口，沿用三端共用导航、顶栏和组件，白色圆角卡片与日期分组适配桌面/窄屏。真实入口目前只有会话成果；完整 Demo 的多类型卡片、浮层动画、四种网格尺寸、拖移/触屏编辑、归档、AI 优化编排仍待接入。临时尺寸按钮与独立已隐藏视图是本批可逆接入选择，不替代已确认的最终交互。原 Demo 未被覆盖。

增加画报 API 1.0.0 和 Flyway V11；会话 API 1.4.0 增加 `GET /conversations/{conversation}/tasks/{task}`。引擎仍为 0.8.0，Agent 1.4、来源/能力 1.0、原件回调 1.3 不变，引擎无需为画报升级。先升级平台再更新前端；回退旧前端保留 V11 数据，不手工删除偏好或任务历史。生产升级/回退尚未演练。
