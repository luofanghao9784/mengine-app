# M3-A1 本地解析与 WeKnora 接入边界

2026-09-23。用户本轮明确“还没有，先完成本地能力”。本地解析、关键词检索与固定来源引用已经实现；WeKnora 只完成锁定版本的来源/API 核对，**没有运行其服务或模型，不计作实机接入验收**。对应 WS-08—WS-11、AI-02；以下是可逆实现选择，不新增客户权限或模型费用承诺。

## 平台与执行器

Spring Boot 持有原件、资料/版本身份、空间权限、任务与片段；`DocumentParser` 只接收本次获准版本的字节并返回结构化提取结果。默认本地实现通过独立受限进程运行，格式与限制见[执行器说明](../../workers/parser/README.md)。替换解析器不改网页契约，也不迁移原件归属。未来引擎调用平台接口取得授权片段，不直接读取此数据库、对象目录或第三方全文索引。

V6 建立 `knowledge_runs` 与 `knowledge_chunks`，通过 tenant/space/material/version 组合外键绑定原件版本。上传事务同时排队；未启用执行器时仅保存原件，用户可在启用后对具体版本发起解析。解析开始和写回都重新验证请求人的当前账号、企业成员及空间维护权限。撤销维护可能取消先前已排队的任务；其他有维护权限的成员可重新发起。

任务：`QUEUED → RUNNING → READY/PARTIAL/FAILED/UNSUPPORTED/CANCELLED`。120 秒租约，至多 3 次接管，旧租约结果不可写回；每次手动重新解析生成新批次，原片段不覆盖。队列与状态存储于 PostgreSQL，后台单执行槽；仅在 Web 进程且显式启用时启动，CLI 初始化管理员不启动解析。

网页提供“查看 vN 解析”、重新解析、“搜索内容”和来源片段。每次读取和检索复核企业/空间权限；管理角色没有正文旁路；正文以文本渲染。只读成员可查看提取结果，重新解析要求维护权，操作使用 CSRF、请求幂等键和期望批次。

## 本地检索规则

[Knowledge API 契约](../../contracts/public-api/knowledge.openapi.json)与[TypeScript 类型](../../contracts/public-api/knowledge.ts)为客户端边界。

- 内容关键词检索，至多 8 个空白分隔词，大小写无关的包含匹配；中文可输入短语。不宣称向量召回或语义理解。
- 在 SQL 授权条件内限定空间，再匹配内容与分页。省略空间仅汇总可见共享空间；显式个人空间仅本人访问。空授权范围为空结果。
- 默认只搜索资料当前文件版本的最新解析批次，且状态必须为 READY/PARTIAL；新版排队/失败或重新解析期间不悄悄返回旧内容。
- 历史引用使用片段 UUID，固定到具体文件版本和解析批次；重新解析不会改写旧引用。每次读取历史引用仍复核当前权限。
- 本地初版 SQL 包含匹配未建全文/向量索引；查询有 3 秒服务端时限。大资料量召回质量和性能待后续真实样例/WeKnora 验收，不把少量合成样例当作规模验证。
- 当前没有删除文件、移动空间或删除索引的业务入口；未来增加时必须同步阻断检索/旧引用，并补齐删除与回收测试。不能把本轮撤权测试写作删除验收。

## WeKnora 核对记录与后续门槛

本轮核对 Tencent 官方 **v0.8.0** 提交 `1edcd54b43606d9079bb36650efe3f68707a79ea`，不依赖浮动 main，也没有猜测 SDK。来源：[官方版本](https://github.com/Tencent/WeKnora/releases/tag/v0.8.0)、[锁定 API 文档](https://github.com/Tencent/WeKnora/blob/1edcd54b43606d9079bb36650efe3f68707a79ea/docs/api/knowledge-search.md)、[许可证及第三方内容](https://github.com/Tencent/WeKnora/blob/1edcd54b43606d9079bb36650efe3f68707a79ea/LICENSE)。主项目 MIT 不代表所有附带依赖和模型许可相同。

检索端点为 `POST /api/v1/knowledge-search`，使用服务端 `X-API-Key`，指定 query、knowledge_base_ids 和 knowledge_ids。`resource_urls=handle`；不向客户端暴露第三方公有资源 URL。接口直接返回片段并不表示整个检索过程完全不需要嵌入/重排模型。文档“必须指定知识库”与仅文件 ID 的例子存在差异，未来适配器应同时传入显式知识库和非空获准文件列表；空列表直接返回空，不发外部请求。

后续真实接入仍需：独立受控服务、模型配置和调用范围；平台版本与第三方知识 ID 映射；上传/解析状态转换；权限过滤前置与结果映射后二次核对；默认无权限、跨企业、撤权、旧版本、新批次、重试与索引重建的实机验证；保留 notice 并核验实际镜像。暂未编写或启用远程 HTTP 适配器；源文件核对不能代替这些步骤。

本地能力可继续支撑 M4-A1 会话/任务接口；WeKnora 实机验收保持为 M3-A1 的未完成项，配置就绪后独立推进。Harness 与真实模型会话不包含在本次结果中。
