- 当前 npm `latest` 标签与显式版本不一致；初次安装实测还发生 peer 依赖把 `session-persistence` 提升到 `0.1.5-rc.3` 的冲突。因此 18 个 Harness 包通过 `overrides` 固定同版，其余依赖由 lock 固定。使用 `npm ci --ignore-scripts`，未用 force/legacy-peer-deps 绕过冲突。
- `sdk-minimal@0.1.5-rc.2` 实际为配置包，其 `cordis.patch.yml` 带本地 Shell、子进程和 `danger-full-access` 策略及用户配置层；未安装/启用整套配置。只装配核心服务和本项目授予的工具，native 模式关闭 PTC 代码工具路径，没有用户目录配置或动态插件装载器。
- 上游 `ToolRuntime.register` 接收底层定义，不自动执行 `defineTool` 才附加的参数验证。本项目在调用执行函数前显式验证 schema 和实参，并在文件/代码工具再次检查句柄、字节数及授权。上游 schema 子集不支持 `minLength/maxLength`，代码长度由本项目服务端检查，不能只声明约束而误认为生效。

## 独立升级边界

`ports.ts` 的 `ModelPort`、`TaskTool`、`RuntimeResult` 与 `sandbox.ts` 的 `TaskSandbox` 为本项目接口；平台和 React 不导入 Harness 的类型或 Cordis 插件结构。`harness.ts` 是唯一核心适配实现；替换 Harness 需复验循环、参数、预算、取消、错误和回执，不能改变平台的权限与状态事实。

每次调用新建上下文并在结束后释放。当前授权副本采用不可变快照，没有跨任务全局文件缓存，没有数据库凭据。外部 Skill 文本和模型工具参数不能新增工具。并发工具数暂定 1，真实执行状态按 call ID 对应，不把多个调用回执混到最后一个工具上。

模型端口是可信供应商适配代码，不是任意插件执行入口；应遵守取消信号。当前无真实 HTTP 适配器，未验证坏连接或不响应取消的供应商。云模型密钥及外部数据出口不进入任务执行进程；具体网关需下一切片落实。

## 本地资源和文件边界

以下是可调工程上限，不是用户购买额度或最终产品限制：

- 默认 4 次模型调用、4 次工具调用、15 秒运行预算；最高分别为 12、16、60 秒。模型累计输出及单次工具结果 JSON 上限 64 KiB，无静默重试。
- 最多 10 个输入副本、合计 1 MiB；句柄为不含目录的受限名称，文本读取最多 16 KiB 且须为 UTF-8。代码最多 16 KiB。与现有资料库原件上传上限无关。
- 独立执行默认 10 秒、最高 15 秒；OS CPU 限制 5 秒，单文件 64 KiB，文件描述符 64，禁 core dump；Node JS 堆限制 64 MiB。**JS 堆限制不是进程总内存硬配额**。
- stdout/stderr 合计超过 64 KiB 立即结束进程，stderr 不返回模型。完成后仅接受至多 8 个普通输出文件、总计 64 KiB，拒绝目录、软链接和硬链接。这个输出检查并不是执行中总磁盘硬配额；云端接入前必须另验内存、文件数量及磁盘限额。
- 父进程写入只读输入和脚本。受限进程仅可写本次 outputs/tmp，OS 拒绝其他任务/宿主数据文件、输入覆盖及所有网络，包括 localhost；只授予系统库、实际 Node/dylib 文件和当前任务读取。系统文件元数据及根目录读取为运行所需的例外，不承诺宿主元信息完全不可见。
- 环境白名单不继承密钥、NODE_OPTIONS、用户配置；OPENSSL_CONF 指向 `/dev/null`，不读取宿主 OpenSSL 用户配置。Node 权限机制额外拒绝子进程、worker 和原生扩展，但 OS 沙箱才承担文件/网络边界。
- 取消、超时、正常完成后清理实际进程组和任务目录。没有可用沙箱则失败，不尝试裸跑。该后端仅用于 macOS 本地合成原型，**未启用真实客户任意代码或公开包安装**。

运行结果按 call ID 保留通过校验的真实工具输出，产物含临时字节与 SHA-256；平台无需从模型文案反推产物。取消/失败时不交付这些输出。没有正式对象 URL，也没有发布动作。平台后续必须根据任务/attempt/当前权限核验、持久化并记录来源；本原型的 `completed` 仅表明循环结束，模型文本不能替代成果验证。
