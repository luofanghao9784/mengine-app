# M6-A1 企业动态边界

2026-09-24，M6-A1 第四切片，DEC-068。沿 WS-05、WS-07、WS-12、WS-14、ACT-01、ACT-04 的已授权开发方向，落实共享资料维护记录；本批具体分页及页面布局为可逆实现选择，不新增私人任务的公开授权。

## 首批行为

工作空间首页在“我的空间”下展示“企业动态”，复用三端面板、按钮、徽标、分页、错误及空态样式。默认汇总本人当前可见的共享空间，支持单空间筛选、刷新及前后翻页。没有另设管理端内容入口。

每个已提交的资料版本对应一条记录：上传资料、上传新版本、明确发布文稿、明确更新已发布文稿。展示维护者当前姓名、当时文件名、目标共享空间当前名称、版本和保存时间；“下载 vN”使用该条不可变版本，“进入资料位置”进入当前目标目录。发布动作由员工明确发起，所以显示员工维护，不把 AI 参与文稿生成冒充系统自主发布。个人文稿编辑不会出现企业动态。

当前 API 单次操作一份文件，因此一版本一记录；发布重试、同一来源重复发布等沿现有去重结果，不另发一条事件；失败、回滚、下载和重新读取动态不会增加记录。既有共享版本直接构成历史，保留原保存时间，不以启用功能的时间伪造历史。尚无批量上传/批次身份，不按时间相近猜测一批操作。

## 权限与数据最小化

- 请求须为有效账号、有效企业及有效成员；总台身份和企业管理员身份本身不授予内容访问。
- 在 SQL 查询中先限定当前企业、SHARED 空间和该成员当前空间授权，再排序分页。没有授权的文件名、空间、数量和游标不会进入结果，也不返回全企业总数。共享只读成员可以读取动态，无需维护权。
- 查询持有与资料读取相同的企业 SHARE 锁，等待权限事务后重新核验成员及授权。指定不可见/个人/不存在空间统一拒绝，不回退至其他范围。
- 只投影目标资料版本与发布类型；不返回私人文稿 ID、会话/任务/原始来源 ID、提示、回复、内部对象地址、邮箱或凭据。完整审计日志不作为客户端动态源。
- 独立企业副本按已确认的目标空间权限读取；作者停用或私人来源撤权不删除已获准的共享记录，历史维护者仍显示其账号当前姓名。读者撤权后列表及旧下载立即按服务端权限拒绝/过滤。
- 页面刷新、窗口重新聚焦和会话变化会重新取数；失败时撤下旧列表，切换空间/页码和离开页面取消旧请求/下载，迟到响应不得重新显示。没有常开推送；持续停留页面时不承诺瞬时抹除已显示信息，下一次操作仍由服务端复核。已下载本地副本不承诺远程收回。

## 接口、实现与升级

新增 Activity API 1.0.0：`GET /api/v1/tenants/{tenant}/activity`，可选 workspace、cursor、limit；默认 20，最大 50。按 material_versions.created_at、id 降序，以原始时间精度及 UUID 组成不透明使用的下一页游标；游标仅是位置，不承载授权。新增较新记录不挤动既有下一页；刷新返回最新记录。期间新提交的旧时间事务或授权变化以重新读取为准，不承诺跨页数据库快照。

直接投影已提交的 material_versions 和 document_publications，无第二套事件写入或双写时序；发布与目标版本同事务可见。V14 只添加版本排序索引，既有数据及存储没有迁移重写。固定下载继续复用资料 API；设置 private, no-store，不在 localStorage 保存动态。

引擎保持 0.9.0 / Agent 1.4，独立引擎无需新增动态回调或直接写业务表。发布 API 1.1.0 和其他契约保持原版本。部署时平台先运行 V14，再更新网页；旧网页不需要调用新接口。回退 UI/API 可隐藏入口，额外索引不会改变业务数据；实际部署/回退尚未演练，历史迁移文件不删除。
