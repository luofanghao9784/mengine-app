# M7-A1 运行用量与当前异常概览

2026-09-24，DEC-071。对应 M7-A1 自用与运行验收、M2-B2/M2-B3 管理端接续、POS-03/POS-06 及需求基线第 13 节。首批提供可核对的运行汇总，不提供内容排障入口、账单或额度管理。

## 入口与授权

总台增加“运行概览”页签，展示全平台（包括停用企业）的汇总；在企业详情内可展开该企业的概览。企业管理端增加相同页签，只允许有效账号、启用企业、启用成员且角色为企业管理员时访问。平台角色不自动成为企业成员，企业管理员不因此拥有员工私人内容权限。

三条只读 GET 接口使用 [Operations 1.0.0](../../contracts/public-api/operations.openapi.json)：

- `/api/platform-admin/v1/operations`：平台管理员的全平台汇总。
- `/api/platform-admin/v1/tenants/{tenant}/operations`：平台管理员的单企业汇总，包括停用企业。
- `/api/tenant-admin/v1/tenants/{tenant}/operations`：有效企业管理员的本企业汇总。

服务端每次检查账号、角色与范围，企业管理读取复用企业共享锁及等待后的权限复核。汇总后再核对身份；不复用授权结果或建立聚合缓存。HTTP 返回 `private, no-store`；两个页面共享组件、样式和契约校验，切换企业时重建统计组件并取消旧请求。迟到响应、错误企业或错误时间范围的响应不能成为当前企业统计。

## 数字如何计算

| 项目 | 首批口径 |
| --- | --- |
| 时间范围 | 只支持滚动最近 7 天/30 天，按服务端时间 `[from, checkedAt)` 选择**创建时间**在窗口内的任务，不是自然日，也不是该窗口内发生的所有任务事件 |
| 状态与任务总数 | 按同一数据库语句快照读取任务当前状态；排队、执行中、成功、失败、取消、中断互斥且合计等于总数 |
| 重试 | 同一任务显式重试仍计一个任务；“重试已启动”累加这些任务的 `max(attempt-1,0)`，尚未认领的重试不算已启动；不是时段内的重试事件数 |
| 原件存储 | 全部已提交 `material_versions` 的字节数、版本数及去重资料数，包括个人、共享、历史版本和停用成员保留原件，不受任务时间范围影响。独立发布副本按实际新增原件计入 |
| 存储排除项 | 不含解析/检索索引、任务附件、文稿内容及导出、数据库附加开销、备份、未提交临时文件；不是磁盘空间或计费容量 |
| 模型调用 | 仅成功 Agent 任务**最后一次成功尝试**的模型回执；按 `live` 和 `verification` 分开，来源检索任务不产生模型用量 |
| Token | 只累加已上报的输入/输出值；显示已上报任务数/成功任务数。不完整回执保持不可得，不用 0 代替缺失；合法上报的 0 与未上报区分 |
| 当前异常 | 该时间范围创建、目前仍为 FAILED/INTERRUPTED 的任务，按固定错误类型计数及最近时间。未知值归 OTHER，不透传原始诊断；成功重试、重新排队后从当前异常移出 |

所有统计由平台业务表计算，不用模型描述代替结果。一个 SQL 快照避免任务状态并发变化导致同一次响应内分项与总数不一致；查询限制 3 秒，失败时页面显示不可读取，不伪造零值。本批不新增迁移或索引，数据库仍为 V14；适用于当前自用/小规模试点，后续按实际数据量验证查询计划和聚合性能。

`verification` 显示为“本地验证（合成模型）”，不能累加到正式调用冒充真实业务或费用。本批没有按尝试持久化完整模型消耗：失败、取消、中断及成功之前尝试可能已消耗 Token，但未包含在成功回执里。因此成功回执汇总只能用于观察，不用于扣费、配额或供应商对账；无价格推算、货币金额与收费承诺。

## 内容与产品边界

后端只选择汇总所需字段，不查询或返回资料正文、提示词、回复、文件名、会话标题、模型自定义名称、工具参数、日志堆栈、对象路径、凭据或任务/会话/空间/成员标识。单企业接口只返回已授权的企业编号；没有跳转客户内容或下载操作。

异常类型来自固定枚举，不能通过新增模型错误字符串产生内容旁路。首批不是完整错误历史或审计系统，也不展示单个员工或空间的用量。保留既有任务记录和权限机制，不新增跨企业支持访问权。

两个管理端沿用现有导航、按钮、标题、面板和主题变量；仅在进入概览时加载，不持续轮询。可选时间范围、手动刷新、空状态、请求失败、撤权及窄屏均提供明确反馈。现有客户端、引擎 0.9.1、Agent 1.4、回调 1.3、来源 1.0 不变。
