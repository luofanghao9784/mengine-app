# M4-A1 会话与本地任务边界

2026-09-23。沿用户“继续下一步”和先完成本地能力的决定，本批交付 M4-A1 的第一个可运行切片；不把资料检索当作 AI 对话完成。对应 AI-01、AI-02、AI-04 及任务书 M4-A1。原需求编号和完整 Agent 目标不变。

## 平台负责的事实

`conversation` 模块持有私人会话、任务、顺序事件、来源引用。Flyway V7 只增加结构和组合约束，不改动已有原件、授权与解析数据。任务从创建到完成都在 PostgreSQL 持久化；网页或引擎退出不删除它。

- 会话固定属于一个企业、发起人和资料空间。即使选择共享空间，会话也只对本人可见；管理员、同事和总台不能因此读取。共享资料只读成员可查找资料，不获得上传/维护权。
- 首次发送才创建会话。当前每个会话只允许一个 QUEUED/RUNNING 任务；不同会话仍独立排队。关键词至多 200 字符、8 个空白分隔词，复用已有知识检索规则。
- 本批只支持 `SOURCE_LOOKUP`：平台在当前权限内检索最多 10 个固定片段 ID；独立引擎返回确定性的来源结果；平台复核后保存引用并展示原文。没有自然语言生成、向量检索、模型用量或自称完成的成果。
- 当前历史一次最多 50 条（网页 20），最新一页按时间正序显示，可翻看更早记录。成功来源按固定版本/解析批次保留，不随文件更新悄悄变化。

## 状态、取消与恢复

`QUEUED → RUNNING → SUCCEEDED / FAILED`；排队或运行可以 `CANCELLED`。RUNNING 租约过期后变为 `INTERRUPTED`，不自动重复执行。FAILED/CANCELLED/INTERRUPTED 经本人明确重试返回 QUEUED。

每次领取生成新 attemptId（租约令牌），租约 30 秒；每次状态变化递增 revision 并记录顺序事件。取消或重试必须携带当前 revision；旧版本返回 409。取消立即阻止平台接收旧尝试的结果，重试不会让旧结果覆盖新尝试。取消与完成竞争时以数据库先提交者为准，页面重新读取事实。

本地引擎单次调用超时 5 秒、平台完整接收总上限 6 秒、响应最多 16 KiB。当前取消是停止结果交付，不是远端杀进程；后续真正的模型/工具任务必须补取消传播、资源释放和计费验证。正常重启保留排队与终态记录，遗留运行记录在租约到期后中断，等待明确重试。

发送与操作都使用 actor/requestId 幂等键；相同请求只返回当前结果，不重放动作，同键异内容拒绝。网页在发送前保存当前参数和键，响应丢失时可在同一标签页刷新后明确重试。未发送草稿存于按账号、企业、会话区分的 sessionStorage，不保存密码、Cookie 或模型密钥，不承诺跨设备/关闭标签页后的恢复。

事件采用带游标的有界轮询（页面约 1.5 秒），不是模型 token 流。读取详情先取游标再读状态，避免并发提交造成漏掉变化；重复观察同一变化可接受。客户端重新连接、轮询拒绝和身份变化后重新鉴权，不静默显示旧结果或 Demo 数据。

## 权限与替换边界

创建、读取、列会话、事件、取消/重试、执行检索和完成写回都以有效账号、企业成员及空间授权为依据。撤回空间访问后，会话列表不再返回标题，详情/事件拒绝访问；历史来源读取再次授权。企业/成员/账号停用同样阻止新读取和交付。来源组合外键限制 tenant/workspace/task/chunk 的归属；引擎不能自行补入另一个来源。

平台用企业共享锁与管理撤权串行化；会话写入使用非键更新锁，避免任务事件外键检查与取消形成倒置等待。任务领取使用 SKIP LOCKED，完成凭租约和状态条件写入；解析与会话调度使用两条调度线程，避免解析文件时阻塞所有会话分发。

独立 `TaskRuntime` 适配平台与引擎。公开 DTO、任务主键、原件、版本、权限和事件由本项目维护，不暴露第三方 SDK 类型。新增协议见 [Conversation OpenAPI](../../contracts/public-api/conversation.openapi.json) 与 [本地引擎协议](../../contracts/engine-api/source-results.schema.json)。

- 本地引擎版本 `0.2.0`；没有服务间密钥时仍为 `contract-only`，配置至少 32 字符密钥后声明 `local-retrieval / source-lookup`。
- 平台显式设置 `TASK_ENABLED=true`、`TASK_ENGINE_TOKEN` 和 `ENGINE_BASE_URL` 才启用。试用监督程序为每次运行创建随机密钥和独立引擎端口，只由本任务进程持有，关闭时只停止自身子进程。
- 引擎不读业务数据库，不接收资料正文，不执行文件、Shell、插件或网络任务；本地模式不是通用 Agent 沙箱。未来引擎独立替换仍需协议兼容与权限/取消回归，不能只更改能力名称。
