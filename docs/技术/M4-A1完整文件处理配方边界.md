# M4-A1 完整文件处理配方边界

2026-09-23，第八实施切片，DEC-063；沿用 AI-01—AI-04、AI-12—AI-13、WS-08—WS-11、POS-05。用户授权自主完成既定模块，业务权限、费用与交付范围等实质决定仍需确认。本批沿用本地优先及验证环境，不新增模型调用或资料外发。

## 能力与权限

可信目录新增 file-processing 1.0.0；先激活指南，再列出/读取用户明确选定的固定原件，通过 process_original 使用发布版本内置的处理配方。模型提供受限参数，不提供这一步的执行脚本。配方运行在既有离线 TaskSandbox，输入只含已授权并已读取的一个版本，不接收路径，不改变原件。

| 配方 | 当前可验证范围 | 明确限制 |
| --- | --- | --- |
| csv_summary | UTF-8 CSV/TSV，含引号内分隔符、换行和双引号转义；计数、精确十进制求和、分组、精确字符串筛选 | 必须有唯一且非空的表头；逗号/分号/制表符显式选择；不推断列名、口径或区域数字格式 |
| text_extract | UTF-8 TXT/Markdown，按完整文件或明确的 1 起始闭区间行范围提取；保留纯文字和源行位置 | 不渲染 HTML；不是 Office/PDF/OCR 配方；输出超限不静默截取 |

求和支持最多 30 位整数和 12 位小数，以 BigInt 定点计算后返回十进制字符串。指数、百分比、货币符号、千分位、公式及非规范数字均拒绝；空值默认拒绝，明确 blankNumbers=skip 才跳过并记录数量。count 只是记录数，不执行单元格公式。筛选匹配整个字符串，不暗自忽略大小写或空格。结果报告包含总数据行数、匹配行数、实际数字行数及跳过数量，分组按输入首次出现顺序。

每次成功返回私人结果及 processing-report-N.json，文件名按本任务调用序号区分，重复处理也不会覆盖。报告记录 material/version、输入字节数及摘要、配方版本、调用参数、输出文件摘要和统计/源行范围。平台仍核对 actual originalIds、读取回执和已激活能力；未读取、未激活或不在 verification 的配方回执不能写入成功结果。

## 限制与失败

原件仍沿第七切片：最多 3 份、单份 256 KiB、合计 512 KiB；代码输入、产物和工具调用预算不增加。当前 CSV 最多 20000 数据记录、200 列、100 组，单元格 32768 字符，结果 JSON 最多 12000 字节；文稿正文最多 32000 字节；配方参数最多 2048 字节。这些是验证默认值，不是客户套餐或最终额度。

不支持格式、非法 UTF-8、参数不匹配、资源/输出上限、CSV 或数值不明确分别返回 TASK_FILE_UNSUPPORTED/ENCODING/INVALID/LIMIT/DATA。平台保存白名单代码，页面给出具体修改方向；失败任务不发布成功回复或半成品。取消、撤权、企业停用继续沿尝试授权和沙箱中断机制，原件读取事实与任务成功仍是不同状态。

文本提取结果及工具产物可进入模型上下文；不能把 read_original 的元信息返回边界扩大解释为全部处理内容不出模型。真实模型的供应商、资料范围与预算仍待确认。
