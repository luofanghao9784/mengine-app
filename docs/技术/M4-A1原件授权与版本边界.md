# M4-A1 原件授权与版本边界

2026-09-23，第七实施切片，DEC-062。落实 AI-01—AI-04、AI-12—AI-13、WS-08—WS-11、POS-05 的任务输入边界；沿用用户的本地优先决定。以下数量、大小与交互为可逆实现选择，未新增客户额度、企业内容外发或正式代码执行授权。

## 本批行为

会话中可从当前空间选择具体文件版本。选择界面复用资料库权限、文件夹、名称查找和历史版本分页；默认不选任何原件，最多 3 份，同一资料只选一个版本。提交保存 materialId/versionId，文件名、大小和摘要以平台记录为准。

- 选定后，原件读取和已解析片段检索均限制在这些确切版本；不会把新版或其他文件混入。没有选原件的任务沿用当前空间的最新版本片段检索。
- 上传 v2 不改变任务选用的 v1。重试保留原选择，创建新尝试凭证并重新读取；旧尝试凭证失效。选择项规范化排序后加入发送幂等指纹，换文件或版本不能复用旧 requestId 冒充同一请求。
- 读取只需要查看权限。共享空间只读成员可在本人私人会话处理获准资料，不需要资料维护权限。企业管理员、总台与其他成员没有私人会话/产物的管理旁路。
- 页面分别显示“已选用 · 尚未读取”和“已读取原件”。后者依据本次尝试的服务端读取记录，只代表字节已交付，不代表文件已理解或任务成功。重试排队时重置显示，不继承上一尝试的已读取状态。
- 草稿与选择在当前标签页恢复；任务完成后仍能看到固定版本。产物仍是私人下载文件，不自动发布到资料库、企业共享或画报。

## 平台与引擎边界

平台新增 Flyway V10：`conversation_originals` 保存任务选定版本，`conversation_original_reads` 保存按尝试记录的版本、摘要和读取时间。复合外键约束 tenant/workspace/task/material/version，不依赖前端隐藏或模型自律。原件继续由平台对象存储持有；引擎不能访问业务数据库或枚举存储目录。

内部接口均为 POST，使用现有短期尝试 Bearer，响应 `Cache-Control: no-store`：

| 路径（前缀 `/internal/v1/agent-access/{task}`） | 内容 |
| --- | --- |
| `/originals` | 本任务所选版本元信息，没有文件正文、路径或存储 ID |
| `/read-original` | 仅接受 versionId，返回该版本的摘要和受限 base64 字节 |
| `/search` | 有选择时只检索选定版本的已解析片段；未解析原件仍可独立读取 |

每次使用复核当前企业、成员、空间、私人会话归属、任务状态及租约；读完原件后再次检查。对象存储按大小和 SHA-256 核对实际字节；取消、撤权、停用、租约过期后拒绝后续读取和结果发布。引擎的周期授权检查继续向执行器传播终止信号。已交付到用户设备或已进入运行中执行器的字节不承诺瞬时撤回。

引擎新增 `list_originals`、`read_original`。读取工具只给模型元信息及不含路径权限的 inputHandle，不自动返回文件正文。`run_javascript` 新增可选 `inputHandles`：显式指定已经获准且已加载的输入，不能通过猜测文件名读取未选版本；省略时仅挂载既有检索片段，不隐式挂载原件。文件复制继续走既有 `TaskSandbox` 端口，Linux/macOS 后端接口不变。候选 INI 配方本批仍处理片段，没有扩大其原件访问范围。

任务结束清理引擎持有的原件缓冲，执行目录按既有沙箱生命周期清理。读取工具不返回正文，不等于整个任务不会把资料内容给模型：后续代码输出、提取文字或工具结果仍可能进入模型上下文。真实模型接入仍需明确供应商、允许资料范围和预算。

结果协议要求 `originalIds` 与平台本次尝试实际读取的版本集合完全一致；非空时必须有 read_original 工具回执。省略或伪造读取记录均拒绝，不保存成功半成品。工具回执本身不能替代对象读取记录、摘要校验或执行结果。

## 验证默认值与可用性

| 项目 | 当前实现 |
| --- | --- |
| 原件选择 | 最多 3 份；单份 256 KiB、合计 512 KiB；同一任务空间、同一资料一个版本 |
| 代码输入 | 最多 10 个显式句柄，沿用执行器字节与资源限制 |
| 模型/工具预算 | 各最多 8 次、任务 25 秒；注册工具上限 12 不增加执行次数 |
| 私人产物 | 沿用最多 8 个、合计 64 KiB，不支持直接修改原件 |
| 开放环境 | 平台 `verification` ＋注入沙箱的验证引擎；正式入口不启用代码/原件工具，普通试用仍默认关闭模型 |

使用已安装的官方 Harness 工具 schema 子集；数组长度、重复句柄等在可信执行层校验，不向该 schema 子集塞入未支持的关键字。没有更换 Harness 或扩大沙箱权限。

本批支持完整二进制字节的受控传输，但不因此声称支持任意格式理解。实际证明是合成 CSV 的完整 4000 行统计与结果文件；这段脚本不是通用 CSV/Excel 解析器。大文件、复杂 Office/PDF、宏、更多候选配方及生产额度尚未实现或验收。下一切片以完整原件为输入扩展有明确格式和失败行为的处理配方，再安排真实模型、WeKnora、实际搜索和云节点验收。

## 版本、升级与替换

引擎 **0.7.0**、Agent 请求/结果 **1.3**、公开会话 API **1.3.0**、数据库 **V10**。来源/能力协议仍 **1.0**。新引擎和平台拒绝旧 Agent 1.2；这是需双方协调的契约升级，不能只替换一侧。

升级时暂停任务接收并排空/取消在途任务，备份数据库与原件，先应用追加迁移，再部署匹配的引擎、平台和网页并验证后恢复。旧任务无选定原件，公开响应返回空数组；V10 不更改或删除原件版本。以上是操作约定，本批未对生产执行升级演练。

回退也先关闭 Agent 并停止/取消在途任务，不自动删除 V10 表或文件。已有原件任务不能直接在旧平台重新执行：旧版不理解选定版本约束，可能退回更宽的空间检索。需保持这些任务停止，确认数据兼容与重试策略后才能降级恢复；本批未提供自动降级工具。后续在同一权限和 1.3 契约内可独立替换引擎算法、格式配方或执行器。
