## DEC-011：开发协作规则修订（2026-09-17）

- 原因：避免将待确认的业务事项扩大为全部开发的暂停条件，或将交付验收误作建立骨架的前置条件。
- 决定：在已授权目标内自主完成可逆技术与交互选择；按依赖推进验证；按任务需要和可用权限使用子代理；相关检查通过后仅因新改动、失败或具体未解决风险追加验证。当前阶段状态留在 README 与交接文档，入口资料按上下文需要补读。
- 边界：产品运行时模型与 Harness 单独选型；业务权限、费用及交付承诺不因开发自主性而自动获准。暂定方案和实现结果不等于用户确认。
- 验证范围：本次仅修订协作与开发流程文档，不代表框架选型、Harness 技术验证、应用开发或交付验收完成。
- 替换影响：以后调整开发 agent 或协作偏好时更新本记录和相关规则，无需因此替换产品运行时。


## DEC-022：实际前端 Demo（2026-09-17）

- 依据：用户要求沿 V2 浅蓝极简设计制作实际可交互前端，确认功能、布局与样式，按钮接入具体操作；不要求后端、数据库或真实 AI。
- 选择：React + TypeScript + Vite、Lucide、原生 dialog、浏览器 localStorage 与轻量哈希导航。减少额外框架层，便于继续调整页面和状态；依赖版本由 package-lock.json 固定。
- 范围：工作入口、会话、空间概览、工作台、资料库、仪表盘、应用及个人设置；统一合成状态串联版本、共享申请、梦境分类、业务记录和统计。
- 重要边界：个人修订独立；资料发布与权限申请绑定版本快照；重复批准不重复写入；应用共享只发布配置，个人试填记录不随之开放；无数据源显示空状态。
- 验证：TypeScript 与构建、状态规则测试、真实浏览器操作和布局查看。明细见 [Demo 使用与验收](../产品/前端Demo使用与验收-V0.1.md)。测试前端行为不等于真实模型、服务端权限或客户验收。

## DEC-025：资料库双入口与文件夹模型（2026-09-18）

- 依据：用户指出顶层标签只应切换个人空间与企业资料库，并确认按提出的文件夹浏览方案实施。对应 WS-03、WS-06—WS-08、WS-12—WS-16。
- 选择：工作空间仍为资料所属与权限边界，在企业根目录投影为文件夹入口；新增独立 `MaterialFolder`（空间、父目录、名称），`Material.folderId` 仅管理空间内位置。版本继续属于同一 Material。

## DEC-027 补充：直接拖动卡片与触屏滑动优先（2026-09-21）

- 依据：用户最新指令取消顶部移动把手；桌面直接拖动，触屏长按后拖动，正常滑动不可误判。替代前述把手入口与触屏 10px 长按容差，布局保存、撤销、尺寸调整及右上角完成沿用。
- 桌面：正文 PointerEvent 先记录候选，约 6px 内仍是原生点击；超过阈值后由稳定页面捕获指针并显示浮起预览，释放提交。图片原生拖动关闭；关注、菜单、头像和尺寸把手独立响应。正文鼠标拖动不再触发分类切换或下拉刷新，空白处及触控板保留原入口。
- 触屏：每次单指静止 500ms 后激活，沿用同一触点继续移动。长按前移动超过 8px、滚动、多指、取消、失焦或视口变化使本次候选失效，停住不重新计时；编辑态也必须每次先长按。仅激活后的 touchmove 阻止原生滚动，不对正文设置 touch-action:none。
- 防误触细节：浏览器可能在原生滚动阈值前延迟 touchmove，因此同时读取 touch 指针的 pointermove 来取消小幅滑动后的长按计时。拖动后的合成点击受抑制，新一次指针接触恢复点击；键盘提交不触发指针点击抑制。
- 可访问性：卡片菜单提供“用方向键调整位置”，拿起后方向键移动、回车或空格提交、Esc 取消；未拿起时保留正文键盘打开会话。读屏提示同步更新。

- 同步：复用 `syncBriefing` 的一源一卡机制，卡片保存回复身份与可选版本引用；新消息即使同文也能识别，刷新和显示偏好不改变回复时间。旧消息无时间时采用首次观察时间，后续稳定。隐藏期间继续同步内容，归档不删除会话、历史或偏好。
- 导航：内容入口直接返回原 chatId，不调用派生会话初始化，不附加自引用消息；卡片优化仍使用单独且排除展示的优化会话。当前预置的3条空谷独立会话也参与显示，原40张内容卡与源资料保持原义。
- 排列：保存布局中的坐标增加可选内容时间 `at`。最新视图通过 `refreshConversationLayout` 将时间变化／新加入的会话放在前面，将其余原布局整体后移；此为只读投影，直至用户再次调整才保存，不清除其他视图布局，也不改变内容规格。
- 可见范围：检查当前会话空间、回复引用资料和指定版本；历史卡片也检查会话当前状态与权限。纯前端检查不构成服务端隔离；后续接入真实模型时以服务端消息时间、任务结果与权限为准，不能把回复文字视为业务执行证据。
- 交互修正：新增最新日期分组暴露入场动画期间小按钮点击落空的边界，鼠标进入卡片时提前结束入场，确保按下与抬起命中同一控件；触屏与减少动态效果沿用原逻辑。验证见[Demo 验收记录](../产品/前端Demo使用与验收-V0.1.md)。
