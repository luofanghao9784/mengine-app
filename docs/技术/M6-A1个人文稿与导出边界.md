# M6-A1 个人文稿与导出边界

2026-09-24，M6-A1 第一个切片，沿用 WS-06—WS-14，DEC-065。用户确认个人文稿继续跟随来源权限；实现不代表整个 M6 完成。实际验证见[验证记录](../交接/M6-A1个人文稿与导出验证-2026-09-24.md)。

## 使用流程与来源

在本人成功的 AGENT 回复旁选择“保存为个人文稿”，或在 UTF-8 TXT/Markdown 产物旁选择编辑。平台读取确切任务/产物正文，创建个人空间文稿；客户端不能提交模型原文、改写所有者、选择他人的任务或解除来源。重复保存同一任务/产物打开同一文稿。其他格式、无效编码、未完成任务和过长/空内容明确拒绝。

资料库“个人文稿”进入本人列表。网页修改标题和正文，明确保存后产生不可变新版本；内容不变不增加版本。原回复、工具产物、资料原件和旧导出不变。页面可逐次查看历史版本，只读下载，也可回到最新版本继续编辑。会话中的模型回复不是网页编辑后版本，两者有单独身份。

## 授权与一致性

- 每次列表、详情、编辑、导出和幂等重试检查当前账号、租户、成员、个人空间所有权及原会话和固定来源。来源空间撤权后记录保留，无法查看、编辑或下载；恢复授权可再次访问。总台、企业管理员和同空间其他成员没有私人内容旁路。
- 当前会话只允许一个来源空间，引用与原件受该空间约束；V12 用复合外键保留源会话/任务/产物关系。后续支持跨空间任务时必须扩展来源依赖集合和列表过滤，不得只检查首个空间。
- 保存用 requestId + expectedRevision；两个并发编辑仅一个成功，另一个 409，草稿不丢弃。请求键绑定主体、目标与内容，响应丢失后明确重试原请求；后续已有其他编辑时，重试仍返回本次写入的确切版本及当前最新版本号。
- 数据库锁遵循既有租户授权保护；文稿锁与版本读取分成两个语句，避免等待并发保存后误判 404。缓存下载也先重新授权，不能用知道 URL 或命中缓存绕过撤权。
- sessionStorage 仅暂存当前标签页草稿，账号/企业/文稿隔离；恢复前先获服务端授权。可见页面每 15 秒及重新聚焦复核权限，收到 401/403/404 清除当前文稿草稿并撤下编辑器，身份层在确认退出/失去企业成员身份时提前清除相关草稿以避免卸载竞争；不承诺离线设备远程抹除，已下载副本仍是设备文件。网络失败不当作撤权，暂时隐藏正文并保留草稿以便重新验证。

## 确定性导出与限制

导出读取确切文稿版本，不调用模型，不把正文当 HTML 或脚本，也不读取外部图片/链接。通过 DocumentRenderer 替换排版实现不会改动引擎 API。默认标题 160、正文 32768 个 UTF-16 代码单元；非 XML 字符拒绝。`#`、`##`、`###` 行作为标题，其余 Markdown/列表标记按文字保留。尚非富文本编辑器或正式公文/复杂 Office 模板。

PDF 使用 Apache PDFBox 3.0.8；DOCX 生成受限 OOXML。两种文件嵌入固定许可字体的字形子集，不依赖平台安装 Word、LibreOffice、开发工具运行库或联网字体。字体来源、OFL、摘要及重建脚本见[字体说明](../../apps/api/src/main/resources/fonts/README.md)。DOCX 缺失字形仍保留 Unicode 文本，目标阅读器负责回退；PDF 缺字明确 422，不输出方框伪装成功。导出最多 2 MiB / PDF 100 页，每进程两个渲染槽；失败不记成功缓存。这是首期可逆上限，不是租户费用配额。

Word 字体子集限 BMP 覆盖。FontBox 3.0.8 子集写入 OS/2 v0 字段，故仅对内存实例将表版本归零并清除较新版本位，且不复制重编号后失效的 GSUB/GPOS 等原始字形表。导出保留版权与随附 OFL；本字体已使用派生名称。实际四页中文/英文文件经过独立阅读器渲染与逐页检查，仍需目标 Word/WPS 和真机验收。规范参考：[Word 字体部件](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/ea097c57-5794-4624-b08e-017b47051b1d)、[FontBox 固定版本源码](https://github.com/apache/pdfbox/blob/3.0.8/fontbox/src/main/java/org/apache/fontbox/ttf/TTFSubsetter.java)。

导出按文稿/版本/格式保存独立摘要和生成器版本，当前小文件暂存 PostgreSQL bytea。浏览器验证 MIME、附件头、长度和 SHA-256，再触发下载。生成器升级不覆盖已有固定版本缓存；若日后需要重新排版，应显式增加导出修订。所有响应 private/no-store，错误不返回正文。未来大文件、对象存储、异步队列与租户额度单独实现和压测。

## 契约与接续

文稿 API 1.0.0，Flyway V12；公开会话 API 1.4.0、画报 1.0.0、引擎 0.8.0 / Agent 1.4 不变。平台先应用加法迁移，前端使用新入口；旧引擎无需配套修改。回退前端/平台可以隐藏入口并保留新增表，不能删除用户版本；未做生产升级/回退演练。

下一切片是明确共享到企业资料。已确认目标空间维护权限、明确发布、不公开私人会话及不自动同步。**尚需确定：发布是否形成可独立读取的共享副本，还是共享读者也必须持有原来源权限；来源撤权、发布者离职后的副本行为须一起确认。** 本批没有通过导出再上传或隐藏来源实现绕过，也未启用共享按钮。Excel 成果、动态、完整 Demo 文稿视窗、跨设备草稿和复杂模板继续保留待办。
