# M6-A1 共享发布与企业版本边界

2026-09-24，M6-A1 第二切片，沿用 WS-06—WS-14，DEC-066。用户已按建议确认：明确发布生成独立企业副本，由目标空间权限管理；来源撤权或发布者停用不撤回企业副本。私人文稿仍遵守 [DEC-065 对应规则](M6-A1个人文稿与导出边界.md)。实际检查见[验证记录](../交接/M6-A1共享发布与企业版本验证-2026-09-24.md)。

## 使用流程

个人文稿已保存的当前或历史版本可选择“发布到企业资料库”，指定共享空间、文件夹、Word/PDF 格式，并明确确认目标成员可独立阅读副本。有未保存草稿或未确认完成的保存时先完成保存；发布不读取未保存正文，不调用模型，也不替换原会话回复。

首次发布创建独立资料条目及 v1，可按目标空间权限在资料库下载、解析和检索。私人的来源空间、会话、任务和文稿 ID 不随企业资料接口返回。共享文件只有用户选择发布的标题与正文；如果正文自身包含信息，仍会包含在副本中，发布确认不是自动脱敏。

个人文稿后续修改只增加私人版本；明确选择“更新已有企业资料”并选中目标条目后才增加企业版本。目标资料 ID、所属文件夹保持不变，旧版本和旧下载保留。条目名称沿资料库现有规则保持，具体版本文件名记录发布时标题与格式。无需强制双方版本号相等。改用 PDF 可作为同一资料的新版本。

发布者在私人文稿内可看固定发布回执及目标文件夹入口，包含文稿版本、企业版本、文件名、时间、摘要。列表只展示本人仍有权查看的目标空间；它不是对全员开放的来源接口。资料库版本展示“文稿发布”标记，不提供私人来源跳转。当前没有全员动态推送、通知、匿名链接或审核流。

## 服务端权限与事务

- 发布及重试同时复核当前账号、企业、成员、私人所有权和全部必要来源，以及目标共享空间的维护权限。仅查看权限不能发布，个人空间不能充当共享目标；知道 UUID、管理身份、前端选择均不产生额外权限。
- 发布后，目标成员按现有资料权限读取企业副本；不需要原来源空间权限。原来源撤权、发布者成员/账号停用不会删除已发布文件或使读者失去访问。读者自身撤权或企业停用仍拒绝下载、解析和检索。
- 企业副本复制至平台原件对象存储，具有独立资料/版本/对象 ID 和摘要，不通过私人导出链接间接读取。平台内部保留确切来源关系用于追溯，不在共享响应暴露私人 ID 或正文。
- requestId 绑定主体、源文稿版本、目标、格式和预期企业版本。相同键不同请求返回 409；提交成功但响应丢失时明确重试返回同一回执，不再次执行。
- 不同键的重复发布也去重：同一文稿版本、目标空间及新建文件夹（或待更新资料）、格式只落一次。再次请求返回原确切回执，企业条目后续已有版本也不将旧发布重新置为最新。如需内容修改，先形成新文稿版本，再明确更新。
- 更新复用资料上传的行锁和 expectedMaterialVersion；另一上传/发布先更新则返回 409，用户重新核对当前企业版本。原件写入、版本、发布映射、解析排队、成功回执和审计处于同一事务，失败回滚清理新增对象。
- 锁顺序为请求键、租户授权保护、私人文稿、源会话、目标资料；先导出获取文稿锁再读取来源，避免与文稿保存的锁顺序相反。并发不同键不会重复插入。

解析使用现有 M3 队列，启用解析时随发布排队。文件成功发布不代表解析已经成功；状态在资料库单独呈现。已完成的解析按目标空间读取。尚在运行的解析仍遵守任务发起者的实时权限：发布者失去维护权限或停用可使该次解析取消，目标维护者可明确重试，不影响已发布原件。这一切片没有扩大后台任务的授权或引入系统身份代跑。

## 契约、替换和待办

文稿 API、资料 API 均增至 1.1.0，增加发布接口/回执和可选版本 origin 标记；身份、公开会话 1.4.0、画报 1.0.0、引擎 0.8.0 / Agent 1.4 不变。`DocumentPublicationService` 使用平台导出、资料存储和权限接口，引擎升级/替换不改变共享身份。公开 API 不接受客户端提供的正文、所有者、来源替换、共享对象字节或成功状态。

Flyway V13 只追加映射及复合外键/唯一约束。先升级数据库与平台，再升级前端；旧前端忽略兼容新增字段。平台回退可保留 V13 数据表，既有文件仍按资料库读取；旧代码可能不显示“文稿发布”标记。禁止靠删除表回退并丢失追溯，没有执行生产升级或回退演练。

Excel 成果、企业动态、AI 简介/属性、最终确认标记、复杂模板、共享审批、删除/撤回和平台运维仍按任务书继续。管理员自授权/任命规则没有被本次开发决定；客户私有部署、真实云模型、WeKnora、真实搜索服务和云隔离尚待分别验收。
