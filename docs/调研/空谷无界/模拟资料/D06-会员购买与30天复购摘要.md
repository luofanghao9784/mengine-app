# 会员购买与30天复购摘要

> 为演示信息整合与AI分析编写。内部数字、角色、客户、计划和执行状态均为合成，不是空谷真实记录。文中公开报道与用户提供的信息另行注明。

| --- | --- |
| 既有活跃会员 | 280 |
| 本期新增购买会员 | 210 |
| 既有低频回访会员 | 150 |

分组优先以首次购买日期识别新增；既有会员再按演示规则分活跃和低频回访。只有汇总情景，尚无逐人行为明细，不伪造可审计的真实名单。

独立的30天复购队列：首次购买时间在8/1—8/15的180位合成会员，每人的30天窗口均观察完整，最后观察截止9/14；其中54位在各自30天内再次购买。54÷180=30%。它与本期640人不是同一分母。

“840单−640人=200笔额外订单”不是复购人数；一位会员可能有多笔额外订单。没有真实身份、电话或微信号。
