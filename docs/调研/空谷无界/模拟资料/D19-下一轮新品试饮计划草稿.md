# 下一轮新品试饮计划草稿

> 为演示信息整合与AI分析编写。内部数字、角色、客户、计划和执行状态均为合成，不是空谷真实记录。文中公开报道与用户提供的信息另行注明。

目标：在D10小样本基础上分别验证口味偏好、价格接受及制作稳定性。属于拟议计划，未组织活动。

建议记录字段：合成编号或现场匿名编号、版本、盲测顺序、甜度感受、喜欢/不喜欢的原因、拟价下的选择、出杯时间、异常。不要把“说愿意买”当实际成交。

建议比较：先对V1/V2平衡展示顺序；记录非偏好V2者的原因；增加不同到店动机的自愿参与者，避免只问熟客。所有阈值与样本量由负责人结合可执行性决定，本稿未宣称达到统计显著。

交付：整理一个待审的试饮汇总和配方差异页。进入试售前核对原料、制作稳定性、价格及资料版本，不用“75%喜欢”直接标新品研发完成。
