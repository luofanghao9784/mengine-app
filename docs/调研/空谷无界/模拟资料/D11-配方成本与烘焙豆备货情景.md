# 配方成本与烘焙豆备货情景

合成供应商A的烘焙豆报价情景：128→136元/kg；供应商和价格不是询价实录。

单杯净配方18g，额外损耗按净用量加4%计：0.018×1.04=0.01872kg/杯。价格上涨影响=0.01872×8=0.14976元/杯，展示约0.15元；不是整杯饮品利润降幅。

未来7天独立需求假设820杯咖啡，需要豆820×0.018×1.04=15.3504kg。库存假设6.8kg，净缺口8.5504kg，约8.55kg。均匀需求假设下覆盖3.1天；交期假设3天。

该情景未计活动额外饮品、安全库存、整袋规格及替代豆，不能直接生成采购订单。820杯是备货假设，不能当作本期实售咖啡杯量。

拟议新品配方原料成本：刺梨冷萃8.90元、桂花燕麦拿铁10.40元、山野抹茶拿铁9.80元。拟价分别34、36、36元；差额未扣人工、租金、税费、包装及完整损耗，不命名为实际净利润或经营毛利。
