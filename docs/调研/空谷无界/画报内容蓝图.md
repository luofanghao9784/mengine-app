## 7. 画报编排与日期

首页建议混排经营数字、真实图文、新品进度、活动与短分析；避免让资讯、图表或“风险提醒”占满整屏。最能体现整合的是C02、C15、C19、C32、C35、C40，几张大图用于提供门店与行业语境。

沿用现有Demo至少3天、超过30张卡片的覆盖方向，建议最终40张分成9/17—9/20四期。**本表编号不代表发布时间**：需要在实现时为每期生成与截止时间对应的来源版本；例如9/17卡只能引用9/16及以前的销售。这里9/13—9/19完整周数据、9/20商机与研发状态只用于9/20版。旧日可用当时已发布的新闻和当日可得底表，不把9/20调研或核验假装在更早日期真实执行。所有四期都注明为编写的演示情境快照。

原文日期与画报整理日期分别保存；历史活动明确“历史回顾”。不得通过刷新把旧新闻变成当日新消息。隐藏、固定、会话与资料身份的保留方式在后续场景替换实现时验证。

1. **经营**：C01 → C02 → D01/D05 → C35 → 起草经营复盘。展示多源对齐、口径识别、缺口说明。
2. **新品**：C21 → C12 → C17/C18 → C19 → D19。展示真实行业信息如何与本店模拟记录一起支撑行动建议。
