# 引擎仪表盘改造方案（已确认设计）

> 历史设计参考：本平面方案已由后续 3D 舞台替代。当前实现与验证见[主线整合记录](../交接/前端改版与主线整合-2026-10-06.md)，下文按原设计阶段阅读。

设计稿来源：claude.ai 设计画布「梦核引擎仪表盘 · 改造方案」（2026-10-06 确认）。
同目录 `引擎仪表盘-设计稿.dc.html` 为该画布主画板的完整源码（Design Component 格式，作为视觉与交互参考，不直接作为产品代码使用）。

## 页面结构（总台，可交互原型，1440 宽，流式布局）

1. 引擎仪表盘（星图 + 读数带）
2. 近 5 分钟脉搏
3. 需要留意
4. 近 7 天节律
5. 资料与接入
6. 企业执行分布（仅总台）
7. 自进化（静态预留）
8. 通道详情抽屉（点击左右通道名称或处理节点打开）

## 数据来源与口径

- 星图、读数带、近 5 分钟脉搏：现有 engine-telemetry 快照（页面可见时每 3 秒），无需改接口。
- 需要留意：operations 的 errors（按错误码聚合）+ 遥测中的待核对与保留异常。
- 近 7 天节律：usage 的 days（工作请求、Token）。Token 未回报的日子单独标出，不按 0 画。
- 资料与接入：data-operations 的 CONNECTIONS / MATERIALS 计数。
- 企业活跃（仅总台）：需新增按企业聚合的执行中数量接口，仅返回计数，不含企业内容。
- 自进化：仍为未启用，只做静态预留。

## 动效原则

- 光点数量 = 该通道实际执行中记录数，每条最多 6 个；没有执行就没有光点。
- 排队用通道入口处的珠串表示，一颗珠子一条排队记录，超过 10 条显示 +n。
- 核心光晕：有执行时 3 秒一次呼吸，空闲时 7 秒，与 3 秒采样节奏一致。
- 系统开启减少动态效果时，隐藏光点、停止旋转与呼吸，数字照常更新。

## 原型专属（正式页面不包含）

- 右上角虚线框「演示场景」：切换空闲 / 繁忙 / 有异常三种合成数据，仅用于原型。
- 「全平台 / 九号泡泡健身」切换仅演示总台与企业端差异：企业端没有总库调整核验和企业活跃。
