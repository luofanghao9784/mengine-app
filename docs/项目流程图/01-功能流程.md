# 三端功能使用流程

这里描述用户怎样完成工作。箭头表示操作或业务交接，不代表全部步骤自动执行；“部署配置”属于工程接入环节。

## F01 三端协同总流程

总台负责企业与平台运营；企业端负责组织、数据和治理；员工端使用获权数据完成工作。三端通过共同身份、权限和任务记录协作。

候选框为本次研判，虚线表示可替换或补强的位置；原实线仍描述当前业务。绿色优先验证，黄色有条件采用，紫色已在使用；蓝色业务步骤由本项目保留。
