## 本地浏览

可直接打开 `index.html`，无需联网或安装依赖。也可在仓库根目录启动只读预览：

```sh
python3 -m http.server 5198 --bind 127.0.0.1 --directory docs
```

访问 `http://127.0.0.1:5198/项目流程图/index.html`；根地址也会跳转到图册并保留图号。以 `docs` 为服务目录，图册与协作看板可通过页面顶部互相跳转。端口若已被占用，使用空闲端口或确认现有预览的归属。

## 编辑与生成

功能和实现图的编辑源为三份带 Mermaid 的 Markdown：`01-功能流程.md`、`02-实现流程.md`、`05-开源替代流程.md`。功能清单直接编辑 `03-功能清单.md`。开源评估数据在 `research-build.py` 中维护，官方仓库调查快照保存在 `opensource-sources.json`。

在仓库根目录执行：

```sh
# 已按根 README 安装 npm 开发依赖；浏览器任选一种：
# 本机 Chrome，或 npx playwright install chromium
# 也可设置 DIAGRAM_BROWSER_PATH 指向已安装的兼容浏览器。
python3 docs/项目流程图/prepare.py
python3 docs/项目流程图/research-build.py
python3 docs/项目流程图/build.py
node docs/项目流程图/render.mjs
```

Python 3.9+；Node 版本沿根项目要求。`prepare.py` 校验固定 Mermaid 11.4.1 的 SHA-256；缺少缓存时下载到 Git 忽略的 `.local/diagram-tools/`。渲染使用根项目已有的 Playwright。浏览网页不依赖这些生成工具；依赖、运行日志、截图、PID 和机器绝对路径不入库。

`snapshot.json` 固定内容核查日期及代码基线，普通重建不会把当前 HEAD 冒充新的核查结论。功能或开源选型有新证据时，先更新说明与来源，再显式更新快照。

维护源和生成结果一起提交：`catalog.json`、`opensource-options.json`、两份 HTML、`04-开源替代研判.md` 以及 `diagrams/` 中的 SVG/Mermaid。这些是可离线阅读和单独导出的交付文档，不包含 Mermaid 运行库。
