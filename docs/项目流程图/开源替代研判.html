先替换能力内核，保留业务规则

优先验证 Docling 的复杂文档解析，比较 WeKnora 与 pgvector 的检索路线，再用 Langfuse 补内部诊断。PPT 已使用 PptxGenJS，继续复用。

三端业务、权限、来源版本、画报规则和成果发布继续由现有系统掌握。开源项目可以只承担一个函数、组件或执行步骤。

P1 优先验证 · P2 有需求/瓶颈再引入 · P3 条件成立再评估 · 已有继续维护。判断与集成方案为技术研判；未承诺节省工时或运行效果。

OSS01 · P1 · 局部替换

Docling

当前实现：平台通过 DocumentParser 调用 Python 解析器；PDF 使用文字提取和 OCR，复杂版式能力有限。

可替代部分：复杂 PDF 的布局、阅读顺序、表格结构和扫描件解析；可以只替换 PDF 分支。

本项目保留：上传、原件与版本、解析任务、状态、权限复核和固定引用；CSV/XLSX 原值与公式缓存语义先保留。

接入方式：独立受限进程或服务接入 DocumentParser，将结构化结果适配回 chunks/locator/status/warnings；新 parserVersion，不覆盖旧批次。

代价：中：模型资源、进程隔离和定位符适配

通过条件：用获准中文扫描件、跨页表格及混合版式对照原解析器；检查页码定位、表格值、超时、取消和撤权。

许可：MIT；模型单独许可。代码 MIT 不等于全部模型同许可；按实际选用模型与镜像核验。

通过条件：按真实允许集合评测召回率、过滤后结果不足、中文查询和索引更新；不把向量距离当正确答案。

许可：PostgreSQL License。
