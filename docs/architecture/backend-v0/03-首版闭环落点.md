## API 面（只列契约分片对应的资源族；具体路径以 contracts 定稿为准，仓内现在**未找到**这些契约文件）
- platform：capability-registry（登记、准入测试、admit/deprecate）
- tenant：check-flow-config（草稿/发布/退役）、quality-check-run（调试跑）、check-run-log（Task/Attempt 查询、复核动作）
- workspace：data-version-readonly（只读）

## 首版最小纵切（建议顺序）
1. contracts：五个 openapi 分片入仓（文档 PR，先于代码）。
2. 迁移 V190+：qo_* 表。
3. 端口 + LocalProcessAdapter（02 §2 S1–S2）。
4. 内置模块 `pii-regex/v1`（in-process），跑通 check → issue → review → publish。
5. 只读 data-version API 和前端 Live 对接。
