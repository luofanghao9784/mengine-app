## 8. 验收对齐（前端展示含义）

| 项 | 要求 |
| --- | --- |
| 模块可替换 | 配置区显示 `moduleVersionId`；切换不改业务结果页代码路径 |
| 结果可追溯 | 问题绑定 `inputVersionId` + 行/`column`；保留原值 |
| 失败可恢复 | 停在步骤；禁止笼统「全部完成」 |
| 质量真实 | 三态分列；运行成功仍可质量不通过 → 未发布 |
| 模拟 | `executionMode=simulated` 显著标注 |
