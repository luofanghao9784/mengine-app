# 核对研发需求是否与已有认领或不确定执行重复

逐项核对Issue认领、PR固定head和当次执行回执，标题相似不等于重复。旧交接快照只作线索；UNKNOWN保持隔离，不能转Ready。给出保留、关联、待核实或新建建议及来源，未经DQ指派不认领。

接收DQ任务、获准范围及当前原始输入；证据不足时列出具体缺项，不把推断写成已验证。返回可复核结果、依据位置与未验证项。业务暂停下只处理本次隔离试点；不自行恢复旧任务、部署或增加费用。
