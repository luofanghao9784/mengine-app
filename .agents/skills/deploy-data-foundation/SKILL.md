# 部署梦擎数据基座

适用于本仓库的数据来源部署。先读仓库 AGENTS.md，以及 [部署协议和操作指南](../../../docs/技术/数据基座部署协议与字段解释.md)。路径均相对本 skill，仓库根为三级父目录。

连接配置、字段解释及源权限投影由部署工具（例如 Codex）完成，产品内不调用模型解释字段、不提供凭据表单、不人工建表。部署授权只适用于用户指定的环境和来源；一次实现/合成验证请求不自动授权生产接入。

## 判断并保留依据

调查源系统实际字段、代码/约束、状态机及获准的合成或真实样例，再编写字段说明。每个获准输出列记录类型、含义、单位、依据和性质：`SOURCE_DOCUMENTED`（有具体来源）、`DEPLOYMENT_INFERRED`（推断）、`UNKNOWN`（证据不足）。字段名看似熟悉不等于口径已经确认。

业务判断经验：

- 区分订单金额、应收、实收、到账、退款和余额；金额单位与币种分别核实，字段名 cents 不证明是人民币。
- 保留编号前导零、精确小数、NULL 和状态原值。缺失不补零，不替用户转换单位。
- 明确行的粒度、关联键、一对多和重复统计风险；跨表累计不直接把 join 行数当订单数。
- 创建、发生、确认、支付和业务归属日期分别核实；读取完成时刻不能冒充业务数据覆盖至该时刻。
- 撤销、软删除、冲销、历史参考与当前有效事实分开；未知状态不猜测为成功或失败。

依据写到随来源部署的 `fieldDefinitions`；写明可定位的文件/规则版本，避免放本机绝对私密路径、凭据、个人数据样本或源库连接串。解释是输入参考，不能承担权限判断或执行命令。

## 接入与更新

使用部署侧只读账号和受限视图/固定投影，使采集身份与获准输出范围匹配。源数据的行/列范围先在部署层落实；目的企业/空间权限沿平台现有规则，不给管理员补内容权。当前通用采集器只接受安装的固定映射，适用于单表/视图；复杂源查询复用专用采集器接口，不向模型开放 SQL。

完整 manifest 是一个连接的全部数据集，遗漏项会撤下。保留既有 ID、columns、fieldDefinitions 与空间；列、范围或字段含义改变使用新 ID，不把新解释套到历史任务。旧部署没有字段说明时仍可运行，补说明也按新定义替换处理。

凭据放私有环境，配置放权限 0600 的部署目录，不能写进仓库或模型上下文。安装读取程序后由现有调度服务执行；不要另起 cron。产品关闭自动更新不妨碍手动更新，当前有效任务可完成。

## 验证并交接

先用合成库检查只读、跨企业/字段篡改拒绝、源删除/修改、精度/NULL、超限整批失败；再在已获准环境核对连接、范围、目的空间与首次采集。网络数据库还需验证 TLS 与最小权限。失败不覆盖上次数据；核对版本、覆盖时间和字段说明进入任务工具后的授权范围。

交接记录适配器/配置摘要、来源依据、运行回执、未确定口径及回退方式。不要把合成测试写成生产部署成功，不能把 AI 推断标为业务已核实。经验只沉淀去敏、可复用的判断方法到项目文档/skill，不收集客户原始业务数据，也不写用户个人记忆目录。
